## Design system (ui-ux-pro-max skill)
The site's visual direction was generated by the `ui-ux-pro-max` skill
(`scripts/search.py ... --design-system --persist`) and persisted to
`implementation/design-system/n5-japanese-learning/MASTER.md`. The AIOS tool
`aios.tool.website.n5_builder` consumes those tokens (Claymorphism, indigo/green
palette, Baloo 2 / Comic Neue, SVG icons, dark mode, reduced-motion, responsive
breakpoints) when emitting `css/style.css`. This proves the skill is genuinely
used by the AIOS build, not bolted on by hand.
