## TASK-151 — Verification Gate

**Mục tiêu**

Triển khai **Verification Gate** như một năng lực có contract, evidence và harness riêng — xác minh output của loop (T150) trước khi promote PASS, fail-closed, dựa trên Verification Engine (T142) + Verification Integrity (T078). TASK-151 là **gate, không phải verifier mới** (dựa trên Progress/Regression Detection T150 + Verification Engine T142 + Integrity T078 + Evidence T001).

TASK-151 thuộc **M21**, ngay sau T150. Trọng tâm canonical: **Verification Gate**.

### 1. Phạm vi — Gate, không verifier mới

```text
Verification Gate
├── Verify                (xác minh output loop T150)
├── Integrity Gate        (fail-closed, T078)
├── Provenance            (evidence chain, T001 Rule 5)
└── Policy Boundary       (T113)
```

* **Verify** — xác minh output loop (T150) đúng contract, đủ.
* **Integrity Gate** — không verify được → không promote PASS (T078).
* **Provenance** — mọi verification có evidence chain (T001 Rule 5).
* **Policy Boundary** — verification qua policy (T113).

### 2. Verification Gate Contract

```text
VerificationResult
├── result_id            (immutable, T001 Rule 1)
├── progress_ref         (T150)
├── verification_result   (PASS/FAIL/INCONCLUSIVE)
├── integrity_verified    (T078)
├── evidence_ref          (T001)
└── authority: aios
```

Quy tắc:

* Verification FAIL/INCONCLUSIVE → không promote PASS (fail-closed, T078).
* Mọi verification có provenance (T001 Rule 5).
* Verification deterministic: cùng output → cùng result.
* Verification không lộ secret (T040/T113).

### 3. Verification Gate Safety

* **Fail-closed** — INCONCLUSIVE → không promote PASS (T078).
* **Integrity verified** — output qua integrity gate (T078).
* **Evidence required** — mọi verification có provenance (T001 Rule 5).
* **Deterministic** — cùng output → cùng result.
* **No parallel gate** — dùng Progress/Regression (T150) + Verification Engine (T142) + Integrity (T078) + Evidence (T001).

### 4. Deliverables

* Verification Gate (verify + integrity + provenance).
* Policy Boundary (T113).
* Integration với Progress/Regression Detection (T150) + Verification Engine (T142) + Integrity (T078) + Evidence (T001).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — verification gate).

### 5. Acceptance Criteria

TASK-151 chỉ PASS khi:

* Verification Gate xác minh output loop (T150).
* Verification FAIL/INCONCLUSIVE → không promote PASS (fail-closed, T078).
* Mọi verification có provenance (T001 Rule 5).
* Cùng output → cùng result (deterministic).
* Verification không lộ secret (T040/T113).
* Tích hợp được với Progress/Regression Detection + Verification Engine + Integrity + Evidence.
* Regression của các milestone trước PASS; không vi phạm invariants.
