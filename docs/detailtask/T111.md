## TASK-111 — Model Registry + Deterministic Resolver

**Mục tiêu**

Triển khai **Model Registry + Deterministic Resolver** như một năng lực có contract, evidence và harness riêng — đăng ký model (qua T109 contract), và resolver chọn model theo policy/capability/cost/health một cách **deterministic** (không LLM). TASK-111 là **registry + deterministic resolver, không phải router mới** (dựa trên Model Contract T109 + Model Router T025 + Provider Registry T110).

TASK-111 thuộc **M17**, ngay sau T109. Trọng tâm canonical: **Model Registry + Deterministic Resolver**.

### 1. Phạm vi — Registry + deterministic resolver, không new router

```text
Model Registry + Deterministic Resolver
├── Model Registry        (đăng ký model qua T109)
├── Deterministic Resolver (chọn model theo rule, không LLM)
├── Capability Filter     (lọc theo capability)
└── Policy Boundary       (T113)
```

* **Model Registry** — đăng ký model với `model_id` immutable (T001 Rule 1).
* **Deterministic Resolver** — chọn model theo policy/capability/cost/health (T025) bằng rule, không LLM.
* **Capability Filter** — lọc model theo capability yêu cầu.
* **Policy Boundary** — resolver phải qua policy (T113).

### 2. Model Resolver Contract

```text
ModelResolver
├── model_id              (immutable, T001 Rule 1)
├── capability_req
├── policy_ref            (T113)
├── cost_budget
├── health_filter         (T025/T110)
├── selected_model
└── resolver_deterministic: bool
```

Quy tắc:

* `model_id` immutable; không cho trùng/tái sử dụng (T001 Rule 1).
* Resolver chạy deterministic (rule engine, không LLM) — LLM call count = 0.
* Cùng request + cùng registry/policy → cùng `selected_model` (deterministic).
* Mọi resolve có provenance (T001 Rule 5).

### 3. Model Resolver Safety

* **Deterministic-first** — resolver rule, không LLM (T001 Rule 4).
* **Fail-closed** — không resolve được → reject, không promote PASS (T078).
* **Immutable id** — `model_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi resolve có provenance (T001 Rule 5).
* **Policy boundary** — dùng Permission/Policy (T113) + Provider (T110) + Router (T025).
