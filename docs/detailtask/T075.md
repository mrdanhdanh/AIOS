## TASK-075 — Performance & Cost + Model Independence

**Mục tiêu**

Tối ưu **performance, cost và provider/model independence** cho AIOS — đảm bảo hệ thống không khoá chặt vào một model provider, có đo lường cost/perf và routing linh hoạt. TASK-075 là **perf/cost/independence layer, không phải runtime rewrite** (dựa trên `aios/model_router`, deterministic path T001 Rule 4).

TASK-075 thuộc **M10 – Architecture 1.0**, ngay sau T074 (Migration). Trọng tâm canonical: **Hiệu năng, cost và provider independence**.

### 1. Phạm vi — Perf/cost/independence, không lock-in

```text
Perf / Cost / Independence
├── Model Router         (aios/model_router — provider-agnostic)
├── Cost metering        (per-step / per-goal cost)
├── Performance budget   (latency / throughput SLO, T069)
├── Fallback routing     (provider hỏng -> khác, T055)
└── Deterministic-first  (T001 Rule 4 — LLM không mặc định)
```

* **Model Router** — abstraction chọn provider/model theo policy (không hardcode).
* **Cost metering** — đo cost mỗi step/goal; alert khi vượt budget (T067).
* **Perf budget** — latency/throughput nằm trong SLO (T069).
* **Fallback** — provider hỏng → route sang provider khác (T055).

### 2. Independence Contract

```text
ModelRoute
├── intent
├── selected_provider (policy-driven)
├── fallback_providers: [..]
├── cost_estimate
├── latency_budget
└── evidence_ref
```

Quy tắc:

* Không hardcode một provider — selection qua policy (model router).
* LLM chỉ fallback khi deterministic INSUFFICIENT (Rule 4, T001).
* Cost vượt budget → escalate/stop (T067/T068).

### 3. Independence Safety

* **No provider lock-in** — selection policy-driven (model router).
* **Deterministic-first** — LLM không mặc định (Rule 4).
* **Cost guard** — vượt budget → escalate/stop (fail-closed).
* **Evidence required** — mọi route + cost có provenance.
* **Deterministic** — cùng intent + cùng policy → cùng route.

### 4. Deliverables

* Model Router (provider-agnostic, policy-driven).
* Cost metering (per-step/goal) + budget alert.
* Performance budget integration (T069 SLO).
* Fallback routing (T055).
* Integration với Model Router (aios/model_router) + Deterministic (T001) + Recovery (T055).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — independence policy).

### 5. Acceptance Criteria

TASK-075 chỉ PASS khi:

* Không hardcode provider — selection qua model router (policy-driven).
* Cost được đo per-step/goal; vượt budget → escalate/stop (T067/T068).
* Perf nằm trong SLO (T069).
* Provider hỏng → fallback route (T055).
* LLM chỉ fallback khi deterministic INSUFFICIENT (Rule 4).
* Mọi route + cost có provenance evidence.
* Cùng intent + policy → cùng route (deterministic).
* Tích hợp được với Model Router + Deterministic + Recovery.
* Regression của các milestone trước PASS; không vi phạm invariants.
