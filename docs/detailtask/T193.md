## TASK-193 — Failure Attribution

**Mục tiêu**

Triển khai **Failure Attribution** như một năng lực có contract, evidence và harness riêng — truy nguyên failure từ evaluation fail về root cause, deterministic. TASK-193 là **attribution, không phải diagnostic mới** (dựa trên Evaluation Engine T186 + Diagnostic Agent T148 + Failure Classification T147 + Evidence T001).

TASK-193 thuộc **M25**, ngay sau T192. Trọng tâm canonical: **Failure Attribution**.

### 1. Phạm vi — Attribution, không diagnostic mới

```text
Failure Attribution
├── Trace                (truy vết từ eval fail)
├── Attribute            (gán nguyên nhân)
├── Confidence           (độ tự tin)
└── Policy Boundary      (T113)
```

* **Trace** — truy vết từ evaluation fail (T186) về observation/diagnosis.
* **Attribute** — gán nguyên nhân từ Failure Classification (T147)/Diagnostic (T148).
* **Confidence** — mỗi attribution có confidence; thấp → UNKNOWN.
* **Policy Boundary** — attribution qua policy (T113).

### 2. Failure Attribution Contract

```text
FailureAttribution
├── attr_id              (immutable, T001 Rule 1)
├── eval_ref             (T186)
├── class_ref            (T147)
├── root_cause_ref       (T148)
├── confidence           (0..1)
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Attribution UNKNOWN (confidence thấp) → không promote PASS (T078).
* Mọi attribution có provenance (T001 Rule 5).
* Attribution deterministic: cùng input → cùng root cause.
* Taxonomy đóng — không sinh nguyên nhân ngoài tập định nghĩa.

### 3. Failure Attribution Safety

* **Fail-closed** — UNKNOWN → không promote PASS (T078).
* **Immutable id** — `attr_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi attribution có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng root cause.
* **No parallel attribution** — dùng Evaluation Engine (T186) + Diagnostic Agent (T148) + Failure Classification (T147) + Evidence (T001).

### 4. Deliverables

* Failure Attribution (trace + attribute + confidence).
* Policy Boundary (T113).
* Integration với Evaluation Engine (T186) + Diagnostic Agent (T148) + Failure Classification (T147) + Evidence (T001).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — failure attribution).

### 5. Acceptance Criteria

TASK-193 chỉ PASS khi:

* Attribution truy vết được từ eval fail (T186) về root cause.
* UNKNOWN (confidence thấp) → không promote PASS (T078).
* Mọi attribution có provenance (T001 Rule 5).
* Cùng input → cùng root cause (deterministic).
* Tích hợp được với Evaluation Engine + Diagnostic Agent + Failure Classification + Evidence.
* Regression của các milestone trước PASS; không vi phạm invariants.
