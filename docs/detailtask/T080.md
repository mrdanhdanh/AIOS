## TASK-080 — Visual Evidence + Visual Regression + UI State Contract

**Mục tiêu**

Thêm **Visual Evidence** cho Harness — capture và so sánh trạng thái UI (screenshot / DOM state) để phát hiện visual regression, kèm **UI State Contract** định nghĩa trạng thái UI hợp lệ. TASK-080 là **visual evidence extension, không phải UI framework mới** (dựa trên Harness T030/T032 + Evidence T001).

TASK-080 thuộc **M11**, ngay sau T079 (RenderReplay). Trọng tâm canonical: **Visual Evidence + Visual Regression + UI State Contract**.

### 1. Phạm vi — Visual evidence, không replace harness

```text
Visual Evidence
├── Capture        (screenshot / DOM snapshot)
├── UI State Contract (defined valid states)
├── Visual Regression (diff vs baseline)
└── Evidence binding (visual -> provenance)
```

* **Visual Capture** — chụp screenshot / DOM state tại điểm verify.
* **UI State Contract** — định nghĩa tập trạng thái UI hợp lệ (baseline).
* **Visual Regression** — diff vs baseline; thay đổi ngoài dự kiến → flag.
* **Evidence binding** — visual evidence gắn với provenance chain (T001).

### 2. Visual Contract

```text
VisualEvidence
├── capture_id
├── ui_state_hash
├── baseline_ref
├── diff_score
├── regression: bool
└── evidence_ref
```

Quy tắc:

* Visual regression vượt ngưỡng → flag (không auto-pass).
* Baseline phải được duyệt (evidence) trước khi dùng so sánh.
* Mọi visual evidence gắn provenance (T001 Rule 5).

### 3. Visual Safety

* **Fail-closed regression** — diff vượt ngưỡng → flag, không PASS.
* **Baseline integrity** — baseline thay đổi phải qua evidence/approval.
* **Evidence required** — mọi visual capture có provenance.
* **Deterministic capture** — cùng UI state + cùng capture config → cùng hash.
* **No parallel visual system** — dùng Harness (T030/T032) + Evidence (T001).

### 4. Deliverables

* Visual Capture (screenshot / DOM snapshot).
* UI State Contract (defined valid states + baseline).
* Visual Regression (diff vs baseline).
* Evidence binding (visual → provenance).
* Integration với Harness (T030/T032) + Evidence (T001) + Replay (T079).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs khi task yêu cầu.

### 5. Acceptance Criteria

TASK-080 chỉ PASS khi:

* Visual capture chụp screenshot / DOM state tại điểm verify.
* UI State Contract định nghĩa trạng thái hợp lệ + baseline.
* Visual regression vượt ngưỡng → flag (không auto-pass).

* Mọi visual capture có provenance (T001 Rule 5).
