## TASK-092 — System Readiness vs Harness Trust

**Mục tiêu**

Thiết lập mối quan hệ **System Readiness vs Harness Trust** — chỉ khi harness đủ trust (T090/T091) thì system mới được coi là ready để chứng nhận; ngược lại system sẵn sàng nhưng harness chưa trust → không certify. TASK-092 là **readiness/trust gate, không phải feature mới** (dựa trên Coverage T090 + Meta T091 + Certification T073).

TASK-092 thuộc **M13**, ngay sau T091. Trọng tâm canonical: **System Readiness vs Harness Trust**.

### 1. Phạm vi — Readiness/trust gate, không new system

```text
System Readiness vs Harness Trust
├── System Readiness     (system có sẵn sàng không)
├── Harness Trust        (harness có đủ trust không, T090/T091)
├── Combined Gate        (ready AND trusted -> certify)
└── Trust evidence       (provenance)
```

* **System Readiness** — system đạt các điều kiện sẵn sàng (health, gates).
* **Harness Trust** — harness đủ coverage + meta-verified (T090/T091).
* **Combined Gate** — chỉ certify khi BOTH ready AND trusted.
* **Trust evidence** — mọi trust decision có provenance.

### 2. Trust Contract

```text
ReadinessTrust
├── system_ready: bool
├── harness_trusted: bool
├── combined: READY_TRUSTED | READY_UNTRUSTED | NOT_READY
├── reason
└── evidence_ref
```

Quy tắc:

* System ready nhưng harness untrusted → KHÔNG certify (fail-closed).
* Chỉ READY_TRUSTED mới certify.
* Mọi trust decision có provenance (T001 Rule 5).

### 3. Trust Safety

* **Fail-closed certify** — untrusted → không certify.
* **Both required** — ready AND trusted (không chỉ một).
* **Evidence required** — mọi trust decision có provenance.
* **Deterministic** — cùng system + cùng harness → cùng trust result.
* **No parallel trust system** — dùng Coverage (T090) + Meta (T091) + Cert (T073).
