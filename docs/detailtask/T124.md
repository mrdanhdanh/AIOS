## TASK-124 — Context Harness + Conformance

**Mục tiêu**

Triển khai **Context Harness + Conformance** như một năng lực có contract, evidence và harness riêng — chạy conformance suite cho toàn bộ context pipeline (T117→T123) và cấp conformance evidence có trust, fail-closed. TASK-124 là **harness + conformance, không phải pipeline mới** (dựa trên Repository Scanner T117 + Symbol Index T118 + Dependency T119 + Hybrid Index T120 + Retriever T121 + Builder T122 + Verification T123 + Harness T030/T032 + Integrity T078).

TASK-124 thuộc **M18**, ngay sau T123. Trọng tâm canonical: **Context Harness + Conformance**. Đây là task cuối của M18.

### 1. Phạm vi — Harness + conformance, không new pipeline

```text
Context Harness + Conformance
├── Harness               (chạy pipeline T117→T123 deterministic)
├── Conformance Suite     (kiểm tra từng stage theo contract)
├── Integrity Gate        (fail-closed, T078)
└── Evidence              (provenance, T001 Rule 5)
```

* **Harness** — chạy context pipeline (T117→T123) deterministic, không LLM.
* **Conformance Suite** — check từng stage (scan/symbol/dep/hybrid/retrieve/build/verify) theo contract.
* **Integrity Gate** — stage nào không verify → không promote PASS (T078).
* **Evidence** — mọi harness run có provenance (T001 Rule 5).

### 2. Context Harness Contract

```text
ContextConformance
├── pipeline_ref          (T117→T123)
├── stage_results[]       (PASS/FAIL/INCONCLUSIVE)
├── conformance_result    (PASS/FAIL/INCONCLUSIVE)
├── integrity_verified    (T078)
├── evidence_ref          (T001)
└── authority: aios      (luôn là aios)
```

Quy tắc:

* Mọi stage phải PASS; stage FAIL/INCONCLUSIVE → conformance FAIL (fail-closed, T078).
* Conformance chỉ PASS khi tất cả stage PASS + integrity verified (T078).
* Mọi harness run có provenance (T001 Rule 5).
* Cùng input + cùng suite → cùng result (deterministic).

### 3. Context Harness Safety

* **Fail-closed** — stage INCONCLUSIVE → conformance FAIL (T078).
* **Integrity verified** — mọi stage qua integrity gate (T078).
* **Evidence required** — mọi run có provenance (T001 Rule 5).
* **Deterministic** — cùng input + suite → cùng result.
* **No parallel harness** — dùng pipeline T117→T123 + Harness (T030/T032) + Integrity (T078) + Evidence (T001).

### 4. Deliverables

* Context Harness (chạy pipeline T117→T123 deterministic).
