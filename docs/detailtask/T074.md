## TASK-074 — Upgrade & Migration 1.0

**Mục tiêu**

Xây dựng **Upgrade & Migration 1.0** — cơ chế nâng cấp AIOS và migrate state/data giữa các version một cách an toàn, reversible và có evidence. TASK-074 là **migration tooling, không phải runtime feature** (dựa trên `aios/upgrade`, durable state T066).

TASK-074 thuộc **M10 – Architecture 1.0**, ngay sau T073 (Certification). Trọng tâm canonical: **Migration 1.0**.

### 1. Phạm vi — Migration, không redesign

```text
Upgrade & Migration 1.0
├── Version detection      (current -> target)
├── Migration plan         (ordered, reversible steps)
├── State migration        (durable state T066)
├── Dry-run + verify       (harness T032)
└── Rollback              (reversible)
```

* **Migration Engine** — phát hiện version, chạy plan theo thứ tự.
* **Reversible steps** — mỗi bước có rollback tương ứng.
* **Dry-run** — chạy thử không mutate; verify qua harness trước apply.
* **State migration** — migrate durable state (T066) an toàn.

### 2. Migration Contract

```text
MigrationPlan
├── from_version
├── to_version
├── steps: [ {id, up, down, verify} ]
├── dry_run_supported: bool
└── evidence_ref
```

Quy tắc:

* Migration không áp dụng nếu dry-run/verify FAIL (fail-closed).
* Mỗi bước phải reversible (có `down`).
* Mọi bước ghi evidence (provenance).

### 3. Migration Safety

* **Fail-closed apply** — verify FAIL → không apply.
* **Reversible** — mọi bước có rollback.
* **Evidence required** — mọi bước có provenance.
* **Deterministic** — cùng plan + cùng state → cùng kết quả migrate.
* **No data loss** — migrate state an toàn (T066).

### 4. Deliverables

* Migration Engine (version detect + ordered plan).
* Reversible migration steps + rollback.
* Dry-run + verify (harness T032).
* State migration (durable T066).
* Integration với Upgrade (aios/upgrade) + Durable (T066) + Harness (T032).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — migration process).

### 5. Acceptance Criteria

TASK-074 chỉ PASS khi:

* Migration Engine detect version + chạy plan theo thứ tự.
