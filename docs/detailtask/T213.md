### 3. Coding Health Score Safety

* **Fail-closed** — score thiếu provenance → không ghi nhận (T001 Rule 5).
* **Immutable id** — `score_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi score có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng điểm (T187).
* **No parallel scorer** — dùng Coding Doctor (T212) + Quality Dimensions (T187) + Evaluation Engine (T186) + Evidence (T001).
