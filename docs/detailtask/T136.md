## TASK-136 — Sandbox Manager

**Mục tiêu**

Triển khai **Sandbox Manager** như một năng lực có contract, evidence và harness riêng — quản lý vòng đời sandbox (create/destroy/isolate) để execution (T135) chạy isolated, không phá Core. TASK-136 là **sandbox manager, không phải execution mới** (dựa trên Execution Contract T135 + Credential/Network/Sandbox T040 + Resource T005).

TASK-136 thuộc **M20**, ngay sau T135. Trọng tâm canonical: **Sandbox Manager**.

### 1. Phạm vi — Sandbox manager, không new execution

```text
Sandbox Manager
├── Lifecycle            (create/destroy/isolate)
├── Isolation            (process/fs/network isolation, T040)
├── Health               (sandbox healthy check)
└── Policy Boundary       (T113)
```

* **Lifecycle** — tạo/hủy sandbox; `sandbox_id` immutable (T001 Rule 1).
* **Isolation** — cô lập process/filesystem/network (T040).
* **Health** — healthcheck sandbox; unhealthy → không dùng.
* **Policy Boundary** — sandbox phải qua policy (T113).

### 2. Sandbox Manager Contract

```text
SandboxRecord
├── sandbox_id           (immutable, T001 Rule 1)
├── status               (created/destroyed/isolated)
├── isolation_level      (process/fs/network, T040)
├── health               (healthy/unhealthy)
├── policy_ref           (T113)
└── evidence_ref         (T001)
```

Quy tắc:

* `sandbox_id` immutable; không cho trùng/tái sử dụng (T001 Rule 1).
* Sandbox unhealthy → không chạy execution (T135).
* Mọi lifecycle event có provenance (T001 Rule 5).
* Cùng state → cùng lifecycle result (deterministic).

### 3. Sandbox Manager Safety

* **Fail-closed** — sandbox không isolate được → reject (T040/T078).
* **Immutable id** — `sandbox_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi event có provenance (T001 Rule 5).
* **Deterministic** — cùng state → cùng result.
* **No parallel sandbox** — dùng Execution Contract (T135) + Sandbox (T040) + Resource (T005) + Policy (T113).
