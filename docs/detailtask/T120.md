## TASK-120 — Semantic + Hybrid Index

**Mục tiêu**

Triển khai **Semantic + Hybrid Index** như một năng lực có contract, evidence và harness riêng — kết hợp symbol index (T118) + dependency graph (T119) + semantic embedding thành hybrid index để retrieval. TASK-120 là **hybrid index, không phải retriever mới** (dựa trên Source/Symbol Index T118 + Dependency Graph T119 + Context Retriever T121).

TASK-120 thuộc **M18**, ngay sau T118/T119. Trọng tâm canonical: **Semantic + Hybrid Index**.

### 1. Phạm vi — Hybrid index, không new retriever

```text
Semantic + Hybrid Index
├── Symbol Index Ref     (T118)
├── Dependency Ref       (T119)
├── Semantic Embedding   (embedding cho retrieval)
└── Hybrid Query         (kết hợp symbolic + semantic)
```

* **Symbol Index Ref** — dùng symbol index (T118) làm backbone.
* **Dependency Ref** — dùng dependency graph (T119) để mở rộng ngữ cảnh.
* **Semantic Embedding** — embedding chunk để retrieval ngữ nghĩa.
* **Hybrid Query** — kết hợp symbolic + semantic score.

### 2. Hybrid Index Contract

```text
HybridIndex
├── repo_ref
├── symbol_ref           (T118)
├── dependency_ref       (T119)
├── embeddings[]         (chunk, vector, content_hash)
├── index_id             (immutable, T001 Rule 1)
└── evidence_ref         (T001)
```

Quy tắc:

* Mọi embedding chunk có `content_hash` (T078) + provenance (T001 Rule 5).
* Hybrid query deterministic: cùng query + cùng index → cùng rank (deterministic).
* Embedding fail → reject (fail-closed, T078).
* Mọi index có provenance (T001 Rule 5).

### 3. Hybrid Index Safety

* **Fail-closed** — embedding fail → reject (T078).
* **Secret isolation** — không index secret (T040/T113).
* **Evidence required** — mọi index có provenance (T001 Rule 5).
* **Deterministic** — cùng query + index → cùng rank.
* **No parallel index** — dùng Symbol Index (T118) + Dependency (T119) + Evidence (T001) + Integrity (T078).

### 4. Deliverables
