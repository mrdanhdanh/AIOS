## TASK-122 — Context Builder + Budget

**Mục tiêu**

Triển khai **Context Builder + Budget** như một năng lực có contract, evidence và harness riêng — lắp ráp retrieved context (T121) thành prompt/context cuối, enforce budget (token/size) và không vượt giới hạn. TASK-122 là **builder + budget, không phải retriever mới** (dựa trên Context Retriever T121 + Context Optimizer T024).

TASK-122 thuộc **M18**, ngay sau T121. Trọng tâm canonical: **Context Builder + Budget**.

### 1. Phạm vi — Builder + budget, không new retriever

```text
Context Builder + Budget
├── Assembly             (lắp ráp context từ T121)
├── Budget Enforce       (token/size bound, fail-closed)
├── Priority Trim        (cắt theo priority khi vượt budget)
└── Policy Boundary      (T113)
```

* **Assembly** — lắp ráp retrieved hits (T121) thành context cuối.
* **Budget Enforce** — enforce budget token/size; vượt → trim/fail-closed (T024).
* **Priority Trim** — khi vượt budget, cắt theo priority (T024).
* **Policy Boundary** — builder không lộ secret (T040/T113).

### 2. Context Builder Contract

```text
BuiltContext
├── retrieval_ref        (T121)
├── assembled_chunks[]
├── budget_used
├── budget_limit
├── within_budget: bool
└── evidence_ref         (T001)
```

Quy tắc:

* Context phải `within_budget`; vượt → trim hoặc reject (fail-closed, T024/T078).
* Mọi chunk giữ `content_hash` (T078) + provenance (T001 Rule 5).
* Build deterministic: cùng retrieval + cùng budget → cùng context (deterministic).
* Builder không lộ secret (T040/T113).

### 3. Context Builder Safety

* **Fail-closed** — vượt budget không trim được → reject (T024/T078).
* **Budget bound** — enforce token/size (T024).
* **Secret isolation** — không lộ secret (T040/T113).
* **Evidence required** — mọi build có provenance (T001 Rule 5).
* **Deterministic** — cùng retrieval + budget → cùng context.
* **No parallel builder** — dùng Retriever (T121) + Context Optimizer (T024) + Evidence (T001).
