## TASK-195 — Model / Agent Benchmark

**Mục tiêu**

Triển khai **Model / Agent Benchmark** như một năng lực có contract, evidence và harness riêng — chạy benchmark model/agent trên registry (T188) + baseline (T189) + engine (T186), fail-closed. TASK-195 là **benchmark runner, không phải registry mới** (dựa trên Benchmark Registry T188 + Baseline Manager T189 + Evaluation Engine T186 + Evidence T001).

TASK-195 thuộc **M25**, ngay sau T194. Trọng tâm canonical: **Model / Agent Benchmark**.

### 1. Phạm vi — Benchmark runner, không registry mới

```text
Model / Agent Benchmark
├── Run Benchmark        (chạy benchmark từ T188)
├── Compare Baseline     (so với baseline T189)
├── Verdict              (PASS/FAIL)
└── Policy Boundary      (T113)
```

* **Run Benchmark** — chạy benchmark từ registry (T188) qua engine (T186).
* **Compare Baseline** — so sánh với baseline (T189).
* **Verdict** — tổng hợp verdict (dùng Regression Detector T190).
* **Policy Boundary** — benchmark qua policy (T113), sandbox-only (T136).

### 2. Model / Agent Benchmark Contract

```text
ModelAgentBenchmark
├── bench_run_id         (immutable, T001 Rule 1)
├── registry_ref         (T188)
├── baseline_ref         (T189)
```

Quy tắc:

* Benchmark chỉ trong sandbox (T136/T040).

### 3. Model / Agent Benchmark Safety

* **Fail-closed** — regression → FAIL (T078/T190).
* **Immutable id** — `bench_run_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi run có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng output (T029/T079).
* **No parallel runner** — dùng Benchmark Registry (T188) + Baseline Manager (T189) + Evaluation Engine (T186) + Evidence (T001).
