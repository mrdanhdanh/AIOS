## TASK-191 — Agent Behavior Evaluator

**Mục tiêu**

Triển khai **Agent Behavior Evaluator** như một năng lực có contract, evidence và harness riêng — đánh giá hành vi agent theo behavioral verifier, fail-closed. TASK-191 là **behavior evaluator, không phải verifier mới** (dựa trên Evaluation Engine T186 + Behavioral Verifier T157 + Quality Dimensions T187 + Evidence T001).

TASK-191 thuộc **M25**, ngay sau T190. Trọng tâm canonical: **Agent Behavior Evaluator**.

```text
Agent Behavior Evaluator
├── Behavior Spec        (spec hành vi, T157)
├── Evaluate             (đánh giá hành vi agent)
```

### 2. Agent Behavior Evaluator Contract

```text
BehaviorEval
├── eval_id              (immutable, T001 Rule 1)
├── engine_ref           (T186)
├── behavior_spec        (T157)
├── verdict              (PASS/FAIL/INCONCLUSIVE)
├── evidence_ref         (T001)
```

Quy tắc:

* Behavior không khớp → FAIL/INCONCLUSIVE (fail-closed, T078/T157).
* Mọi eval có provenance (T001 Rule 5).
* Evaluation deterministic: cùng input → cùng verdict.
* Evaluation không lộ secret (T040/T113).

### 3. Agent Behavior Evaluator Safety

* **Fail-closed** — INCONCLUSIVE → không promote PASS (T078/T157).
* **Immutable id** — `eval_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi eval có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng verdict.
* **No parallel evaluator** — dùng Evaluation Engine (T186) + Behavioral Verifier (T157) + Quality Dimensions (T187) + Evidence (T001).
