## TASK-104 — Independent Harness Integration Foundation

**Mục tiêu**

Xây dựng **nền tảng tích hợp Independent Harness (Harness độc lập bên ngoài)** vào AIOS — định nghĩa contract adapter, cơ chế đăng ký (registration), boundary ingest evidence, và giữ **authority/policy ở AIOS**. TASK-104 là **foundation của M16, không phải harness mới** (dựa trên Harness T030/T032 + Integrity T078 + Evidence T001).

TASK-104 thuộc **M16 – Independent Harness Integration**, ngay sau T103 (M15). Trọng tâm canonical: **Independent Harness Integration Foundation**. Đây là task mở M16.

### 1. Phạm vi — Foundation tích hợp, không new harness

```text
Independent Harness Integration Foundation
├── Adapter Contract      (interface cho independent harness bên ngoài)
├── Registration          (đăng ký harness độc lập, immutable id)
├── Evidence Ingest Boundary (boundary nhận evidence từ ngoài)
└── Policy Authority      (AIOS luôn giữ authority/policy)
```

* **Adapter Contract** — định nghĩa interface mà mọi independent harness phải implement để kết nối AIOS.
* **Registration** — đăng ký harness độc lập với `harness_id` immutable; không cho trùng/id tái sử dụng (T001 Rule 1).
* **Evidence Ingest Boundary** — ranh giới tiếp nhận evidence từ harness ngoài; mọi evidence phải qua validate + provenance (T001 Rule 5).
* **Policy Authority** — AIOS giữ authority quyết định; independent harness chỉ cung cấp input, không có quyền policy.

### 2. Integration Foundation Contract

```text
IndependentHarnessAdapter
├── harness_id            (immutable, T001 Rule 1)
├── harness_type          (external / third-party / separate)
├── source                (endpoint / artifact path)
├── supported_checks      (danh sách invariant có thể check)
├── evidence_format       (schema evidence đầu vào)
└── policy_authority: aios (luôn là aios)
```

Quy tắc:

* Mọi independent harness phải đăng ký trước khi ingest evidence.
* Evidence từ ngoài phải có `content_hash` + `producer` + `source` (T001 Rule 5).
* Independent harness **không** được ghi đè policy verdict của AIOS.
* Cùng adapter + cùng input → cùng kết quả ingest (deterministic).

### 3. Integration Foundation Safety

* **Fail-closed ingest** — evidence thiếu provenance/hash → reject (T078).
* **Authority stays in AIOS** — independent harness không có quyền policy.
* **Evidence required** — mọi ingest có provenance (T001 Rule 5).
* **Deterministic** — cùng adapter + cùng input → cùng kết quả.
* **No parallel authority system** — dùng Harness (T030/T032) + Integrity (T078) + Evidence (T001).

### 4. Deliverables

* Independent Harness Adapter Contract (interface + schema).
* Registration mechanism (`harness_id` immutable, T001 Rule 1).
* Evidence Ingest Boundary (validate + provenance, T078/T001).
* Policy Authority boundary (AIOS giữ authority).
* Integration với Harness (T030/T032) + Integrity (T078) + Evidence (T001) + Oracle (T105).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — foundation tích hợp).

### 5. Acceptance Criteria

TASK-104 chỉ PASS khi:

* Independent Harness Adapter Contract được định nghĩa rõ (interface + schema).
* Registration hoạt động; `harness_id` immutable (T001 Rule 1).
* Evidence Ingest Boundary được enforce (thiếu provenance → reject, T078).
* AIOS giữ authority/policy; independent harness không ghi đè verdict.
* Mọi ingest có provenance (T001 Rule 5).
* Cùng adapter + input → cùng kết quả (deterministic).
* Tích hợp được với Harness + Integrity + Evidence + Oracle (T105).
* Regression của các milestone trước PASS; không vi phạm invariants.
