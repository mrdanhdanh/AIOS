## TASK-064 — Public Contract Freeze

**Mục tiêu**

**Đóng băng (freeze) public contracts 1.0** — API, schema, interface và event contract đối ngoại của AIOS được version hóa và cam kết ổn định (backward-compatibility promise bắt đầu từ đây). TASK-064 là **contract freeze + versioning, không phải feature mới**.

TASK-064 thuộc **M10 – Architecture 1.0**, ngay sau T063 (Architecture 1.0). Trọng tâm canonical: **Freeze public contracts 1.0**.

### 1. Phạm vi — Freeze contracts, không change behavior

```text
Public Contracts (1.0 frozen)
├── API contracts        (aios/api + sdk)
├── Schema contracts     (pydantic / json-schema)
├── Event contracts      (aios/core/events)
├── Capability contracts (aios/capability)
└── Tool contracts       (aios/tool)
```

* **Contract Registry** — mọi public contract có `version=1.0.0`, `status=FROZEN`.
* **Compatibility Promise** — breaking change → `major` bump + ADR + deprecation window.
* **Contract Tests** — conformance tests khóa behavior của contract đã freeze.

### 2. Contract Model (frozen)

```text
Contract
├── name
├── version: 1.0.0
├── status: FROZEN | DEPRECATED | DRAFT
├── surface: API | SCHEMA | EVENT | CAPABILITY | TOOL
├── compatibility: backward-compatible-until
└── evidence_ref
```

Quy tắc:

* Contract đã FROZEN không được thay đổi breaking mà không bump major + ADR.
* Mọi public surface phải có contract đã đăng ký.
* Contract test phải PASS trước khi DONE.

### 3. Freeze Safety

* **No silent contract change** — thay đổi public contract → version bump + ADR.
* **Fail-closed** — contract test fail → BLOCK.
* **Deterministic** — cùng contract version + cùng test → cùng kết quả.
* **No shadow contract** — mọi public surface phải đăng ký contract.

### 4. Deliverables

* Public Contract Registry (version 1.0.0, status FROZEN).
* Compatibility promise document (backward-compat policy).
* Contract conformance tests cho mọi public surface.
* ADR/docs (bắt buộc — task là freeze + document).
* Unit + Contract + Architecture + Regression tests.

### 5. Acceptance Criteria

TASK-064 chỉ PASS khi:

* Mọi public contract có `version=1.0.0`, `status=FROZEN`.
* Breaking change yêu cầu major bump + ADR + deprecation window.
* Mọi public surface (API/schema/event/capability/tool) có contract đăng ký.
* Contract conformance tests PASS.
* Thay đổi contract → version bump (no silent change).
* Contract test fail → BLOCK (fail-closed).
* Contract test deterministic.
* Regression của các milestone trước PASS; không vi phạm invariants.
