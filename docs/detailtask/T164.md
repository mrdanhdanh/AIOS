### 3. Trust Evaluator + CodingCertificate + Verification Harness Safety

* **Fail-closed** — verifier fail → không cấp certificate (T078/T049).
* **Immutable id** — `cert_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi certificate có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng trust score.
* **No parallel harness** — dùng toàn bộ M22 (T155→T163) + Certification (T049) + Ecosystem Trust (T046) + Verification Engine (T142) + Evidence (T001).
