## TASK-127 — Code Generation Runtime

**Mục tiêu**

Triển khai **Code Generation Runtime** như một năng lực có contract, evidence và harness riêng — thực thi coding plan (T126) thành code artifact qua capability, không để agent truy cập tool/runtime trực tiếp. TASK-127 là **generation runtime, không phải agent mới** (dựa trên Coder Agent T125 + Coding Planner T126 + Worker T013 + Capability T009/T014).

TASK-127 thuộc **M19**, ngay sau T126. Trọng tâm canonical: **Code Generation Runtime**.

### 1. Phạm vi — Generation runtime, không new agent

```text
Code Generation Runtime
├── Plan Execution        (thực thi CodingPlan T126)
├── Capability Dispatch   (chỉ qua Capability, T009/T014)
├── Artifact Emit         (tạo code artifact có hash)
└── Policy Boundary       (T113)
```

* **Plan Execution** — thực thi từng step của CodingPlan (T126) deterministic.
* **Capability Dispatch** — mọi thao tác code qua Capability (T009/T014), không agent tự gọi tool (ARCH-004).
* **Artifact Emit** — tạo code artifact có `content_hash` (T078).
* **Policy Boundary** — mọi step qua policy (T113).

### 2. Code Generation Contract

```text
GenerationRun
├── plan_ref              (T126)
├── steps_executed[]
├── artifacts[]           (content_hash, T078)
├── capability_ref        (T009/T014)
├── policy_ref            (T113)
└── evidence_ref          (T001)
```

Quy tắc:

* Agent không gọi tool/runtime trực tiếp; chỉ qua Capability (ARCH-004).
* Mọi artifact có `content_hash` (T078) + provenance (T001 Rule 5).
* Execution deterministic: cùng plan → cùng artifact set (deterministic).
* Mọi run có provenance (T001 Rule 5).

### 3. Code Generation Safety

* **Architecture gate** — agent gọi tool trực tiếp → BLOCK (ARCH-004).
* **Fail-closed** — artifact không hash được → reject (T078).
* **Evidence required** — mọi run có provenance (T001 Rule 5).
* **Deterministic** — cùng plan → cùng artifact set.
* **No parallel runtime** — dùng Coder Agent (T125) + Planner (T126) + Capability (T009/T014) + Worker (T013).
