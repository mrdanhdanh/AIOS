## TASK-172 — Environment / Dependency Attackers

**Mục tiêu**

Triển khai **Environment / Dependency Attackers** như một năng lực có contract, evidence và harness riêng — tấn công environment/dependency (T136/T137) bằng poisoned dependency và env drift, để xác nhận sandbox/snapshot vẫn fail-closed. TASK-172 là **attacker, không phải sandbox mới** (dựa trên Adversarial Harness T165 + Sandbox Manager T136 + Workspace/Snapshot T137 + Credential Isolation T040 + Evidence T001).

TASK-172 thuộc **M23**, ngay sau T171. Trọng tâm canonical: **Environment / Dependency Attackers**.

### 1. Phạm vi — Attacker, không sandbox mới

```text
Environment / Dependency Attackers
├── Poisoned Dep         (dependency độc hại)
├── Env Drift            (env drift so với snapshot, T137)
├── Drift Detect         (phát hiện drift, T136/T137)
└── Policy Boundary      (T113)
```

* **Poisoned Dep** — thử inject dependency độc hại.
* **Env Drift** — thử drift env so với snapshot (T137).
* **Drift Detect** — sandbox/snapshot phải phát hiện (fail-closed, T136/T137).
* **Policy Boundary** — attack qua policy (T113), sandbox-only (T136).

### 2. Environment / Dependency Attackers Contract

```text
EnvAttack
├── attack_id            (immutable, T001 Rule 1)
├── harness_ref          (T165)
├── target_ref           (T136/T137)
├── attack_type          (POISONED_DEP/ENV_DRIFT)
├── detected: bool       (T136/T137)
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Poisoned dep / env drift phải bị phát hiện → không execute (fail-closed, T136/T137).
* Mọi attack có provenance (T001 Rule 5).
* Attack deterministic: cùng input → cùng detect result.
* Attack chỉ trong sandbox (T136/T040).

### 3. Environment / Dependency Attackers Safety

* **Fail-closed** — drift bị phát hiện (T136/T137).
* **Immutable id** — `attack_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi attack có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng detect result.
* **No parallel attacker** — dùng Adversarial Harness (T165) + Sandbox (T136) + Workspace/Snapshot (T137) + Credential Isolation (T040) + Evidence (T001).
