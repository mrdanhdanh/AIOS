## TASK-070 — AIOS Security Baseline

**Mục tiêu**

Thiết lập **security baseline 1.0** cho AIOS — authentication, authorization (permission broker), secret handling và least-privilege cho mọi capability/tool. TASK-070 là **security foundation, không phải feature mới** (dựa trên Runtime Permission/Poĺicy đã có).

TASK-070 thuộc **M10 – Architecture 1.0**, ngay sau T069 (Reliability). Trọng tâm canonical: **Security baseline 1.0**.

### 1. Phạm vi — Security foundation, không redesign

```text
Security Layer
├── Authentication       (identity / token)
├── Authorization        (aios/runtime/permission + policy)
├── Secret handling      (no plaintext, scoped)
├── Least-privilege      (capability/tool scoped)
└── Audit                (every privileged action)
```

* **Auth** — mọi external entry (API/SDK) yêu cầu auth hợp lệ.
* **Permission Broker** — mọi capability/tool action qua permission check (T054/Policy).
* **Secret Store** — secret không lưu plaintext; scoped + rotated.
* **Least-privilege** — agent/capability chỉ có quyền tối thiểu cần thiết.

### 2. Security Contract

```text
SecurityContext
├── principal
├── scopes
├── permissions: [capability/tool -> allowed actions]
├── secret_refs (scoped, not values)
└── evidence_ref
```

Quy tắc:

* Action không có permission → BLOCK (fail-closed).
* Secret không bao giờ log plaintext.
* Mọi privileged action ghi audit evidence (provenance).

### 3. Security Safety

* **Fail-closed authz** — thiếu permission → BLOCK (không default-allow).
* **No secret leakage** — secret không log / không truyền qua log.
* **Least-privilege enforced** — vượt scope → BLOCK.
* **Deterministic** — cùng security context + cùng action → cùng quyết định.
* **No parallel security system** — dùng Runtime Permission/Policy.

### 4. Deliverables

* Auth (identity/token) cho external entry.
* Permission Broker integration (Runtime permission + policy).
* Secret handling (scoped, no plaintext, rotation).
* Least-privilege scoping cho capability/tool.
* Audit trail cho privileged action.
* Integration với Runtime (T065) + Governor (T054) + API (aios/api).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — security baseline).

### 5. Acceptance Criteria

TASK-070 chỉ PASS khi:

* Mọi external entry yêu cầu auth hợp lệ.
* Action không permission → BLOCK (fail-closed).
* Secret không log plaintext / không leak.
* Least-privilege enforced (vượt scope → BLOCK).
* Mọi privileged action ghi audit evidence (provenance).
* Cùng security context + action → cùng quyết định (deterministic).
* Tích hợp được với Runtime (T065) + Governor (T054) + API.
* Regression của các milestone trước PASS; không vi phạm invariants.
