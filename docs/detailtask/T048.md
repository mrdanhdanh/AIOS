## TASK-048 — Ecosystem Hub

## 1. Metadata

* **Milestone:** M8 — Ecosystem + Autonomy
* **Task ID:** TASK-048
* **Tên:** Ecosystem Hub
* **Mục tiêu canonical:** Ecosystem Hub.
* **Dependency trực tiếp:** TASK-047 — Developer Kit

Theo roadmap sạch, TASK-048 thuộc **M8 – Ecosystem** và có mục tiêu phân phối extension. Nguồn hiện chỉ đặc tả ở mức khung: triển khai phải tích hợp Runtime/Harness hiện có, không tạo control plane song song; phải có implementation, tests, docs/ADR khi cần; AC phải PASS, regression các milestone trước PASS và không vi phạm invariant. 

### 1. Mục tiêu

Xây **Ecosystem Hub** làm lớp phân phối extension/skill/plugin chính thức của AIOS.

Hub phải cho phép:

* publish extension;
* discover/search extension;
* xem metadata, version, dependency, capability, permission;
* kiểm tra compatibility với AIOS;
* tải/install extension thông qua Plugin Runtime;
* quản lý version;
* hỗ trợ lifecycle phân phối mà **không bypass Runtime, Policy, Permission hoặc Certification**.

Hub **không được trở thành Runtime thứ hai** và không trực tiếp thực thi plugin.

### 2. Phạm vi

#### 2.1 Extension Package

Chuẩn hóa package artifact:

```text
extension/
├── manifest.yaml
├── contracts/
├── skills/
├── capabilities/
├── prompts/
├── workflows/
├── assets/
└── metadata/
```

Manifest tối thiểu:

```yaml
id: com.example.extension
name: Example Extension
version: 1.0.0
api_version: "1.x"
type: skill
description: ...
author: ...
license: ...
dependencies: []
capabilities: []
permissions: []
platforms: []
checksum: ...
```

#### 2.2 Hub Registry

Hub duy trì metadata registry cho extension:

```text
Extension
 ├── identity
 ├── versions
 ├── metadata
 ├── dependencies
 ├── capabilities
 ├── permissions
 ├── compatibility
 ├── certification
 ├── checksum
 └── distribution artifact
```

Registry phải hỗ trợ:

* publish;
* unpublish/revoke;
* version lookup;
* search;
* filtering;
* dependency metadata;
* compatibility query.

#### 2.3 Discovery

Discovery phải hỗ trợ deterministic search trước:

```text
ID
→ exact name
→ capability
→ category/tag
→ compatibility
→ certification/trust
```

Không dùng LLM làm dependency của discovery cơ bản.

#### 2.4 Distribution

Flow chuẩn:

```text
Developer
   ↓
Package
   ↓
Validate
   ↓
Publish
   ↓
Ecosystem Hub
   ↓
Discover
   ↓
Compatibility Check
   ↓
Certification/Trust Check
   ↓
Download
   ↓
Plugin Runtime
   ↓
Policy + Permission
   ↓
Install/Enable
```

Hub chỉ **phân phối artifact**; Plugin Runtime mới chịu trách nhiệm lifecycle.

#### 2.5 Compatibility

Hub phải expose compatibility metadata để client biết extension có phù hợp AIOS hiện tại hay không:

```text
AIOS version
Contract version
Extension API version
Required capabilities
Required permissions
Dependencies
Platform constraints
```

Extension incompatible phải bị chặn hoặc đánh dấu rõ ràng, không được silently install.

### 3. Security Boundary

Hub không được bypass:

```text
Extension
   ↓
Hub
   ↓
Trust/Certification
   ↓
Plugin Runtime
   ↓
Policy
   ↓
Permission
   ↓
Sandbox
```

Đặc biệt:

* Hub không cấp permission.
* Hub không thực thi tool.
* Hub không resolve credential.
* Hub không tự enable plugin.
* Hub không bypass certification/trust.
* Artifact phải có checksum/provenance.
* Package bị revoke phải không được cài mới.

Điều này phù hợp với kiến trúc M8: các task trước đã tách **Plugin Runtime**, **Extension Contracts** và **Ecosystem Registry**; TASK-048 là lớp phân phối phía trên chúng.

### 6. Acceptance Criteria

**AC-01 — Publish**

Extension hợp lệ có thể publish và xuất hiện trong registry.

**AC-02 — Invalid package**

Manifest/package sai schema → `REJECT`.

**AC-03 — Immutable version**

Một `extension_id + version` đã publish không được âm thầm overwrite.

**AC-04 — Discovery**

Có thể tìm extension theo ID, capability, tag và compatibility.

**AC-05 — Compatibility**

Extension không tương thích phải trả về trạng thái `INCOMPATIBLE`, không được coi là installable.

**AC-06 — Integrity**

Artifact tải xuống phải verify checksum trước khi đưa sang Plugin Runtime.

**AC-07 — Runtime boundary**

Hub không trực tiếp execute plugin/tool.

**AC-08 — Policy boundary**

Install/enable phải tiếp tục qua Plugin Runtime + Policy + Permission.

**AC-09 — Provenance**

Mỗi artifact phân phối phải truy được:

```text
Extension
→ Version
→ Artifact
→ Checksum
→ Publisher
→ Certification/Trust
```

**AC-10 — Revocation**

Extension/version bị revoke không được phép tiếp tục được coi là trusted/installable.

**AC-11 — Offline-first**

Registry local/cache vẫn có thể phục vụ discovery và artifact đã cache khi network unavailable.

**AC-12 — Regression**

Regression của M0–M7 PASS và architecture invariants không bị vi phạm.

### 9. Architecture Invariants cần giữ

Đặc biệt:

* **Runtime-first** — Hub không trở thành execution plane.
* **Plugin-first** — extension chỉ hoạt động qua Plugin Runtime.
* **Policy-first** — distribution không đồng nghĩa authorization.
* **Evidence-first** — artifact/provenance phải truy xuất được.
* **Fail-closed** — thiếu compatibility/trust/integrity → không install.
* Không tạo control plane song song.
