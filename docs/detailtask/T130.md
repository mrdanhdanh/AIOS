TASK-130 thuộc **M19**, ngay sau T129. Trọng tâm canonical: **Coding Artifact + CodingEvidence**. Đây là task cuối của M19.

### 3. Coding Artifact Safety

* **Fail-closed** — artifact không verify → không promote PASS (T078).
* **Integrity verified** — artifact qua integrity gate (T078).
* **Immutable id** — `artifact_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi artifact có provenance chain (T001 Rule 5).
* **Deterministic** — cùng artifact + verifier → cùng verdict.
* **No parallel artifact** — dùng Generation (T127) + Patch (T128) + Review (T129) + Evidence (T001) + Integrity (T078).
