## TASK-197 — Unified Coding Contract

**Mục tiêu**

Triển khai **Unified Coding Contract** như một năng lực có contract, evidence và harness riêng — contract thống nhất cho toàn bộ coding (request/response, session ref, evidence ref) mà mọi task M26 dùng chung. TASK-197 là **foundation của M26, không phải engine mới** (dựa trên Coder Agent Contract T125 + Coding Evaluation Contract T185 + Evidence T001 Rule 5).

TASK-197 thuộc **M26**, là task mở milestone cuối. Trọng tâm canonical: **Unified Coding Contract**.

### 1. Phạm vi — Contract chuẩn, không engine mới

```text
Unified Coding Contract
├── Coding Schema        (request/response chuẩn)
├── Session Ref          (ref session, T206)
├── Evidence Ref         (T001)
└── Policy Boundary      (T113)
```

* **Coding Schema** — định nghĩa cấu trúc coding request/response chuẩn.
* **Session Ref** — coding trỏ tới session (T206).
* **Evidence Ref** — mọi coding có provenance (T001 Rule 5).
* **Policy Boundary** — coding qua policy (T113).

### 2. Unified Coding Contract

```text
UnifiedCodingContract
├── contract_id          (immutable, T001 Rule 1)
├── request_schema
├── response_schema
├── session_ref          (T206)
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Mọi coding có provenance (T001 Rule 5).
* Coding deterministic: cùng input → cùng output (T125/T185).
* `contract_id` immutable (T001 Rule 1).
* Cùng coding + cùng verifier → cùng verdict (deterministic).

### 3. Unified Coding Contract Safety

* **Fail-closed** — coding thiếu provenance → không promote (T001 Rule 5).
* **Immutable id** — `contract_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi coding có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng output (T125/T185).
* **No parallel contract** — dùng Coder Agent Contract (T125) + Coding Evaluation Contract (T185) + Evidence (T001).

### 4. Deliverables

* Unified Coding Contract (schema + session ref + evidence ref).
* Policy Boundary (T113).
* Integration với Coder Agent Contract (T125) + Coding Evaluation Contract (T185) + Evidence (T001).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — unified coding contract).

### 5. Acceptance Criteria

TASK-197 chỉ PASS khi:

* Contract định nghĩa cấu trúc coding request/response chuẩn.
* Mọi coding có provenance (T001 Rule 5).
* `contract_id` immutable (T001 Rule 1).
* Cùng input → cùng output (deterministic, T125/T185).
* Tích hợp được với Coder Agent Contract + Coding Evaluation Contract + Evidence.
* Regression của các milestone trước PASS; không vi phạm invariants.
