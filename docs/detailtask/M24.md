# M24 — Governance & Quality

M24 gồm **10 task: TASK-175 → TASK-184**. Theo roadmap sạch, chưa task nào được mặc định là đã hoàn thành.

Thứ tự chuẩn (governance + quality, xây trên verification suite M22 và adversarial M23):

1. **TASK-175 — Quality Gate + Gate States**
2. **TASK-176 — Risk Model + Classification**
3. **TASK-177 — Policy Engine + Profiles + Precedence**
4. **TASK-178 — Exception Management**
5. **TASK-179 — Quality Debt Tracking**
6. **TASK-180 — Release Gate + Decision Explainability**
7. **TASK-181 — Governance Ledger + Provenance Graph**
8. **TASK-182 — Trust Lifecycle + Invalidation + Selective Reverification**
9. **TASK-183 — Approval Workflow + Rollback Recommendation**
10. **TASK-184 — Quality Dashboard + Governance Harness**

Roadmap đặt chuỗi `T175 → T176 → T177 → T178 → T179 → T180 → T181 → T182 → T183 → T184`. M24 xây trên substrate governance của M0 (T001) + verification M22 (T155→T164) + adversarial M23 (T165→T174); các task này là lớp quản trị chất lượng và trust vòng đời.

Vì các task trong file Master Task Specification hiện đang ở dạng chuẩn hóa khá ngắn (`Objective → Scope → Deliverables → Acceptance → Dependencies`), phần chi tiết dưới đây nên bám **master plan gốc** để không tự bịa thêm scope.

### TASK-175 — Quality Gate + Gate States

Quality gate có state machine (dựa trên Lifecycle T001 Rule 6 + Verification Gate T151).

### TASK-176 — Risk Model + Classification

Mô hình rủi ro + phân loại (dựa trên Risk/Trust M9/M22).

### TASK-177 — Policy Engine + Profiles + Precedence

Policy engine + profile + precedence (dựa trên Policy T113/T138).

### TASK-178 — Exception Management

Quản lý ngoại lệ (dựa trên Lifecycle T001 + Recovery T055).

### TASK-179 — Quality Debt Tracking

Theo dõi quality debt (dựa trên Observability T021 + Evidence T001).

### TASK-180 — Release Gate + Decision Explainability

Release gate + giải thích quyết định (dựa trên Verification Gate T151 + Ledger T181).

### TASK-181 — Governance Ledger + Provenance Graph

Ledger + provenance graph (dựa trên Evidence T001 Rule 5 + Integrity T078).

### TASK-182 — Trust Lifecycle + Invalidation + Selective Reverification

Vòng đời trust + invalidation + reverification (dựa trên Trust T164/T046 + Certification T049).

### TASK-183 — Approval Workflow + Rollback Recommendation

Workflow phê duyệt + đề xuất rollback (dựa trên Permission T097 + Recovery T055).

### TASK-184 — Quality Dashboard + Governance Harness

Dashboard chất lượng + governance harness tích hợp. Task cuối của M24.
