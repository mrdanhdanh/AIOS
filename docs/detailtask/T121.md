## TASK-121 — Context Retriever

**Mục tiêu**

Triển khai **Context Retriever** như một năng lực có contract, evidence và harness riêng — truy vấn hybrid index (T120) để lấy relevant context cho agent/runtime. TASK-121 là **retriever, không phải builder mới** (dựa trên Hybrid Index T120 + Context Builder T122).

TASK-121 thuộc **M18**, ngay sau T120. Trọng tâm canonical: **Context Retriever**.

### 1. Phạm vi — Retriever, không new builder

```text
Context Retriever
├── Query                (query từ agent/runtime)
├── Hybrid Lookup        (dùng T120)
├── Relevance Rank       (rank theo relevance)
└── Policy Boundary      (T113)
```

* **Query** — nhận query (symbolic/semantic) từ agent/runtime.
* **Hybrid Lookup** — truy vấn hybrid index (T120).
* **Relevance Rank** — rank kết quả theo relevance score.
* **Policy Boundary** — retriever không lộ secret (T040/T113).

### 2. Context Retriever Contract

```text
RetrievalResult
├── query
├── hits[]               (chunk, score, content_hash)
├── retriever_id         (immutable, T001 Rule 1)
├── policy_ref           (T113)
└── evidence_ref         (T001)
```

Quy tắc:

* Mọi hit có `content_hash` (T078) + provenance (T001 Rule 5).
* Retrieval deterministic: cùng query + cùng index → cùng hits (deterministic).
* Retriever không trả secret chunk (T040/T113).
* Mọi retrieval có provenance (T001 Rule 5).

### 3. Context Retriever Safety

* **Fail-closed** — index không sẵn sàng → reject (T078).
* **Secret isolation** — không trả secret (T040/T113).
* **Evidence required** — mọi retrieval có provenance (T001 Rule 5).
* **Deterministic** — cùng query + index → cùng hits.
* **No parallel retriever** — dùng Hybrid Index (T120) + Evidence (T001) + Integrity (T078).

### 4. Deliverables

* Context Retriever (query + hybrid lookup + relevance rank).
* Policy Boundary (T113, không trả secret).
* Integration với Hybrid Index (T120) + Context Builder (T122) + Evidence (T001) + Integrity (T078).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — retriever).

### 5. Acceptance Criteria

TASK-121 chỉ PASS khi:

* Retriever truy vấn hybrid index (T120) và rank relevance.
* Mọi hit có `content_hash` (T078) + provenance (T001 Rule 5).
* Retriever không trả secret chunk (T040/T113).
* Index không sẵn sàng → reject (fail-closed, T078).
* Cùng query + index → cùng hits (deterministic).
* Tích hợp được với Hybrid Index + Context Builder + Evidence + Integrity.
* Regression của các milestone trước PASS; không vi phạm invariants.
