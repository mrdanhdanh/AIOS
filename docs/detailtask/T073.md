## TASK-073 — AIOS 1.0 Certification Suite

**Mục tiêu**

Xây dựng **Certification Suite 1.0** — bộ test/chứng nhận rằng một build AIOS 1.0 thỏa mãn mọi invariant, contract và governance gate trước khi release. TASK-073 là **certification harness, không phải feature mới** (dựa trên `aios/certification`, governance gates T001).

TASK-073 thuộc **M10 – Architecture 1.0**, ngay sau T072 (Dashboard). Trọng tâm canonical: **Certification suite**.

### 1. Phạm vi — Certification, không redesign

```text
Certification Suite 1.0
├── Governance gates      (T001: 7 rules)
├── Architecture guard   (T063: ARCH-001..004)
├── Contract conformance (T064: 1.0 contracts)
├── Harness evaluation   (T032 / T030)
└── Release certificate  (evidence-backed)
```

* **Certifier** — chạy toàn bộ gate + conformance, sinh release certificate.
* **Release gate** — chỉ release khi mọi gate PASS (fail-closed).
* **Certificate** — artifact có provenance (evidence chain).

### 2. Certification Contract

```text
ReleaseCertificate
├── version: 1.0.x
├── gates_passed: [registry, dependency, architecture, deterministic, evidence, lifecycle, regression]
├── contracts_conformed: [1.0 surfaces]
├── issued_at
└── evidence_ref
```

Quy tắc:

* Một gate FAIL → không cấp certificate (fail-closed).
* Certificate phải có provenance đầy đủ.
* Chỉ build có certificate mới được coi là "1.0 certified".

### 3. Certification Safety

* **Fail-closed release** — gate FAIL → không release.
* **Evidence required** — certificate có provenance.
* **Deterministic** — cùng build + cùng suite → cùng kết quả cert.
* **No parallel certifier** — dùng Governance gates (T001) + Harness (T032).

### 4. Deliverables

* Certification Suite (governance + architecture + contract + harness).
* Release gate (fail-closed).
* Release Certificate (evidence-backed).
* Integration với Certification (aios/certification) + Governance (T001) + Harness (T032).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — release process).

### 5. Acceptance Criteria

TASK-073 chỉ PASS khi:

* Mọi governance gate (T001) chạy trong cert suite.
* Architecture guard (T063) + contract conformance (T064) chạy.
* Một gate FAIL → không cấp certificate (fail-closed).
* Certificate có provenance đầy đủ.
* Cùng build + suite → cùng kết quả cert (deterministic).
* Tích hợp được với Certification + Governance + Harness.
* Regression của các milestone trước PASS; không vi phạm invariants.
