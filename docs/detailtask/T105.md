## TASK-105 — Independent Verification Oracle

**Mục tiêu**

Xây dựng **Independent Verification Oracle** — map các invariant có thể checkable sang independent harness oracle, và **bridge evidence từ independent harness vào AIOS verification**; **không chuyển authority khỏi AIOS policy**. TASK-105 là **oracle bridge, không phải verification engine mới** (dựa trên Foundation T104 + Harness T030/T032 + Integrity T078 + Evidence T001).

TASK-105 thuộc **M16**, ngay sau T104. Trọng tâm canonical: **Independent Verification Oracle**.

### 1. Phạm vi — Oracle bridge, không transfer authority

```text
Independent Verification Oracle
├── Oracle Adapter        (gọi independent harness oracle)
├── Invariant Mapping     (map invariant -> oracle check)
├── Evidence Bridge       (bridge evidence vào AIOS verification)
└── Authority Boundary    (AIOS policy vẫn là authoritative)
```

* **Oracle Adapter** — adapter gọi independent harness oracle để lấy verdict độc lập.
* **Invariant Mapping** — ánh xạ các invariant checkable của AIOS sang check của oracle.
* **Evidence Bridge** — đưa evidence/verdict từ oracle vào AIOS verification (qua T104 ingest boundary).
* **Authority Boundary** — verdict của oracle là input; **AIOS policy verdict mới là authoritative**.

### 2. Oracle Contract

```text
OracleResult
├── oracle_id
├── invariant_ref         (invariant được map)
├── independent_verdict   (verdict từ oracle)
├── aios_policy_verdict   (authoritative, do AIOS quyết)
├── evidence_ref          (provenance bridge)
└── authority: aios       (luôn là aios)
```

Quy tắc:

* Oracle chỉ cung cấp `independent_verdict` (input), không quyết policy.
* `aios_policy_verdict` do AIOS tính; oracle conflict không được override.
* Mọi oracle result có provenance (T001 Rule 5) qua bridge.
* Cùng invariant + cùng oracle input → cùng `independent_verdict` (deterministic).

### 3. Oracle Safety

* **AIOS authority** — oracle không có quyền policy; verdict AIOS là authoritative.
* **Fail-closed** — oracle không xác định → INCONCLUSIVE → không promote PASS (T078/T060).
* **Evidence required** — mọi bridge có provenance (T001 Rule 5).
* **Deterministic** — cùng input + cùng oracle → cùng `independent_verdict`.
* **No transfer authority** — dùng Foundation (T104) + Harness (T030/T032) + Integrity (T078).

### 4. Deliverables

* Oracle Adapter (gọi independent harness oracle).
* Invariant Mapping (invariant → oracle check).
* Evidence Bridge (vào AIOS verification, qua T104).
* Authority Boundary (AIOS policy authoritative).
* Integration với Foundation (T104) + Harness (T030/T032) + Integrity (T078) + Evidence (T001).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — authority boundary).

### 5. Acceptance Criteria

TASK-105 chỉ PASS khi:

* Oracle Adapter map được invariant sang independent harness check.
* Evidence từ oracle được bridge vào AIOS verification (qua T104).
* **AIOS giữ authority/policy boundary** — oracle conflict không override AIOS.
* Verdict oracle không xác định → INCONCLUSIVE → không promote PASS (T078).
* Mọi bridge có provenance (T001 Rule 5).
* Cùng invariant + oracle input → cùng `independent_verdict` (deterministic).
* Tích hợp được với Foundation + Harness + Integrity + Evidence.
* Regression của các milestone trước PASS; không vi phạm invariants.
