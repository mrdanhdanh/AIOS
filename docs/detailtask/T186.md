## TASK-186 — Evaluation Engine

**Mục tiêu**

Triển khai **Evaluation Engine** như một năng lực có contract, evidence và harness riêng — engine chấm điểm evaluation theo contract (T185), fail-closed. TASK-186 là **engine, không phải contract mới** (dựa trên Coding Evaluation Contract T185 + Evaluation Harness T032 + Evidence T001).

TASK-186 thuộc **M25**, ngay sau T185. Trọng tâm canonical: **Evaluation Engine**.

### 1. Phạm vi — Engine, không contract mới

```text
Evaluation Engine
├── Score                (chấm điểm theo dimension)
├── Verify               (xác minh kết quả, T032)
├── Integrity            (fail-closed, T078)
└── Policy Boundary      (T113)
```

* **Score** — chấm điểm evaluation theo dimension (T187).
* **Verify** — xác minh kết quả qua Evaluation Harness (T032).
* **Integrity** — không verify được → không promote PASS (T078).
* **Policy Boundary** — evaluation qua policy (T113).

### 2. Evaluation Engine Contract

```text
EvaluationResult
├── result_id            (immutable, T001 Rule 1)
├── contract_ref         (T185)
├── score
├── verdict              (PASS/FAIL/INCONCLUSIVE)
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Evaluation FAIL/INCONCLUSIVE → không promote PASS (fail-closed, T078).
* Mọi result có provenance (T001 Rule 5).
* Evaluation deterministic: cùng input → cùng score.
* Evaluation không lộ secret (T040/T113).

### 3. Evaluation Engine Safety

* **Fail-closed** — INCONCLUSIVE → không promote PASS (T078).
* **Immutable id** — `result_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi result có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng score.
* **No parallel engine** — dùng Coding Evaluation Contract (T185) + Evaluation Harness (T032) + Evidence (T001).
