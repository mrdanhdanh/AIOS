## TASK-161 — Performance Verifier

**Mục tiêu**

Triển khai **Performance Verifier** như một năng lực có contract, evidence và harness riêng — xác minh hiệu năng (latency/throughput/cost) của output, fail-closed. TASK-161 là **performance verifier, không phải profiler mới** (dựa trên Requirement→Evidence Mapping T155 + Observability T021 + Performance/Cost T075 + Verification Engine T142 + Evidence T001).

TASK-161 thuộc **M22**, ngay sau T160. Trọng tâm canonical: **Performance Verifier**.

### 1. Phạm vi — Performance verifier, không profiler mới

```text
Performance Verifier
├── Metric Collect       (thu metric hiệu năng, T021)
├── Threshold            (ngưỡng SLA, T075)
├── Verdict              (PASS/FAIL/INCONCLUSIVE)
└── Policy Boundary      (T113)
```

* **Metric Collect** — thu metric hiệu năng từ Observability (T021).
* **Threshold** — so sánh với ngưỡng SLA (T075).
* **Verdict** — vượt ngưỡng → FAIL (fail-closed).
* **Policy Boundary** — verification qua policy (T113).

### 2. Performance Verifier Contract

```text
PerformanceResult
├── result_id            (immutable, T001 Rule 1)
├── map_ref              (T155)
├── metrics_ref          (T021)
├── threshold_ref        (T075)
├── verdict              (PASS/FAIL/INCONCLUSIVE)
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Vượt ngưỡng hiệu năng → FAIL (fail-closed, T078/T075).
* Mọi result có provenance (T001 Rule 5).
* Verification deterministic: cùng input → cùng verdict.
* Metric không lộ secret (T040/T113).

### 3. Performance Verifier Safety

* **Fail-closed** — vượt ngưỡng → FAIL (T078/T075).
* **Immutable id** — `result_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi result có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng verdict.
* **No parallel verifier** — dùng Requirement→Evidence (T155) + Observability (T021) + Performance/Cost (T075) + Verification Engine (T142) + Evidence (T001).
