## TASK-059 — Multi-Agent Autonomy

**Mục tiêu**

Xây dựng **delegation layer trên Orchestrator/Runtime hiện hữu** — cho phép một agent tự chủ **delegate** (ủy quyền) các sub-goal cho agent/capability khác để phối hợp hoàn thành goal phức tạp, với **authority attenuation đa chiều, bounded resources, scope isolation, delegation provenance và fail-closed recovery**.

> **TASK-059 không phải một "multi-agent framework" hay control plane thứ hai.** Canonical master spec chỉ xác định *"Delegation giữa agent"*. Do đó bản spec này là **delegation capability mở rộng Orchestrator hiện có** (Agent Selector / Capability Router / Execution Supervisor), không tạo `Delegation Controller/Broker` thành một mini control plane.

TASK-059 thuộc **M9 – Autonomous**, nằm cuối chuỗi M9 (sau T050–T058). Liên quan chặt chẽ đến invariant **INV-034 (No Unverified Promote)**, Evidence-First, Policy-First và nguyên tắc **no parallel control plane**.

### 1. Phạm vi — Delegation là capability của Orchestrator

```text
Parent Goal
    ↓
Autonomous Planner / Goal Engine (T050/T051)
    ↓
Delegation Decision
    ↓
Autonomy Governor (T054)
    ↓
Agent Selector / Capability Router (Orchestrator hiện có)
    ↓
Runtime
    ↓
Child Agent (tuân thủ Agent→Capability→Runtime→Tool)
```

**Không có** (để giữ invariant no-parallel-control-plane):

```text
Delegation Controller (mini control plane)
Delegation Broker (định tuyến độc lập)
Child Executor (execution primitive riêng)
```

Các thành phần (tất cả là capability/interface trên Orchestrator/Runtime hiện có):

* **Delegation Decision** — quyết định có ủy quyền sub-goal nào, với authority đã attenuate.
* **Authority Attenuator** — tính authority của child = `Parent Authority ∩ Delegation Scope ∩ Current Policy ∩ Resource Budget`.
* **Agent Selector / Capability Router** — reuse Orchestrator hiện có để chọn child.
* **Result Aggregator** — thu thập kết quả + evidence, parent chịu trách nhiệm.

### 2. Authority Model — attenuation đa chiều (thay vì scalar budget)

`autonomy_budget` scalar là **chưa đủ** và dễ gây **authority amplification**. Thay vào đó:

```text
Child Authority ⊆ Parent Authority
                 ∩ Delegation Scope
                 ∩ Current Policy
                 ∩ Resource Budget
```

Ít nhất phải tách các authority dimensions:

* **action/capability scope** — capability nào được gọi.
* **resource budget** — token/cost/time tối đa.
* **time/deadline** — hạn hoàn thành.
* **tenant/project/workspace scope** — boundary không được vượt.
* **tool/network permission** — quyền tool/network cụ thể.
* **approval requirement** — ngưỡng nào cần human approval.
* **delegation depth** — độ sâu ủy quyền tối đa.
* **risk level** — mức rủi ro cho phép.

Quy tắc:

* `Child authority = attenuate(Parent authority, delegation_scope, policy, budget)` — **không kế thừa nguyên vẹn**.
* Child **không được tự thay đổi authority của chính nó**.
* Nếu child cần thêm quyền → **request authority extension** → Parent/Governor đánh giá → Policy: `ALLOW | DENY | ASK_HUMAN`.

### 3. Delegation Chain & Anti-Amplification

```text
A authority
   ↓ attenuation
B authority
   ↓ attenuation
C authority
```

Phải phân biệt 3 loại budget để chống **resource explosion / authority amplification**:

* **execution budget** — resource cho chạy child.
* **delegation budget** — quota ủy quyền tiếp cho downstream.
* **authority budget** — quyền hạn được cấp.

Ràng buộc:

* Tổng quyền/chi phí downstream **không vượt** commitment parent được cấp.
* Ví dụ: Parent token = 10k; A = 6k, B = 4k → A **không thể** delegate thêm 6k nếu delegation budget đã cạn.
* `delegation depth exceeded` → BLOCK. `child count exceeded` → BLOCK. `cumulative resource exceeded` → BLOCK.

### 4. Delegation Protocol

```text
DelegateRequest
├── parent_goal_id
├── sub_goal
├── attenuated_authority      # đa chiều, đã ∩ với scope/policy/budget
├── delegation_budget         # quota ủy quyền tiếp
├── execution_budget          # resource cho child
├── max_depth / max_children
└── evidence_ref

DelegateResponse
├── child_agent_id
├── sub_goal_result
├── authority_used
├── resource_used
└── evidence_ref
```

Quy tắc:

* Child chỉ được dùng authority nằm trong `attenuated_authority`.
* Child request extension → Governor/Policy quyết định (không tự nâng).
* Mọi delegation qua Capability/Runtime interface — không peer-to-peer control.

### 5. Delegation Provenance Chain

Không chỉ `child evidence → parent`, mà phải replay/audit được toàn bộ:

```text
Parent Goal
   ↓
Delegation Request
   ↓
Child Goal
   ↓
Child Execution
   ↓
Child Evidence
   ↓
Child Verdict
   ↓
Parent Aggregation
   ↓
Parent Outcome
```

Truy ngược được qua `Evidence → Run → Artifact → Task → Requirement` (canonical Evidence Store). Phải trả lời: parent giao việc vì sao, child được cấp quyền gì, child dùng quyền gì, kết quả nào dẫn tới parent verdict.

### 6. Child Architecture Boundary

Child vẫn tuân thủ strict layering:

```text
Agent → Capability → Runtime → Tool
```

AC kiến trúc phải kiểm tra:

```text
Child Agent
  X → direct Runtime
  X → direct Tool
  X → direct Provider
  X → direct Filesystem
  ✓ → Capability / Runtime contract
```

(ARCH-001/002/003/004 — child không được gọi provider/tool/FS trực tiếp.)

### 7. Coordination Safety & Bounded Recovery

* **No parallel control plane** — Delegation là capability của Orchestrator hiện có.
* **Governor authority** — delegation bị giới hạn bởi Autonomy Governor (T054); vượt authority/budget → BLOCK.
* **Bounded recovery** — child thất bại → Recovery policy (T055) tại parent scope, nhưng **không retry/delegate vô hạn**:
  * max delegation depth, max child count, max retries, max cumulative cost, max execution time, max concurrent children.
  * Recovery options: `retry child | fallback child | replan | abort parent | ask human`.
* **Fail-closed** — child evidence thiếu → parent verdict `≠ PASS`; parent cancelled → descendants cancelled/terminated.
* **No bypass** — mọi thứ qua Capability.

* Autonomy-gated delegation (T054).

### 9. Acceptance Criteria

TASK-059 chỉ PASS khi:

* Delegation tạo sub-goal có scope rõ ràng, authority đã attenuate (không kế thừa nguyên vẹn).
* Child authority ⊆ Parent ∩ Scope ∩ Policy ∩ Budget (đa chiều).
* Child authority = parent → chỉ được nếu scope được delegate rõ ràng.
* Child authority > parent → **BLOCK**.
* Child request thêm authority → Governor/Policy → ALLOW/DENY/ASK_HUMAN (không tự nâng).
* Grandchild delegation → authority phải attenuate tiếp.
* Delegation depth / child count / delegation budget / cumulative resource vượt → **BLOCK**.
* Parent chịu trách nhiệm cuối cùng (accountable outcome).
* Delegation qua Capability/Runtime, **không** direct control.
* Child **không** direct Runtime/Tool/Provider/Filesystem (Architecture FAIL nếu vi phạm).
* Cross-project/tenant delegation → DENY nếu scope không cho phép.
* Delegation provenance chain truy ngược được (Evidence→Run→Artifact→Task→Requirement).
* Child failure → bounded recovery (T055), không retry/delegate vô hạn.
* Parent cancelled → descendants cancelled/terminated.
* Parent checkpoint/resume → delegation state recoverable (T056).
* Duplicate delegation → idempotency handling; concurrent children → aggregate deterministic.
* Không tạo autonomous control plane thứ hai.
* Regression của các milestone trước PASS.
* Không vi phạm architecture invariants.
