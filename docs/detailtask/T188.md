## TASK-188 — Benchmark Registry

**Mục tiêu**

Triển khai **Benchmark Registry** như một năng lực có contract, evidence và harness riêng — đăng ký benchmark có id immutable, deterministic. TASK-188 là **registry, không phải benchmark mới** (dựa trên Quality Dimensions T187 + Benchmark/Regression T033 + Coding Evaluation Contract T185 + Evidence T001).

TASK-188 thuộc **M25**, ngay sau T187. Trọng tâm canonical: **Benchmark Registry**.

### 1. Phạm vi — Registry, không benchmark mới

```text
Benchmark Registry
├── Register             (đăng ký benchmark có id)
├── Resolve              (resolve version)
├── Dimension Link       (link dimension, T187)
└── Policy Boundary      (T113)
```

* **Register** — đăng ký benchmark có id immutable (T001 Rule 1).
* **Resolve** — resolve version benchmark (deterministic).
* **Dimension Link** — link benchmark tới dimension (T187).
* **Policy Boundary** — registry qua policy (T113).

### 2. Benchmark Registry Contract

```text
BenchmarkRegistry
├── bench_id             (immutable, T001 Rule 1)
├── dim_ref              (T187)
├── version
├── checksum
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Mọi benchmark có provenance (T001 Rule 5).
* Registry deterministic: cùng id → cùng version/checksum.
* `bench_id` immutable (T001 Rule 1).
* Benchmark không vượt policy boundary (T113).

### 3. Benchmark Registry Safety

* **Fail-closed** — benchmark thiếu provenance → không ghi nhận (T001 Rule 5).
* **Immutable id** — `bench_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi benchmark có provenance (T001 Rule 5).
* **Deterministic** — cùng id → cùng version/checksum.
* **No parallel registry** — dùng Quality Dimensions (T187) + Benchmark/Regression (T033) + Coding Evaluation Contract (T185) + Evidence (T001).

### 4. Deliverables

* Benchmark Registry (register + resolve + dimension link).
* Policy Boundary (T113).
* Integration với Quality Dimensions (T187) + Benchmark/Regression (T033) + Coding Evaluation Contract (T185) + Evidence (T001).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — benchmark registry).

### 5. Acceptance Criteria

TASK-188 chỉ PASS khi:

* Benchmark đăng ký có id immutable (T001 Rule 1).
* Resolve version deterministic.
* Mọi benchmark có provenance (T001 Rule 5).
* Link được tới dimension (T187).
* Tích hợp được với Quality Dimensions + Benchmark/Regression + Coding Evaluation Contract + Evidence.
* Regression của các milestone trước PASS; không vi phạm invariants.
