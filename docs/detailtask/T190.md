## TASK-190 — Regression Detector

**Mục tiêu**

Triển khai **Regression Detector** như một năng lực có contract, evidence và harness riêng — phát hiện regression so với baseline (T189), fail-closed. TASK-190 là **detector, không phải baseline mới** (dựa trên Baseline Manager T189 + Regression Verifier T159 + Benchmark/Regression T033 + Evidence T001).

TASK-190 thuộc **M25**, ngay sau T189. Trọng tâm canonical: **Regression Detector**.

### 1. Phạm vi — Detector, không baseline mới

```text
Regression Detector
├── Compare              (so sánh với baseline, T189)
├── Regression Flag      (phát hiện regression)
├── Verdict              (PASS/FAIL)
└── Policy Boundary      (T113)
```

* **Compare** — so sánh evaluation với baseline (T189).
* **Regression Flag** — regression phát hiện → FAIL (fail-closed).
* **Verdict** — tổng hợp verdict.
* **Policy Boundary** — detection qua policy (T113).

### 2. Regression Detector Contract

```text
RegressionDetect
├── detect_id            (immutable, T001 Rule 1)
├── baseline_ref         (T189)
├── verdict              (PASS/FAIL)
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Regression phát hiện → FAIL (fail-closed, T078/T159/T033).
* Mọi detect có provenance (T001 Rule 5).
* Detection deterministic: cùng input → cùng verdict.
* Baseline từ T189 — không tự sinh ngoài baseline.

### 3. Regression Detector Safety

* **Fail-closed** — regression → FAIL (T078/T159/T033).
* **Immutable id** — `detect_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi detect có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng verdict.
* **No parallel detector** — dùng Baseline Manager (T189) + Regression Verifier (T159) + Benchmark/Regression (T033) + Evidence (T001).

### 4. Deliverables

* Regression Detector (compare + flag + verdict).
* Policy Boundary (T113).
* Integration với Baseline Manager (T189) + Regression Verifier (T159) + Benchmark/Regression (T033) + Evidence (T001).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — regression detector).
