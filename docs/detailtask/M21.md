# M21 — Autonomous Coding Loop

M21 gồm **10 task: TASK-145 → TASK-154**. Theo roadmap sạch, chưa task nào được mặc định là đã hoàn thành.

Thứ tự chuẩn (coding loop tuần tự — observe → classify → diagnose → repair → verify → refresh → safety → harness):

1. **TASK-145 — Coding Loop State Machine**
2. **TASK-146 — Execution Observation**
3. **TASK-147 — Failure Classification**
4. **TASK-148 — Diagnostic Agent**
5. **TASK-149 — Repair Planner**
6. **TASK-150 — Progress + Regression Detection**
7. **TASK-151 — Verification Gate**
8. **TASK-152 — Context Refresh + Patch Chain**
9. **TASK-153 — Autonomous Safety Controller**
10. **TASK-154 — Autonomous Coding Harness**

Roadmap đặt chuỗi `T145 → T146 → T147 → T148 → T149 → T150 → T151 → T152 → T153 → T154`. M21 xây trên substrate execution của M20 (T135→T144) và autonomous core của M9 (T050→T062).

Vì các task trong file Master Task Specification hiện đang ở dạng chuẩn hóa khá ngắn (`Objective → Scope → Deliverables → Acceptance → Dependencies`), phần chi tiết dưới đây nên bám **master plan gốc** để không tự bịa thêm scope.

### TASK-145 — Coding Loop State Machine

Điều khiển vòng lặp coding tự chủ qua một state machine xác định, fail-closed. Nền tảng của M21; mọi task sau (T146→T154) là các bước của loop này.

### TASK-146 — Execution Observation

Quan sát execution trace/event trong suốt loop (dựa trên Execution Contract T135 + Collector T141) để làm input cho classification.

### TASK-147 — Failure Classification

Phân loại failure từ observation (T146) theo taxonomy xác định, deterministic.

### TASK-148 — Diagnostic Agent

Chẩn đoán root cause từ failure đã classify (T147) + observation (T146); sinh diagnostic report.

### TASK-149 — Repair Planner

Lập kế hoạch repair (patch) từ diagnosis (T148), dùng Planning Engine T026 + Autonomous Recovery T055.

### TASK-150 — Progress + Regression Detection

Phát hiện tiến độ và regression của loop (T149) dựa trên Benchmark/Regression T033 + Autonomous Recovery T055.

### TASK-151 — Verification Gate

Xác minh output của loop trước khi promote PASS (dựa trên Verification Engine T142 + Integrity T078), fail-closed.

### TASK-152 — Context Refresh + Patch Chain

Làm mới context (Context Optimizer T024) và chuỗi hóa patch (Workspace/Snapshot T137) giữa các vòng lặp.

### TASK-153 — Autonomous Safety Controller

Đặt boundary/an toàn cho coding tự chủ (Autonomy Safety T067 + Kill Switch T068) — giới hạn blast radius.

### TASK-154 — Autonomous Coding Harness

Harness tích hợp toàn bộ loop (T145→T153) trên nền Harness Kernel T029 + Test Harness T031 + Evaluation Harness T032. Task cuối của M21.
