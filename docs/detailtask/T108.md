## TASK-108 — Management Console / Independent Harness Integration

**Mục tiêu**

Xây dựng **Management Console Integration cho Independent Harness** — tích hợp independent harness vào management console để operator có thể xem/quản lý independent verification mà không phá Core. TASK-108 là **console integration, không phải feature mới** (dựa trên Oracle T105 + Foundation T104 + Bridges T106/T107 + Enterprise Ops/Dashboard T042/T072/T018).

TASK-108 thuộc **M16**, ngay sau T106/T107. Trọng tâm canonical: **Management Console / Independent Harness Integration**. Đây là task cuối của M16.

### 1. Phạm vi — Console integration, không new feature

```text
Management Console / Independent Harness Integration
├── Console Contract       (view independent harness status)
├── Harness Status View    (tổng hợp verdict từ T105/T106/T107)
├── Operator Action Boundary (action qua API/runtime, policy-gated)
└── Policy Authority       (AIOS policy authoritative)
```

* **Console Contract** — định nghĩa view trạng thái independent harness cho operator.
* **Harness Status View** — tổng hợp verdict từ Oracle (T105) + Behavioral (T106) + Permission/Sandbox (T107).
* **Operator Action Boundary** — mọi action operator đi qua API/runtime, không bypass policy.
* **Policy Authority** — AIOS giữ authority; console chỉ hiển thị/điều phối qua policy.

### 2. Console Integration Contract

```text
ConsoleHarnessView
├── console_id
├── harness_status          (tổng hợp từ T105/T106/T107)
├── independent_results_summary
├── aios_authority_flag     (luôn aios)
├── operator_action         (view-only / policy-gated)
└── evidence_ref            (provenance)
```

Quy tắc:

* Console chỉ hiển thị; action operator phải qua API/runtime (T017/T018).
* `aios_authority_flag` luôn `aios`; console không quyết policy.
* Mọi view có provenance (T001 Rule 5).
* Cùng harness state → cùng view (deterministic).

### 3. Console Integration Safety

* **AIOS authority** — console không quyết policy; action qua API/runtime.
* **Fail-closed** — verdict không xác định → không promote PASS (T078).
* **Evidence required** — mọi view có provenance (T001 Rule 5).
* **Deterministic** — cùng state → cùng view.
* **No parallel console system** — dùng Oracle (T105) + Foundation (T104) + Bridges (T106/T107) + Dashboard (T042/T072/T018).
