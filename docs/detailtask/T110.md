## TASK-110 — Provider Registry + Lifecycle

**Mục tiêu**

Triển khai **Provider Registry + Lifecycle** như một năng lực có contract, evidence và harness riêng — đăng ký provider (Mock/OpenAI/Ollama…) qua contract, quản lý lifecycle (register/enable/disable/deprecate) mà không khóa AIOS vào một vendor. TASK-110 là **registry + lifecycle, không phải adapter mới** (dựa trên Model Contract T109 + Model Contract + Provider Registry T006).

TASK-110 thuộc **M17**, ngay sau T109. Trọng tâm canonical: **Provider Registry + Lifecycle**.

### 1. Phạm vi — Registry + lifecycle, không new adapter

```text
Provider Registry + Lifecycle
├── Registry              (đăng ký provider qua contract)
├── Lifecycle             (register/enable/disable/deprecate)
├── Health                (healthcheck provider)
└── Policy Boundary       (T113)
```

* **Registry** — đăng ký provider với `provider_id` immutable (T001 Rule 1).
* **Lifecycle** — quản lý trạng thái provider (register/enable/disable/deprecate).
* **Health** — healthcheck provider; provider unhealthy → không chọn (T025).
* **Policy Boundary** — chọn provider phải qua policy (T113).

### 2. Provider Registry Contract

```text
ProviderRecord
├── provider_id           (immutable, T001 Rule 1)
├── model_contract_ref    (T109)
├── status                (registered/enabled/disabled/deprecated)
├── health                (healthy/unhealthy)
├── lifecycle_event_log
└── policy_ref            (T113)
```

Quy tắc:

* `provider_id` immutable; không cho trùng/tái sử dụng (T001 Rule 1).
* Provider sai → `deprecated`, không xóa rồi tái sử dụng id.
* Provider unhealthy → không được chọn (T025).
* Mọi lifecycle event có provenance (T001 Rule 5).

### 3. Provider Registry Safety

* **Fail-closed** — provider không hợp lệ → reject (T078).
* **Immutable id** — `provider_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi event có provenance (T001 Rule 5).
* **Deterministic** — cùng registry state → cùng selection.
* **No vendor lock** — provider thay thế qua contract (T109).
* **Policy boundary** — dùng Permission/Policy (T113) + Model Router (T025).

### 4. Deliverables
