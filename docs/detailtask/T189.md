## TASK-189 — Baseline Manager

**Mục tiêu**

Triển khai **Baseline Manager** như một năng lực có contract, evidence và harness riêng — quản lý baseline benchmark có version, deterministic. TASK-189 là **baseline manager, không phải registry mới** (dựa trên Benchmark Registry T188 + Benchmark/Regression T033 + Evidence T001).

TASK-189 thuộc **M25**, ngay sau T188. Trọng tâm canonical: **Baseline Manager**.

### 1. Phạm vi — Baseline manager, không registry mới

```text
Baseline Manager
├── Set Baseline         (thiết lập baseline)
├── Snapshot             (snapshot baseline)
├── Compare              (so sánh với baseline)
└── Policy Boundary      (T113)
```

* **Set Baseline** — thiết lập baseline từ benchmark (T188).
* **Snapshot** — snapshot baseline có version.
* **Compare** — so sánh evaluation với baseline.
* **Policy Boundary** — manager qua policy (T113).

### 2. Baseline Manager Contract

```text
BaselineManager
├── baseline_id          (immutable, T001 Rule 1)
├── bench_ref            (T188)
├── version
├── snapshot_ref
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Mọi baseline có provenance (T001 Rule 5).
* Baseline deterministic: cùng input → cùng snapshot.
* `baseline_id` immutable (T001 Rule 1).
* Baseline không vượt policy boundary (T113).

### 3. Baseline Manager Safety

* **Fail-closed** — baseline thiếu provenance → không ghi nhận (T001 Rule 5).
* **Immutable id** — `baseline_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi baseline có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng snapshot.
* **No parallel manager** — dùng Benchmark Registry (T188) + Benchmark/Regression (T033) + Evidence (T001).

### 4. Deliverables

* Baseline Manager (set + snapshot + compare).
* Policy Boundary (T113).
* Integration với Benchmark Registry (T188) + Benchmark/Regression (T033) + Evidence (T001).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — baseline manager).

### 5. Acceptance Criteria

TASK-189 chỉ PASS khi:

* Baseline thiết lập được từ benchmark (T188).
* Snapshot baseline có version.
* Mọi baseline có provenance (T001 Rule 5).
* Cùng input → cùng snapshot (deterministic).
* Tích hợp được với Benchmark Registry + Benchmark/Regression + Evidence.
* Regression của các milestone trước PASS; không vi phạm invariants.
