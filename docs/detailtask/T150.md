## TASK-150 — Progress + Regression Detection

**Mục tiêu**

Triển khai **Progress + Regression Detection** như một năng lực có contract, evidence và harness riêng — phát hiện tiến độ và regression của loop (T149) dựa trên Benchmark/Regression (T033) + Autonomous Recovery (T055). TASK-150 là **detector, không phải verifier mới** (dựa trên Repair Planner T149 + Benchmark/Regression T033 + Autonomous Recovery T055 + Evidence T001).

TASK-150 thuộc **M21**, ngay sau T149. Trọng tâm canonical: **Progress + Regression Detection**.

### 1. Phạm vi — Detector, không verifier mới

```text
Progress + Regression Detection
├── Progress             (đo tiến độ loop)
├── Regression           (phát hiện regression)
├── Baseline             (baseline từ T033)
└── Policy Boundary      (T113)
```

* **Progress** — đo tiến độ loop qua các bước (T145→T149).
* **Regression** — phát hiện regression so với baseline (T033).
* **Baseline** — baseline lấy từ Benchmark/Regression (T033).
* **Policy Boundary** — detection qua policy (T113).

### 2. Progress + Regression Detection Contract

```text
ProgressReport
├── report_id           (immutable, T001 Rule 1)
├── loop_ref            (T145)
├── plan_ref            (T149)
├── progress_metric
├── regression_flag     (bool)
├── evidence_ref        (T001)
└── authority: aios
```

Quy tắc:

* Regression phát hiện → loop quay lại repair (T149) hoặc stop (T055).
* Mọi report có provenance (T001 Rule 5).
* Detection deterministic: cùng state → cùng verdict.
* Baseline từ T033 — không tự sinh ngoài baseline.

### 3. Progress + Regression Detection Safety

* **Fail-closed** — regression không phát hiện → không promote PASS (T033).
* **Immutable id** — `report_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi report có provenance (T001 Rule 5).
* **Deterministic** — cùng state → cùng verdict.
* **No parallel detector** — dùng Repair Planner (T149) + Benchmark/Regression (T033) + Recovery (T055) + Evidence (T001).

### 4. Deliverables

* Progress + Regression Detection (progress + regression + baseline).
* Policy Boundary (T113).
* Integration với Repair Planner (T149) + Benchmark/Regression (T033) + Autonomous Recovery (T055) + Evidence (T001).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — progress + regression detection).

### 5. Acceptance Criteria

TASK-150 chỉ PASS khi:

* Detection đo được tiến độ loop (T145→T149).
* Regression phát hiện được so với baseline (T033).
* Mọi report có provenance (T001 Rule 5).
* Cùng state → cùng verdict (deterministic).
* Regression → loop quay lại repair/stop (T055).
* Tích hợp được với Repair Planner + Benchmark/Regression + Autonomous Recovery + Evidence.
* Regression của các milestone trước PASS; không vi phạm invariants.
