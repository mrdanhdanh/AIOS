## TASK-214 — Release Gate

**Mục tiêu**

Triển khai **Release Gate** như một năng lực có contract, evidence và harness riêng — gate phát hành coding tổng hợp, fail-closed. TASK-214 là **release gate, không phải quality gate mới** (dựa trên Coding Health Score T213 + Release Gate T180 + Quality Gate T175 + Evidence T001).

TASK-214 thuộc **M26**, ngay sau T213. Trọng tâm canonical: **Release Gate**.

### 2. Release Gate Contract

```text
CodingRelease
├── release_id           (immutable, T001 Rule 1)

├── quality_ref          (T175)
├── verdict              (ALLOW/DENY)
├── evidence_ref         (T001)
```

Quy tắc:

* Quality gate BLOCKED / health fail → DENY (fail-closed, T078/T175/T213).
* Mọi quyết định có provenance (T001 Rule 5).
* Decision deterministic: cùng input → cùng verdict.
* Gate không vượt policy boundary (T113).

### 3. Release Gate Safety

* **Fail-closed** — gate BLOCKED → DENY (T078/T175).
* **Immutable id** — `release_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi quyết định có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng verdict.
* **No parallel gate** — dùng Coding Health Score (T213) + Release Gate (T180) + Quality Gate (T175) + Evidence (T001).

### 4. Deliverables
