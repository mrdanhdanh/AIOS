# M22 — Verification Suite

M22 gồm **10 task: TASK-155 → TASK-164**. Theo roadmap sạch, chưa task nào được mặc định là đã hoàn thành.

Thứ tự chuẩn (các verifier độc lập, cùng xây trên substrate evidence/verification của M20 và coding loop của M21):

1. **TASK-155 — Requirement → Evidence Mapping**
2. **TASK-156 — Test Adequacy Analyzer + Mutation Verifier**
3. **TASK-157 — Behavioral Verifier**
4. **TASK-158 — Contract Verifier**
5. **TASK-159 — Regression Verifier**
6. **TASK-160 — Security Verifier**
7. **TASK-161 — Performance Verifier**
8. **TASK-162 — Replay & Flaky Detector**
9. **TASK-163 — Evidence Collector + Evidence Integrity**
10. **TASK-164 — Trust Evaluator + CodingCertificate + Verification Harness**

Roadmap đặt chuỗi `T155 → T156 → T157 → T158 → T159 → T160 → T161 → T162 → T163 → T164`. M22 xây trên substrate verification của M20 (T135→T144) và coding loop của M21 (T145→T154); các verifier này là năng lực mà Verification Gate (T151) và Autonomous Coding Harness (T154) sử dụng.

Vì các task trong file Master Task Specification hiện đang ở dạng chuẩn hóa khá ngắn (`Objective → Scope → Deliverables → Acceptance → Dependencies`), phần chi tiết dưới đây nên bám **master plan gốc** để không tự bịa thêm scope.

### TASK-155 — Requirement → Evidence Mapping

Ánh xạ requirement → evidence (T001 Rule 5 + T144), làm nền cho mọi verifier sau xác minh coverage.

### TASK-156 — Test Adequacy Analyzer + Mutation Verifier

Đo độ phủ test và mutation score (dựa trên Test Harness T031 + Verification Engine T142).

### TASK-157 — Behavioral Verifier

Xác minh hành vi (dựa trên Evaluation Harness T032 + Behavioral).

### TASK-158 — Contract Verifier

Xác minh contract (dựa trên Execution Contract T135 + Contract Freeze T064).

### TASK-159 — Regression Verifier

Xác minh regression (dựa trên Benchmark/Regression T033).

### TASK-160 — Security Verifier

Xác minh bảo mật (dựa trên Security/Replay T143 + Security Baseline T070).

### TASK-161 — Performance Verifier

Xác minh hiệu năng (dựa trên Observability T021 + Performance/Cost T075).

### TASK-162 — Replay & Flaky Detector

Phát hiện replay non-determinism và flaky (dựa trên Replay T030/T079).

### TASK-163 — Evidence Collector + Evidence Integrity

Thu thập evidence + integrity (dựa trên Collector T141 + Integrity T078 + Evidence T001).

### TASK-164 — Trust Evaluator + CodingCertificate + Verification Harness

Đánh giá trust + cấp certificate + harness tích hợp (dựa trên Certification T049 + Ecosystem Trust T046 + Verification T142). Task cuối của M22.
