## TASK-072 — AIOS Dashboard 1.0

**Mục tiêu**

Phát hành **Dashboard 1.0** — giao diện quan sát (observability) và vận hành AIOS: health, goals, loops, autonomy state, evidence và alerts. TASK-072 là **observability UI, không phải control plane mới** (dựa trên `aios/dashboard`, `aios/observability`).

TASK-072 thuộc **M10 – Architecture 1.0**, ngay sau T071 (DX). Trọng tâm canonical: **Dashboard release**.

### 1. Phạm vi — Observability UI, không control

```text
Dashboard 1.0
├── Health view          (aios/core/healthcheck)
├── Goal / Loop view     (T050 / T053)
├── Autonomy state       (T067 / T054)
├── Evidence view        (governance/evidence)
└── Alerts               (T061 / T068 / T069)
```

* **Read-only by default** — dashboard quan sát, không tự thay đổi state (kill switch vẫn qua cơ chế riêng T068).
* **Health view** — tổng hợp health các component (T065/T069).
* **Goal/Loop view** — tiến triển goal/loop đang chạy.
* **Evidence view** — provenance chain có thể truy tra.

### 2. Dashboard Contract

```text
DashboardView
├── view: HEALTH | GOALS | AUTONOMY | EVIDENCE | ALERTS
├── data_source (read-only)
├── refresh
└── evidence_ref
```

Quy tắc:

* Dashboard chỉ đọc (read-only) — mọi action qua API/CLI có auth (T070).
* Mọi hiển thị phải trace được về evidence (provenance).
* Không hiển thị secret (T070).

### 3. Dashboard Safety

* **Read-only** — dashboard không tự mutate state (fail-closed nếu cố).
* **Auth required** — truy cập qua auth (T070).
* **No secret leak** — không hiển thị secret.
* **Deterministic** — cùng data source + cùng view → cùng render.
* **No parallel control plane** — dùng Observability + API (read).

### 4. Deliverables

* Dashboard 1.0 (health/goals/autonomy/evidence/alerts).
* Read-only views (action qua API/CLI auth).
* Evidence traceability trong UI.
* Integration với Dashboard (aios/dashboard) + Observability + API (T070).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — release).
