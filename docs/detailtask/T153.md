### 3. Autonomous Safety Controller Safety

* **Fail-closed** — vi phạm boundary → kill switch (T068).
* **Immutable id** — `decision_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi decision có provenance (T001 Rule 5).
* **Deterministic** — cùng state → cùng decision.
* **No parallel controller** — dùng Context Refresh (T152) + Autonomy Safety (T067) + Kill Switch (T068) + Evidence (T001).
