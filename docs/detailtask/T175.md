## TASK-175 — Quality Gate + Gate States

**Mục tiêu**

Triển khai **Quality Gate + Gate States** như một năng lực có contract, evidence và harness riêng — quality gate có state machine xác định, fail-closed, tổng hợp verdict từ verification suite (T155→T164). TASK-175 là **gate + states, không phải verifier mới** (dựa trên Lifecycle T001 Rule 6 + Verification Gate T151 + Trust Evaluator T164 + Evidence T001).

TASK-175 thuộc **M24**, là task nền tảng của milestone. Trọng tâm canonical: **Quality Gate + Gate States**.

### 1. Phạm vi — Gate + states, không verifier mới

```text
Quality Gate + Gate States
├── Gate States          (OPEN→EVALUATING→PASS/FAIL/BLOCKED)
├── Aggregate            (tổng hợp verdict từ T155→T164)
├── Fail-Closed          (bất kỳ FAIL → BLOCKED)
└── Policy Boundary      (T113)
```

* **Gate States** — state machine gate theo Lifecycle (T001 Rule 6).
* **Aggregate** — tổng hợp verdict từ các verifier (T155→T164).
* **Fail-Closed** — bất kỳ verifier FAIL/INCONCLUSIVE → BLOCKED (T078/T151).
* **Policy Boundary** — gate qua policy (T113).

### 2. Quality Gate + Gate States Contract

```text
QualityGate
├── gate_id              (immutable, T001 Rule 1)
├── verifier_refs[]      (T155→T164)
├── state                (OPEN/EVALUATING/PASS/FAIL/BLOCKED)
├── aggregated_verdict   (PASS/FAIL/BLOCKED)
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Bất kỳ verifier FAIL/INCONCLUSIVE → gate BLOCKED (fail-closed, T078/T151).
* Mọi transition có provenance (T001 Rule 5).
* Gate deterministic: cùng input → cùng verdict.
* Gate không vượt policy boundary (T113).

### 3. Quality Gate + Gate States Safety

* **Fail-closed** — verifier fail → BLOCKED (T078/T151).
* **Immutable id** — `gate_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi transition có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng verdict.
* **No parallel gate** — dùng Lifecycle (T001) + Verification Gate (T151) + Trust Evaluator (T164) + Evidence (T001).
