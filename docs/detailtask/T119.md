## TASK-119 — Dependency Graph

**Mục tiêu**

Triển khai **Dependency Graph** như một năng lực có contract, evidence và harness riêng — xây đồ thị dependency (import/require/call) giữa modules/symbols để phân tích tác động. TASK-119 là **dependency graph, không phải registry mới** (dựa trên Repository Scanner T117 + Source/Symbol Index T118 + Dependency Graph Governance T001 Rule 2).

TASK-119 thuộc **M18**, ngay sau T117. Trọng tâm canonical: **Dependency Graph**.

### 1. Phạm vi — Dependency graph, không new registry

```text
Dependency Graph
├── Edge Extraction      (import/require/call edges)
├── Graph Store          (node + edge + metadata)
├── Cycle Detection      (phát hiện cycle, BLOCK)
└── Policy Boundary      (T113)
```

* **Edge Extraction** — trích cạnh dependency từ source (import/require/call).
* **Graph Store** — lưu node (module/symbol) + edge (kind, target).
* **Cycle Detection** — phát hiện cycle → BLOCK (T001 Rule 2).
* **Policy Boundary** — graph không lộ secret (T040/T113).

### 2. Dependency Graph Contract

```text
DependencyGraph
├── repo_ref
├── nodes[]              (module/symbol, content_hash)
├── edges[]              (from, to, kind)
├── has_cycle: bool
├── graph_id             (immutable, T001 Rule 1)
└── evidence_ref         (T001)
```

Quy tắc:

* Mọi node có `content_hash` (T078) + provenance (T001 Rule 5).
* Cycle phát hiện → `has_cycle = true` → BLOCK (T001 Rule 2).
* Graph idempotent: cùng source → cùng graph (deterministic).
* Mọi graph có provenance (T001 Rule 5).

### 3. Dependency Graph Safety

* **Fail-closed** — cycle → BLOCK (T001 Rule 2).
* **Secret isolation** — không lộ secret (T040/T113).
* **Evidence required** — mọi graph có provenance (T001 Rule 5).
* **Deterministic** — cùng source → cùng graph.
* **No parallel graph** — dùng Scanner (T117) + Symbol Index (T118) + Evidence (T001) + Integrity (T078).

### 4. Deliverables

* Dependency Graph (edge extraction + store + cycle detection).
* Cycle Detection (BLOCK on cycle, T001 Rule 2).
* Policy Boundary (T113).
* Integration với Repository Scanner (T117) + Source/Symbol Index (T118) + Evidence (T001) + Integrity (T078).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — dependency graph).

### 5. Acceptance Criteria

TASK-119 chỉ PASS khi:

* Trích được edge dependency (import/require/call) từ source.
* Graph lưu node + edge + metadata.
* Cycle phát hiện → BLOCK (T001 Rule 2).
* Mọi node có `content_hash` (T078) + provenance (T001 Rule 5).
* Cùng source → cùng graph (deterministic).
* Tích hợp được với Scanner + Symbol Index + Evidence + Integrity.
* Regression của các milestone trước PASS; không vi phạm invariants.
