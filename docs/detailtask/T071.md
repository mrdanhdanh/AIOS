## TASK-071 — AIOS 1.0 Developer Experience

**Mục tiêu**

Đưa **Developer Experience (DX) lên mức production** — CLI ổn định, scaffolding, error message rõ ràng, docs và workflow tooling cho developer xây capability/agent/tool trên AIOS 1.0. TASK-071 là **DX tooling, không phải runtime feature** (dựa trên `aios/cli`, `aios/devkit`).

TASK-071 thuộc **M10 – Architecture 1.0**, ngay sau T070 (Security). Trọng tâm canonical: **DX production**.

### 1. Phạm vi — DX tooling, không change contracts

```text
DX Layer
├── CLI (aios/cli, aiagent)        # stable commands
├── Scaffold (aios/devkit)         # capability/agent/tool template
├── Error messages                 # actionable, not stack-only
├── Docs                           # getting-started + reference
└── Workflow tooling               # governance gates friendly
```

* **Stable CLI** — lệnh `aiagent` / gate_check / parse_spec ổn định, versioned.
* **Scaffold** — template tạo capability/agent/tool tuân thủ architecture (T063).
* **Actionable errors** — error message chỉ rõ nguyên nhân + cách sửa.
* **Docs** — getting-started + reference cho 1.0.

### 2. DX Contract

```text
DevArtifact
├── kind: capability | agent | tool | workflow
├── template_version
├── conforms_to: architecture(1.0) + contract(1.0)
└── evidence_ref
```

Quy tắc:

* Scaffold sinh artifact tuân thủ architecture 1.0 (T063) + contract 1.0 (T064).
* CLI thay đổi breaking → version bump + deprecation.
* Error message phải actionable (không chỉ stack trace).

### 3. DX Safety

* **No contract violation in scaffold** — template phải conform (guard T063).
* **Stable CLI** — breaking change → version bump.
* **Deterministic scaffold** — cùng template + version → cùng artifact.
* **No parallel DX system** — dùng `aios/cli` + `aios/devkit`.

### 4. Deliverables

* Stable CLI commands (versioned).
* Scaffold templates (capability/agent/tool) conform 1.0.
* Actionable error messages.
* Getting-started + reference docs.
* Integration với CLI (aios/cli) + Devkit (aios/devkit) + Governance gates.
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — DX).

### 5. Acceptance Criteria

TASK-071 chỉ PASS khi:

* CLI commands ổn định, versioned.
* Scaffold sinh artifact conform architecture 1.0 (T063) + contract 1.0 (T064).
* Error message actionable (chỉ rõ nguyên nhân + cách sửa).
* Docs getting-started + reference sẵn sàng.
* Scaffold deterministic (cùng template + version → cùng artifact).
* Tích hợp được với CLI + Devkit + Governance gates.
* Regression của các milestone trước PASS; không vi phạm invariants.
