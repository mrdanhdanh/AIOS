## TASK-091 — Meta-Harness / Verify-the-Verifier

**Mục tiêu**

Xây dựng **Meta-Harness (Verify-the-Verifier)** — kiểm tra chính harness: đảm bảo harness (T030/T032/T078/T079/T089/T090) tự nó đúng, không sinh verdict sai, và có thể bị verify. TASK-091 là **harness-of-harness, không phải feature mới**.

TASK-091 thuộc **M13**, ngay sau T090. Trọng tâm canonical: **Meta-Harness / Verify-the-Verifier**.

### 1. Phạm vi — Verify the verifier, không new feature

```text
Meta-Harness
├── Known-answer tests   (harness must give known verdict)
├── Mutation tests       (mutate input -> harness must detect)
├── Verifier integrity   (T078 lock)
└── Meta evidence        (provenance)
```

* **Known-answer** — harness phải trả verdict đã biết với input mẫu.
* **Mutation** — đột biến input → harness phải phát hiện sai khác.
* **Verifier integrity** — dùng T078 để khóa verifier.
* **Meta evidence** — mọi meta-run có provenance.

### 2. Meta Contract

```text
MetaCheck
├── harness_under_test
├── known_answer: expected verdict
├── mutation_detected: bool
├── verifier_locked: bool
└── evidence_ref
```

Quy tắc:

* Harness trả verdict sai với known-answer → meta FAIL (fail-closed).
* Mutation không bị phát hiện → meta FAIL.
* Mọi meta-run có provenance (T001 Rule 5).

### 3. Meta Safety

* **Fail-closed meta** — harness sai → meta FAIL, không certify.
* **Verifier lock** — dùng T078 khóa verifier.
* **Evidence required** — mọi meta-run có provenance.
* **Deterministic** — cùng meta-input + cùng harness → cùng meta-result.
* **No parallel meta system** — dùng Harness (T030/T032) + Integrity (T078).

### 4. Deliverables

* Known-answer test suite cho harness.
* Mutation test suite (detect mutation).
* Verifier integrity integration (T078).
* Meta evidence (provenance).
* Integration với Harness (T030/T032) + Integrity (T078) + Coverage (T090).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs khi task yêu cầu.

### 5. Acceptance Criteria

TASK-091 chỉ PASS khi:

* Known-answer tests: harness trả verdict đúng với input mẫu.
* Mutation tests: harness phát hiện đột biến input.
* Harness sai verdict → meta FAIL (fail-closed).
* Verifier được khóa (T078).
* Mọi meta-run có provenance (T001 Rule 5).
* Cùng meta-input + harness → cùng meta-result (deterministic).
* Tích hợp được với Harness + Integrity + Coverage.
* Regression của các milestone trước PASS; không vi phạm invariants.
