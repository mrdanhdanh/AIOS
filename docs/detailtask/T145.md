## TASK-145 — Coding Loop State Machine

**Mục tiêu**

Triển khai **Coding Loop State Machine** như một năng lực có contract, evidence và harness riêng — điều khiển vòng lặp coding tự chủ (observe → classify → diagnose → repair → verify → refresh → safety) qua một state machine xác định, fail-closed. TASK-145 là **state machine điều khiển, không phải execution mới** (dựa trên Autonomous Loop T053 + Goal Engine T050 + Evidence T001 + Lifecycle T001 Rule 6).

TASK-145 thuộc **M21**, là task nền tảng của milestone. Trọng tâm canonical: **Coding Loop State Machine**.

### 1. Phạm vi — State machine điều khiển loop, không execution mới

```text
Coding Loop State Machine
├── States               (OBSERVING→CLASSIFYING→DIAGNOSING→REPAIRING→VERIFYING→REFRESHING→SAFETY→DONE)
├── Transitions          (điều kiện artifact bắt buộc)
├── Loop Controller      (drive observe→...→safety)
└── Policy Boundary      (T113)
```

* **States** — các trạng thái loop xác định, mỗi transition có điều kiện artifact.
* **Transitions** — thiếu artifact → reject transition (T001 Rule 6).
* **Loop Controller** — điều khiển chuỗi bước coding tự chủ.
* **Policy Boundary** — mọi transition qua policy (T113).

### 2. Coding Loop State Machine Contract

```text
CodingLoopState
├── loop_id              (immutable, T001 Rule 1)
├── current_state
├── transition_history[]
├── evidence_ref         (T001)
├── policy_ref           (T113)
└── authority: aios
```

Quy tắc:

* Mọi transition có điều kiện artifact bắt buộc (T001 Rule 6).
* Thiếu artifact → transition bị reject (fail-closed).
* Mọi transition có provenance (T001 Rule 5).
* Cùng state + cùng input → cùng next state (deterministic).

### 3. Coding Loop State Machine Safety

* **Fail-closed** — thiếu artifact → reject transition (T001 Rule 6).
* **Immutable id** — `loop_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi transition có provenance (T001 Rule 5).
* **Deterministic** — cùng state + input → cùng next state.
* **No parallel loop** — dùng Autonomous Loop (T053) + Goal Engine (T050) + Evidence (T001) + Lifecycle (T001).
