## TASK-115 — Usage / Cost / Audit / Evidence

**Mục tiêu**

Triển khai **Usage / Cost / Audit / Evidence** như một năng lực có contract, evidence và harness riêng — ghi nhận usage (token/latency), tính cost, audit mọi inference call, và tạo evidence có provenance. TASK-115 là **observability + evidence, không phải metering mới** (dựa trên Inference T112 + Resilience T114 + Quota/Cost T039 + Evidence T001 + Integrity T078).

TASK-115 thuộc **M17**, ngay sau T114. Trọng tâm canonical: **Usage / Cost / Audit / Evidence**.

### 1. Phạm vi — Observability + evidence, không new metering

```text
Usage / Cost / Audit / Evidence
├── Usage Record         (token/latency theo T109 schema)
├── Cost Compute         (cost theo quota, T039)
├── Audit Log            (immutable log mọi call)
└── Evidence             (provenance, T001 Rule 5)
```

* **Usage Record** — ghi nhận usage theo `usage_schema` (T109).
* **Cost Compute** — tính cost theo quota/budget (T039).
* **Audit Log** — log bất biến mọi inference call (T078 tamper-evident).
* **Evidence** — mọi record có provenance (T001 Rule 5).

### 2. Usage/Cost Contract

```text
UsageRecord
├── inference_ref        (T112)
├── token_usage          (T109 schema)
├── latency_ms
├── cost                 (T039)
├── audit_entry          (immutable, T078)
├── content_hash         (sha256, T078)
└── evidence_ref         (T001)
```

Quy tắc:

* Mọi inference call (T112) sinh UsageRecord + AuditEntry.
* AuditEntry bất biến, tamper-evident (T078).
* UsageRecord có `content_hash` (T078) + provenance (T001 Rule 5).
* Cùng call → cùng usage/cost (deterministic).

### 3. Usage/Cost Safety

* **Fail-closed** — usage thiếu hash/provenance → reject (T078).
* **Tamper-evident** — audit sửa → phát hiện (T078).
* **Evidence required** — mọi record có provenance (T001 Rule 5).
* **Deterministic** — cùng call → cùng usage/cost.
* **No parallel metering** — dùng Inference (T112) + Quota (T039) + Integrity (T078) + Evidence (T001).

### 4. Deliverables
