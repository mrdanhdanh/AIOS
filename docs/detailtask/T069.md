## TASK-069 — Reliability Engineering

**Mục tiêu**

Thiết lập **SLO và reliability controls** cho AIOS — định nghĩa Service Level Objectives, error budgets, circuit breakers và retry/backoff chuẩn cho toàn hệ thống. TASK-069 là **reliability controls, không phải runtime rewrite** (dựa trên T065 Hardening + T066 Durable).

TASK-069 thuộc **M10 – Architecture 1.0**, ngay sau T068 (Kill Switch). Trọng tâm canonical: **SLO và reliability controls**.

### 1. Phạm vi — Reliability controls, không redesign

```text
Reliability Layer
├── SLO definitions        (latency / availability / success-rate)
├── Error Budget           (burn-rate guard)
├── Circuit Breaker        (open on repeated failure)
├── Retry/Backoff policy   (bounded, T065/T061)
└── Health probes          (aios/core/healthcheck)
```

* **SLO Registry** — mỗi critical path có SLO được định nghĩa + đo.
* **Error Budget** — burn-rate vượt ngưỡng → degrade safe / stop new traffic.
* **Circuit Breaker** — mở (open) khi failure rate vượt ngưỡng; half-open để thử lại.
* **Retry/Backoff** — bounded exponential backoff (liên kết T065/T061).

### 2. Reliability Contract

```text
SLOMetric
├── name
├── objective            # e.g. 99.5% success
├── window
├── current
├── error_budget_remaining
└── evidence_ref
```

Quy tắc:

* Error budget cạn → fail-closed (degrade safe / stop new work), không tiếp tục bình thường.
* Circuit breaker mở → không gửi traffic tới dependency hỏng.
* Mọi SLO measurement có evidence (provenance).

### 3. Reliability Safety

* **Fail-closed budget** — error budget cạn → degrade/stop (không ignore).
* **Bounded retry** — không infinite retry (liên kết T061/T065).
* **Evidence required** — mọi SLO/breaker state có provenance.
* **Deterministic** — cùng metric + cùng policy → cùng quyết định.
* **No parallel reliability system** — dùng Runtime + Observability (T065).

### 4. Deliverables

* SLO Registry + Error Budget guard.
* Circuit Breaker (open/half-open/closed).
* Bounded Retry/Backoff policy.
* Health probe integration (`aios/core/healthcheck`).
* Integration với Runtime (T065) + Durable (T066) + Kill Switch (T068).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — SLO policy).

### 5. Acceptance Criteria

TASK-069 chỉ PASS khi:

* Mọi critical path có SLO định nghĩa + đo được.
