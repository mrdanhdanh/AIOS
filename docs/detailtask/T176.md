## TASK-176 — Risk Model + Classification

**Mục tiêu**

Triển khai **Risk Model + Classification** như một năng lực có contract, evidence và harness riêng — mô hình rủi ro + phân loại, deterministic, làm input cho policy (T177) và gate (T175). TASK-176 là **risk model, không phải gate mới** (dựa trên Quality Gate T175 + Trust Evaluator T164 + Evidence T001).

TASK-176 thuộc **M24**, ngay sau T175. Trọng tâm canonical: **Risk Model + Classification**.

### 1. Phạm vi — Risk model, không gate mới

```text
Risk Model + Classification
├── Risk Model           (mô hình rủi ro)
├── Classification       (phân loại risk level)
├── Confidence           (độ tự tin)
└── Policy Boundary      (T113)
```

* **Risk Model** — mô hình đánh giá rủi ro từ evidence/verdict.
* **Classification** — phân loại risk level (đóng, xác định trước).
* **Confidence** — mỗi classification có confidence; thấp → UNKNOWN (không promote).
* **Policy Boundary** — classification qua policy (T113).

### 2. Risk Model + Classification Contract

```text
RiskClassification
├── class_id             (immutable, T001 Rule 1)
├── gate_ref             (T175)
├── risk_level
├── confidence           (0..1)
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Classification UNKNOWN (confidence thấp) → không promote PASS (T078).
* Mọi classification có provenance (T001 Rule 5).
* Classification deterministic: cùng input → cùng risk level.
* Taxonomy đóng — không sinh level ngoài tập định nghĩa.

### 3. Risk Model + Classification Safety

* **Fail-closed** — UNKNOWN → không promote PASS (T078).
* **Immutable id** — `class_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi classification có provenance (T001 Rule 1/5).
* **Deterministic** — cùng input → cùng risk level.
* **No parallel model** — dùng Quality Gate (T175) + Trust Evaluator (T164) + Evidence (T001).

### 4. Deliverables

* UNKNOWN (confidence thấp) → không promote PASS (T078).
