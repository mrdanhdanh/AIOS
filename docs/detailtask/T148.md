## TASK-148 — Diagnostic Agent

**Mục tiêu**

Triển khai **Diagnostic Agent** như một năng lực có contract, evidence và harness riêng — chẩn đoán root cause từ failure đã classify (T147) + observation (T146), sinh diagnostic report làm input cho repair planner (T149). TASK-148 là **diagnostic agent, không phải repair mới** (dựa trên Failure Classification T147 + Execution Observation T146 + Evidence T001).

TASK-148 thuộc **M21**, ngay sau T147. Trọng tâm canonical: **Diagnostic Agent**.

### 1. Phạm vi — Diagnostic agent, không repair mới

```text
Diagnostic Agent
├── Root Cause          (tìm nguyên nhân từ class + observation)
├── Diagnostic Report   (báo cáo chẩn đoán)
├── Hypothesis          (giả thuyết có thể bác bỏ)
└── Policy Boundary      (T113)
```

* **Root Cause** — suy luận root cause từ failure class (T147) + observation (T146).
* **Diagnostic Report** — báo cáo có provenance (T001 Rule 5).
* **Hypothesis** — giả thuyết có thể bác bỏ; không chốt → UNKNOWN (không promote).
* **Policy Boundary** — diagnostic qua policy (T113).

### 2. Diagnostic Agent Contract

```text
DiagnosticReport
├── report_id           (immutable, T001 Rule 1)
├── class_ref           (T147)
├── observation_ref     (T146)
├── root_cause
├── confidence          (0..1)
├── evidence_ref        (T001)
└── authority: aios
```

Quy tắc:

* Diagnostic UNKNOWN (confidence thấp) → không promote PASS (T078).
* Mọi diagnostic có provenance (T001 Rule 5).
* Diagnostic deterministic: cùng input → cùng root cause.
* Diagnostic không lộ secret (T040/T113).

### 3. Diagnostic Agent Safety

* **Fail-closed** — UNKNOWN → không promote PASS (T078).
* **Immutable id** — `report_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi diagnostic có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng root cause.
* **No parallel diagnostic** — dùng Classification (T147) + Observation (T146) + Evidence (T001).
