## TASK-101 — Continuous Certification

**Mục tiêu**

Thiết lập **Continuous Certification** — chứng nhận (certify) liên tục thay vì chỉ một lần tại release: mọi thay đổi (code/config/policy) đều chạy lại certification suite và chỉ được phép deploy khi PASS. TASK-101 là **continuous cert gate, không phải certification mới** (dựa trên Certification Suite T073 + Harness chain + Autonomous Harness Loop T099).

TASK-101 thuộc **M15 – Autonomous Harness**, ngay sau T100 (Failure-Corpus). Trọng tâm canonical: **Continuous Certification**.

### 1. Phạm vi — Continuous cert, không new suite

```text
Continuous Certification
├── Trigger on change    (T062 / T099 loop)
├── Run cert suite       (T073 + T087 + T090/T091)
├── Gate deploy          (PASS -> deploy, FAIL -> block)
└── Cert evidence        (provenance)
```

* **Trigger** — mỗi change (commit/config/policy) kích hoạt cert (qua T062/T099).
* **Run suite** — chạy lại toàn bộ certification (T073) + conformance (T087) + harness trust (T090/T091).
* **Gate** — chỉ deploy khi mọi gate PASS (fail-closed).
* **Cert evidence** — mọi cert run có provenance.

### 2. Continuous Cert Contract

```text
ContinuousCertRun
├── trigger: change_id
├── gates_run: [governance, architecture, contract, harness, conformance]
├── all_passed: bool
├── deploy_allowed: bool
└── evidence_ref
```

Quy tắc:

* Một gate FAIL → không deploy (fail-closed).
* Cert phải chạy lại mỗi change (không chỉ tại release).
* Mọi cert run có provenance (T001 Rule 5).

### 3. Continuous Cert Safety

* **Fail-closed deploy** — gate FAIL → không deploy.
* **Re-run on change** — mọi change trigger cert (không bỏ qua).
* **Evidence required** — mọi cert run có provenance.
* **Deterministic** — cùng change + cùng suite → cùng cert result.
* **No parallel cert system** — dùng Certification (T073) + Conformance (T087) + Harness trust (T090/T091).

### 4. Deliverables

* Change trigger for certification (T062/T099).
* Cert suite runner (T073 + T087 + T090/T091).
* Deploy gate (fail-closed).
* Cert evidence (provenance).
* Integration với Certification (T073) + Conformance (T087) + Harness trust (T090/T091) + Loop (T099).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs khi task yêu cầu.

### 5. Acceptance Criteria

TASK-101 chỉ PASS khi:

* Mọi change trigger certification (T062/T099).
* Toàn bộ cert suite chạy lại (T073/T087/T090/T091).
* Một gate FAIL → không deploy (fail-closed).
* Mọi cert run có provenance (T001 Rule 5).
* Cùng change + suite → cùng cert result (deterministic).
* Tích hợp được với Certification + Conformance + Harness trust + Loop.
* Regression của các milestone trước PASS; không vi phạm invariants.
