## TASK-157 — Behavioral Verifier

**Mục tiêu**

Triển khai **Behavioral Verifier** như một năng lực có contract, evidence và harness riêng — xác minh hành vi (behavioral contract) của output, fail-closed. TASK-157 là **behavioral verifier, không phải evaluator mới** (dựa trên Requirement→Evidence Mapping T155 + Evaluation Harness T032 + Verification Engine T142 + Evidence T001).

TASK-157 thuộc **M22**, ngay sau T156. Trọng tâm canonical: **Behavioral Verifier**.

### 1. Phạm vi — Behavioral verifier, không evaluator mới

```text
Behavioral Verifier
├── Behavior Spec        (spec hành vi kỳ vọng)
├── Verify               (xác minh hành vi)
├── Determinism          (cùng input → cùng hành vi)
└── Policy Boundary      (T113)
```

* **Behavior Spec** — spec hành vi kỳ vọng từ requirement (T155).
* **Verify** — xác minh output thỏa behavior spec.
* **Determinism** — cùng input → cùng hành vi (deterministic).
* **Policy Boundary** — verification qua policy (T113).

### 2. Behavioral Verifier Contract

```text
BehavioralResult
├── result_id            (immutable, T001 Rule 1)
├── map_ref              (T155)
├── behavior_spec
├── verdict              (PASS/FAIL/INCONCLUSIVE)
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Behavior không khớp → FAIL/INCONCLUSIVE (fail-closed, T078).
* Mọi result có provenance (T001 Rule 5).
* Verification deterministic: cùng input → cùng verdict.
* Verification không lộ secret (T040/T113).

### 3. Behavioral Verifier Safety

* **Fail-closed** — INCONCLUSIVE → không promote PASS (T078).
* **Immutable id** — `result_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi result có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng verdict.
* **No parallel verifier** — dùng Requirement→Evidence (T155) + Evaluation Harness (T032) + Verification Engine (T142) + Evidence (T001).

### 4. Deliverables

* Behavioral Verifier (spec + verify + determinism).
