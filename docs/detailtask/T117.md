## TASK-117 — Repository Scanner

**Mục tiêu**

Triển khai **Repository Scanner** như một năng lực có contract, evidence và harness riêng — quét repository (file/structure) để thu thập artifact metadata phục vụ indexing và context. TASK-117 là **scanner, không phải index mới** (dựa trên Evidence T001 + Context Retriever T121).

TASK-117 thuộc **M18**, ngay sau T116 (M17). Trọng tâm canonical: **Repository Scanner**. Đây là task mở M18.

### 1. Phạm vi — Scanner, không new index

```text
Repository Scanner
├── File Walk            (duyệt repo, bỏ qua ignore)
├── Artifact Metadata    (size/type/hash, T001 Rule 5)
├── Change Detection     (diff so với scan trước)
└── Policy Boundary      (T113)
```

* **File Walk** — duyệt cây file, tôn trọng `.gitignore`/ignore rules.
* **Artifact Metadata** — thu thập metadata (path, size, type, `content_hash` T078).
* **Change Detection** — phát hiện file mới/sửa/xóa giữa các scan.
* **Policy Boundary** — scan không truy cập secret (T040/T113).

### 2. Scanner Contract

```text
ScanResult
├── repo_ref
├── files[]              (path, size, type, content_hash)
├── scan_id              (immutable, T001 Rule 1)
├── changed_files[]      (new/modified/deleted)
├── policy_ref           (T113)
└── evidence_ref         (T001)
```

Quy tắc:

* Mọi file có `content_hash` (T078) + provenance (T001 Rule 5).
* Scanner không đọc nội dung secret (T040).
* Scan idempotent: cùng repo state → cùng scan result (deterministic).
* Mọi scan có provenance (T001 Rule 5).

### 3. Scanner Safety

* **Fail-closed** — file không hash được → reject (T078).
* **Secret isolation** — không lộ secret (T040/T113).
* **Evidence required** — mọi scan có provenance (T001 Rule 5).
* **Deterministic** — cùng repo state → cùng result.
* **No parallel scanner** — dùng Evidence (T001) + Integrity (T078) + Security (T113).

### 4. Deliverables

* Repository Scanner (file walk + metadata + change detection).
* Artifact Metadata (hash, T078).
* Policy Boundary (T113, không đọc secret).
* Integration với Evidence (T001) + Integrity (T078) + Security (T113) + Source Index (T118).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — scanner).

### 5. Acceptance Criteria

TASK-117 chỉ PASS khi:

* Scanner duyệt repo, tôn trọng ignore rules.
* Mọi file có `content_hash` (T078) + provenance (T001 Rule 5).
* Change detection phát hiện new/modified/deleted.
* Scanner không lộ secret (T040/T113).
* File không hash được → reject (fail-closed, T078).
* Cùng repo state → cùng result (deterministic).
* Tích hợp được với Evidence + Integrity + Security + Source Index.
* Regression của các milestone trước PASS; không vi phạm invariants.
