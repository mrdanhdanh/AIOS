## TASK-128 — Patch Engine

**Mục tiêu**

Triển khai **Patch Engine** như một năng lực có contract, evidence và harness riêng — áp dụng code artifact (T127) thành patch an toàn (diff/apply/rollback) lên repository, không phá Core. TASK-128 là **patch engine, không phải generator mới** (dựa trên Code Generation T127 + Upgrade/Migration T020 + Durable T066).

TASK-128 thuộc **M19**, ngay sau T127. Trọng tâm canonical: **Patch Engine**.

### 1. Phạm vi — Patch engine, không new generator

```text
Patch Engine
├── Diff                  (tạo diff từ artifact)
├── Apply                 (áp dụng patch an toàn)
├── Rollback             (rollback nếu fail, T020/T066)
└── Policy Boundary       (T113)
```

* **Diff** — tạo diff (unified) từ code artifact (T127).
* **Apply** — áp dụng patch an toàn, có backup trước (T020).
* **Rollback** — nếu apply fail → rollback về certified state (T020/T066).
* **Policy Boundary** — apply phải qua policy (T113).

### 2. Patch Engine Contract

```text
PatchRun
├── artifact_ref          (T127)
├── diff                  (unified)
├── applied: bool
├── backup_ref            (T020)
├── rollback_available: bool
└── evidence_ref          (T001)
```

Quy tắc:

* Apply phải có backup trước (T020); fail → rollback (T020/T066).
* Mọi patch có `content_hash` (T078) + provenance (T001 Rule 5).
* Patch deterministic: cùng artifact + cùng target → cùng diff (deterministic).
* Mọi run có provenance (T001 Rule 5).

### 3. Patch Engine Safety

* **Fail-closed** — apply fail → rollback, không để repo hỏng (T020/T066).
* **Backup first** — phải backup trước apply (T020).
* **Evidence required** — mọi run có provenance (T001 Rule 5).
* **Deterministic** — cùng artifact + target → cùng diff.
* **No parallel patcher** — dùng Generation (T127) + Upgrade (T020) + Durable (T066) + Evidence (T001).

### 4. Deliverables

* Patch Engine (diff + apply + rollback).
* Backup-before-apply (T020).
* Rollback to certified state (T020/T066).
* Policy Boundary (T113).
* Integration với Code Generation (T127) + Upgrade/Migration (T020) + Durable (T066) + Evidence (T001).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — patch engine).

### 5. Acceptance Criteria

TASK-128 chỉ PASS khi:

* Patch Engine tạo diff từ artifact (T127) và apply an toàn.
* Apply có backup trước (T020); fail → rollback (T020/T066).
* Mọi patch có `content_hash` (T078) + provenance (T001 Rule 5).
* Apply fail → rollback, không để repo hỏng (fail-closed).
* Cùng artifact + target → cùng diff (deterministic).
* Tích hợp được với Generation + Upgrade + Durable + Evidence.
* Regression của các milestone trước PASS; không vi phạm invariants.
