## TASK-137 — Workspace / Snapshot Manager

**Mục tiêu**

Triển khai **Workspace / Snapshot Manager** như một năng lực có contract, evidence và harness riêng — quản lý workspace (thư mục làm việc) và snapshot (checkpoint) để execution (T135) có thể resume/rollback. TASK-137 là **workspace/snapshot manager, không phải execution mới** (dựa trên Execution Contract T135 + Durable T066 + Upgrade/Migration T020).

TASK-137 thuộc **M20**, ngay sau T135. Trọng tâm canonical: **Workspace / Snapshot Manager**.

### 1. Phạm vi — Workspace/snapshot manager, không new execution

```text
Workspace / Snapshot Manager
├── Workspace            (quản lý thư mục làm việc)
├── Snapshot             (checkpoint state, T066)
├── Restore              (rollback về snapshot, T020/T066)
└── Policy Boundary       (T113)
```

* **Workspace** — quản lý workspace riêng biệt cho mỗi execution (T135).
* **Snapshot** — checkpoint state (T066) để resume.
* **Restore** — rollback về snapshot khi fail (T020/T066).
* **Policy Boundary** — workspace/snapshot qua policy (T113).

### 2. Workspace/Snapshot Contract

```text
WorkspaceRecord
├── workspace_id         (immutable, T001 Rule 1)
├── snapshot_id          (immutable, T001 Rule 1)
├── state_hash           (sha256, T078)
├── restore_available: bool
├── policy_ref           (T113)
└── evidence_ref         (T001)
```

Quy tắc:

* `workspace_id` / `snapshot_id` immutable (T001 Rule 1).
* Snapshot có `state_hash` (T078) + provenance (T001 Rule 5).
* Restore fail → rollback về snapshot trước (T020/T066).
* Cùng state → cùng snapshot (deterministic).

### 3. Workspace/Snapshot Safety

* **Fail-closed** — snapshot không hash được → reject (T078).
* **Immutable id** — `workspace_id`/`snapshot_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi snapshot có provenance (T001 Rule 5).
* **Deterministic** — cùng state → cùng snapshot.
* **No parallel manager** — dùng Execution Contract (T135) + Durable (T066) + Upgrade (T020) + Policy (T113).
