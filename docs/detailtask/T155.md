## TASK-155 — Requirement → Evidence Mapping

**Mục tiêu**

Triển khai **Requirement → Evidence Mapping** như một năng lực có contract, evidence và harness riêng — ánh xạ mỗi requirement tới evidence chứng minh nó được thỏa mãn, làm nền cho mọi verifier sau (T156→T164) xác minh coverage. TASK-155 là **mapping layer, không phải verifier mới** (dựa trên Evidence T001 Rule 5 + Execution Evidence/Conformance T144 + Verification Engine T142).

TASK-155 thuộc **M22**, là task nền tảng của milestone. Trọng tâm canonical: **Requirement → Evidence Mapping**.

### 1. Phạm vi — Mapping layer, không verifier mới

```text
Requirement → Evidence Mapping
├── Requirement Registry  (đăng ký requirement)
├── Evidence Link         (link requirement → evidence)
├── Coverage              (đo coverage requirement)
└── Policy Boundary       (T113)
```

* **Requirement Registry** — đăng ký requirement có id immutable (T001 Rule 1).
* **Evidence Link** — mỗi requirement link tới evidence có provenance (T001 Rule 5).
* **Coverage** — đo coverage requirement; thiếu evidence → UNKNOWN (không promote).
* **Policy Boundary** — mapping qua policy (T113).

### 2. Requirement → Evidence Mapping Contract

```text
RequirementEvidenceMap
├── map_id               (immutable, T001 Rule 1)
├── requirement_id
├── evidence_ref[]       (T001/T144)
├── coverage_status      (COVERED/UNCOVERED/UNKNOWN)
├── authority: aios
```

Quy tắc:

* Requirement không có evidence → coverage UNKNOWN (không promote PASS, T078).
* Mọi link có provenance (T001 Rule 5).
* Mapping deterministic: cùng requirement → cùng evidence set.
* Evidence phải verify được (T142/T144).

### 3. Requirement → Evidence Mapping Safety

* **Fail-closed** — requirement không có evidence → UNKNOWN (T078).
* **Immutable id** — `map_id`/`requirement_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi link có provenance (T001 Rule 5).
* **Deterministic** — cùng requirement → cùng evidence set.
* **No parallel mapping** — dùng Evidence (T001) + Execution Evidence/Conformance (T144) + Verification Engine (T142).

### 4. Deliverables

* Requirement → Evidence Mapping (registry + link + coverage).
* Policy Boundary (T113).
* Integration với Evidence (T001) + Execution Evidence/Conformance (T144) + Verification Engine (T142).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — requirement → evidence mapping).

### 5. Acceptance Criteria

TASK-155 chỉ PASS khi:

* Mỗi requirement link được tới evidence có provenance (T001 Rule 5).
* Requirement không có evidence → coverage UNKNOWN (không promote, T078).
* Mapping deterministic: cùng requirement → cùng evidence set.
* Evidence phải verify được (T142/T144).
* Tích hợp được với Evidence + Execution Evidence/Conformance + Verification Engine.
* Regression của các milestone trước PASS; không vi phạm invariants.
