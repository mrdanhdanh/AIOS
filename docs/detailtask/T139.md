### 3. Test Runner Safety

* **Fail-closed** — policy vi phạm → BLOCK (T078).
* **Sandbox only** — không chạy ngoài sandbox (T136/T040).
* **Evidence required** — mọi result có provenance (T001 Rule 5).
* **Deterministic** — cùng suite + env → cùng result.
* **No parallel runner** — dùng Execution (T135) + Sandbox (T136) + Workspace (T137) + Policy (T138) + Evidence (T001).
