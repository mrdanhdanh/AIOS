## TASK-207 — Session Fork

**Mục tiêu**

Triển khai **Session Fork** như một năng lực có contract, evidence và harness riêng — fork session coding thành nhánh thử nghiệm, fail-closed. TASK-207 là **fork, không phải session mới** (dựa trên Coding Session T206 + Workspace/Snapshot T137 + Evidence T001).

TASK-207 thuộc **M26**, ngay sau T206. Trọng tâm canonical: **Session Fork**.

### 2. Session Fork Contract

```text
SessionFork
├── fork_id              (immutable, T001 Rule 1)
```

Quy tắc:

* Fork phải snapshot trước (T137) — mismatch → fail-closed.
* Mọi fork có provenance (T001 Rule 5).

* Fork chỉ trong sandbox (T136/T040).

### 3. Session Fork Safety

* **Fail-closed** — snapshot mismatch → reject (T137).
* **Immutable id** — `fork_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi fork có provenance (T001 Rule 5).
* **Deterministic** — cùng session → cùng fork.
* **No parallel fork** — dùng Coding Session (T206) + Workspace/Snapshot (T137) + Sandbox (T136) + Evidence (T001).
