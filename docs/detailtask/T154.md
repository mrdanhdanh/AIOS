## TASK-154 — Autonomous Coding Harness

**Mục tiêu**

Triển khai **Autonomous Coding Harness** như một năng lực có contract, evidence và harness riêng — harness tích hợp toàn bộ coding loop (T145→T153) trên nền Harness Kernel (T029) + Test Harness (T031) + Evaluation Harness (T032). TASK-154 là **harness tích hợp, không phải loop mới** (dựa trên toàn bộ M21 T145→T153 + Harness Kernel T029 + Test Harness T031 + Evaluation Harness T032 + Evidence T001).

TASK-154 thuộc **M21**, là task cuối của milestone. Trọng tâm canonical: **Autonomous Coding Harness**.

```text
CodingHarnessRun
├── run_id               (immutable, T001 Rule 1)
```

Quy tắc:

### 3. Autonomous Safety Controller Safety

* **Fail-closed** — loop fail → harness báo FAIL, không promote (T078).
* **Immutable id** — `run_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi run có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng output (T029/T079).
* **No parallel harness** — dùng toàn bộ M21 (T145→T153) + Harness Kernel (T029) + Test Harness (T031) + Evaluation Harness (T032) + Evidence (T001).
