## TASK-097 — Permission + Human Approval + Apply + Re-test + Rollback + Certification

**Mục tiêu**

Thực thi **Apply remediation** đã qua simulation gate (T096): xin **Permission + Human Approval** (khi cần), **Apply** candidate, **Re-test** qua harness, **Rollback** nếu fail, và **Certify** kết quả. TASK-097 là **apply/rollback orchestration, không phải detection** (dựa trên Simulation T096 + Permission T070 + Governor T054 + Harness T030/T032 + Certification T073).

TASK-097 thuộc **M14**, ngay sau T096. Trọng tâm canonical: **Permission + Human Approval + Apply + Re-test + Rollback + Certification**.

### 1. Phạm vi — Apply + rollback, không detect

```text
Apply + Rollback Orchestration
├── Permission check     (T070 security)
├── Human approval       (high-risk, T054/T067)
├── Apply candidate      (safe)
├── Re-test              (harness T030/T032)
├── Rollback on fail     (T074/T066)
└── Certify result       (T073)
```

* **Permission** — mọi apply qua permission broker (T070).
* **Human approval** — candidate high-risk → cần human approve (T054/T067).
* **Apply** — thực thi candidate an toàn.
* **Re-test** — chạy lại harness để xác nhận khắc phục.
* **Rollback** — nếu re-test FAIL → rollback (T074/T066).
* **Certify** — kết quả cuối có certificate (T073).


* Mọi bước có provenance (T001 Rule 5).

### 3. Apply Safety

* **Fail-closed permission** — thiếu permission → không apply.
* **Human-in-loop for risk** — high-risk cần approval.
* **Rollback on fail** — re-test FAIL → rollback an toàn.
* **Evidence required** — mọi bước có provenance.
* **Deterministic** — cùng candidate + cùng policy → cùng apply result.
* **No parallel apply system** — dùng Permission (T070) + Governor (T054) + Harness + Cert (T073).
