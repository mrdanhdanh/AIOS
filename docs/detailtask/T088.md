## TASK-088 — Docs & ADR — Compatibility

**Mục tiêu**

Soạn **Docs & ADR cho Compatibility** — tài liệu hóa đầy đủ chính sách tương thích, quy trình versioning, backward-compat guarantee và conformance (T084-T087) thành ADR + docs tham chiếu. TASK-088 là **documentation, không phải code mới**.

TASK-088 thuộc **M12 – Compatibility**, ngay sau T087. Trọng tâm canonical: **Docs & ADR — Compatibility**.

### 1. Phạm vi — Documentation, không code

```text
Compatibility Docs & ADR
├── ADR-Compatibility    (policy + rationale)
├── Versioning guide     (T084)
├── Migration guide      (T085)
```

* **ADR** — ghi nhận quyết định compatibility (semver, deprecation, matrix).

* **Reference** — tài liệu tham chiếu cho developer (T071 DX).

Quy tắc:

* Docs phải cover đủ T084-T087.
* ADR phải ghi rationale (tại sao chọn policy).
* Mọi doc reference có provenance (link tới task).

### 3. Docs Safety

* **Coverage** — docs phải cover đủ chuỗi compatibility.
* **ADR integrity** — ADR ghi rationale, không mâu thuẫn với T084-T087.
* **No stale doc** — doc phải khớp với implementation đã DONE.
* **Deterministic review** — cùng nội dung → cùng review result.
* **No parallel doc system** — dùng docs/ + ADR convention.

### 4. Deliverables

* ADR-Compatibility (policy + rationale).
* Versioning / Migration / Backward-compat / Conformance guides.
* Reference docs cho developer (T071).
* Integration với Docs (docs/) + DX (T071) + chuỗi T084-T087.
* Review + link checks.
* ADR/docs (bắt buộc — task là docs).

### 5. Acceptance Criteria

TASK-088 chỉ PASS khi:

* Docs cover đủ T084-T087.
* ADR ghi rationale rõ ràng.
* Doc khớp với implementation đã DONE (không stale).
* Mọi doc reference có provenance (link task).
* Cùng nội dung → cùng review result (deterministic).
* Tích hợp được với Docs + DX + chuỗi compatibility.
* Regression của các milestone trước PASS; không vi phạm invariants.
