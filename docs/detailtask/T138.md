## TASK-138 — Resource + Network + Command Policy

**Mục tiêu**

Triển khai **Resource + Network + Command Policy** như một năng lực có contract, evidence và harness riêng — enforce policy cho resource (cpu/mem), network (egress) và command (allow/deny) trong execution (T135). TASK-138 là **policy enforcement, không phải runner mới** (dựa trên Execution Contract T135 + Credential/Network/Sandbox T040 + Quota/Cost T039 + Permission T035).

TASK-138 thuộc **M20**, ngay sau T135. Trọng tâm canonical: **Resource + Network + Command Policy**.

### 1. Phạm vi — Policy enforcement, không new runner

```text
Resource + Network + Command Policy
├── Resource Policy      (cpu/mem limit, T039)
├── Network Policy       (egress allow/deny, T040)
```

```text
ExecutionPolicy
```
