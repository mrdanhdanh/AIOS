## TASK-210 — Change Impact Analysis

**Mục tiêu**

Triển khai **Change Impact Analysis** như một năng lực có contract, evidence và harness riêng — phân tích tác động thay đổi code, fail-closed. TASK-210 là **impact analyzer, không phải graph mới** (dựa trên Parallel Coding T209 + Dependency Graph T119 + Context Retriever T121 + Evidence T001).

TASK-210 thuộc **M26**, ngay sau T209. Trọng tâm canonical: **Change Impact Analysis**.

### 1. Phạm vi — Impact analyzer, không graph mới

```text
Change Impact Analysis
├── Analyze              (phân tích tác động)
├── Dependency Bind      (gắn dependency graph T119)
├── Impact Flag          (flag impacted)
└── Policy Boundary      (T113)
```

* **Analyze** — phân tích tác động thay đổi từ coding.
* **Dependency Bind** — dùng Dependency Graph (T119).
* **Impact Flag** — flag các node bị tác động.
* **Policy Boundary** — analysis qua policy (T113).

### 2. Change Impact Analysis Contract

```text
ImpactAnalysis
├── analysis_id          (immutable, T001 Rule 1)
├── coding_ref           (T209)
├── dep_graph_ref        (T119)
├── impacted_nodes[]
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Mọi analysis có provenance (T001 Rule 5).
* Analysis deterministic: cùng change → cùng impact.
* `analysis_id` immutable (T001 Rule 1).
* Analysis không vượt policy boundary (T113).

### 3. Change Impact Analysis Safety

* **Fail-closed** — analysis thiếu provenance → không ghi nhận (T001 Rule 5).
* **Immutable id** — `analysis_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi analysis có provenance (T001 Rule 5).
* **Deterministic** — cùng change → cùng impact.
* **No parallel analyzer** — dùng Parallel Coding (T209) + Dependency Graph (T119) + Context Retriever (T121) + Evidence (T001).

### 4. Deliverables

* Change Impact Analysis (analyze + dependency bind + impact flag).
* Policy Boundary (T113).
* Integration với Parallel Coding (T209) + Dependency Graph (T119) + Context Retriever (T121) + Evidence (T001).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — change impact analysis).

### 5. Acceptance Criteria

TASK-210 chỉ PASS khi:

* Phân tích được tác động thay đổi code.
* Dùng được Dependency Graph (T119).
* Mọi analysis có provenance (T001 Rule 5).
* Cùng change → cùng impact (deterministic).
* Tích hợp được với Parallel Coding + Dependency Graph + Context Retriever + Evidence.
* Regression của các milestone trước PASS; không vi phạm invariants.
