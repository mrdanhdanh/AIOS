## TASK-087 — Compatibility Conformance

**Mục tiêu**

Xây dựng **Compatibility Conformance** — bộ kiểm tra xác nhận một build AIOS 1.x **conform** với compatibility baseline (T084) và backward-compat guarantee (T086), sinh conformance report có evidence. TASK-087 là **conformance harness, không phải feature mới** (dựa trên Certification T073 + Contract T064).

TASK-087 thuộc **M12 – Compatibility**, ngay sau T086. Trọng tâm canonical: **Compatibility Conformance**.

### 1. Phạm vi — Conformance harness, không redesign

```text
Compatibility Conformance
├── Run compat test suite (T086)
├── Check version policy   (T084)
├── Check contract freeze  (T064)
└── Conformance report     (evidence-backed)
```

* **Conformance Runner** — chạy toàn bộ compat + version + contract checks.
* **Report** — sinh báo cáo conformance có provenance.
* **Gate** — không conform → không cấp conformance (fail-closed).

### 2. Conformance Contract

```text
ConformanceReport
├── target_version: 1.x
├── baseline: 1.0 (T084)
├── checks_passed: [api, schema, event, version, contract]
├── issued_at
└── evidence_ref
```

Quy tắc:

* Một check FAIL → không conform (fail-closed).
* Report phải có provenance đầy đủ.
* Chỉ build conform mới được coi là compatible.

### 3. Conformance Safety

* **Fail-closed conform** — check FAIL → không conform.
* **Evidence required** — report có provenance.
* **Deterministic** — cùng build + cùng suite → cùng kết quả.
* **No parallel conformer** — dùng Certification (T073) + Contract (T064).

### 4. Deliverables

* Conformance Runner (compat + version + contract).
* Conformance Report (evidence-backed).
* Conformance gate (fail-closed).
* Integration với Certification (T073) + Contract (T064) + Version (T084) + Backward (T086).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs khi task yêu cầu.

### 5. Acceptance Criteria

TASK-087 chỉ PASS khi:

* Mọi compat check (T086) chạy trong conformance.
* Version policy (T084) + contract freeze (T064) chạy.
* Một check FAIL → không conform (fail-closed).
* Report có provenance đầy đủ.
* Cùng build + suite → cùng kết quả (deterministic).
* Tích hợp được với Certification + Contract + Version + Backward.
* Regression của các milestone trước PASS; không vi phạm invariants.
