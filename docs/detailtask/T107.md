## TASK-107 — Permission + Sandbox Bridge

**Mục tiêu**

Xây dựng **Permission + Sandbox Bridge** — bridge các permission/sandbox check từ independent harness vào AIOS verification mà không phá Core. TASK-107 là **bridge quyền + sandbox, không phải feature mới** (dựa trên Oracle T105 + Foundation T104 + Identity/RBAC T035 + Sandbox Isolation T040 + Credential/Permission/Policy T113).

TASK-107 thuộc **M16**, ngay sau T105. Trọng tâm canonical: **Permission + Sandbox Bridge**.

### 1. Phạm vi — Bridge quyền + sandbox, không new feature

```text
Permission + Sandbox Bridge
├── Permission Contract   (định nghĩa permission kỳ vọng)
├── Sandbox Contract      (định nghĩa sandbox boundary kỳ vọng)
├── Bridge                (bridge check từ independent harness)
└── Policy Boundary       (AIOS policy authoritative)
```

* **Permission Contract** — định nghĩa permission/authorization kỳ vọng (T035/T113).
* **Sandbox Contract** — định nghĩa sandbox/network/secrets boundary kỳ vọng (T040).
* **Bridge** — đưa kết quả check permission/sandbox từ independent harness vào AIOS.
* **Policy Boundary** — AIOS quyết policy; independent result là input.

### 2. Permission + Sandbox Contract

```text
PermissionSandboxReport
├── check_id
├── permission_ref         (ref permission, T035/T113)
├── sandbox_ref            (ref sandbox boundary, T040)
├── independent_result     (từ independent harness)
├── aios_policy_result      (authoritative, do AIOS quyết)
├── evidence_ref           (provenance)
└── authority: aios        (luôn là aios)
```

Quy tắc:

* Independent result là input; `aios_policy_result` do AIOS tính.
* Mọi report có provenance (T001 Rule 5) qua bridge.
* Result không xác định → INCONCLUSIVE → không promote PASS (T078).
* Cùng check + cùng input → cùng `aios_policy_result` (deterministic).

### 3. Permission + Sandbox Safety

* **AIOS authority** — AIOS quyết policy; independent result không override.
* **Fail-closed** — result không xác định → không promote PASS (T078).
* **Evidence required** — mọi bridge có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng `aios_policy_result`.
* **No parallel policy system** — dùng Oracle (T105) + Foundation (T104) + Identity (T035) + Sandbox (T040) + Credential (T113).

### 4. Deliverables

* Permission + Sandbox Bridge (check → AIOS policy result).
* Evidence Mapping (result → evidence AIOS, T001).
* Policy Boundary (AIOS authoritative).
* Integration với Oracle (T105) + Foundation (T104) + Identity (T035) + Sandbox (T040) + Credential (T113).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs khi task yêu cầu.
