## TASK-099 — Autonomous Harness Loop

**Mục tiêu**

Xây dựng **Autonomous Harness Loop** — một vòng lặp tự chủ mà ở đó hệ thống tự động chạy harness (T030/T032/T078/T079/T089/T091) lên chính nó, phát hiện regression/hành vi sai và kích hoạt remediation (T094-T098) một cách autonomy-aware và fail-closed. TASK-099 là **self-testing loop, không phải harness mới** (dựa trên Autonomous Loop T053 + Harness chain + Remediation T094-T098).

TASK-099 thuộc **M15 – Autonomous Harness**, mở đầu chuỗi cuối. Trọng tâm canonical: **Autonomous Harness Loop**.

### 1. Phạm vi — Self-testing loop, không new harness

```text
Autonomous Harness Loop
├── Schedule/Trigger harness run (T062)
├── Run harness chain   (T030/T032/T078/T079/T089/T091)
├── Detect deviation   (T094)
├── Trigger remediation(T095-T098) [autonomy-gated]
└── Loop evidence      (provenance)
```

* **Schedule/Trigger** — chạy harness định kỳ hoặc khi có change (T062).
* **Run harness chain** — thực thi toàn bộ harness đã xây dựng.
* **Detect deviation** — nếu harness phát hiện sai → detect (T094).
* **Remediation** — kích hoạt remediation (T095-T098) chỉ khi autonomy cho phép (T054/T067).
* **Loop evidence** — mọi vòng lặp có provenance.

### 2. Loop Contract

```text
HarnessLoopRun
├── run_id
├── harnesses_run: [..]
├── deviations: [..]
├── remediation_triggered: bool
├── autonomy_allowed: bool
└── evidence_ref
```

Quy tắc:

* Deviation phát hiện → không auto-promote PASS (fail-closed, T078/T060).
* Remediation chỉ trigger khi autonomy cho phép (T054/T067).
* Mọi vòng lặp có provenance (T001 Rule 5).

### 3. Loop Safety

* **Fail-closed deviation** — deviation → không PASS, trigger detect.
* **Autonomy-gated remediation** — chỉ trigger khi Governor allow (T054/T067).
* **Evidence required** — mọi vòng lặp có provenance.
* **Deterministic** — cùng system state + cùng harness → cùng loop result.
* **No parallel loop** — dùng Autonomous Loop (T053) + Harness chain + Remediation.
