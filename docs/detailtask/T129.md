## TASK-129 — Code Review Agent

**Mục tiêu**

Triển khai **Code Review Agent** như một năng lực có contract, evidence và harness riêng — review code artifact/patch (T127/T128) theo contract, I/O-free, capability-injected, không trở thành God Object. TASK-129 là **review agent, không phải runtime mới** (dựa trên Coder Agent T125 + Patch T128 + Architecture Guard ARCH + Reviewer T001/AGENTS).

TASK-129 thuộc **M19**, ngay sau T128. Trọng tâm canonical: **Code Review Agent**.

### 1. Phạm vi — Review agent, không new runtime

```text
Code Review Agent
├── Agent Contract        (I/O-free, capability-injected, T125)
├── Review Rules         (static/contract checks)

```

* **Agent Contract** — review agent thuần túy, không I/O trực tiếp (T125/AGENTS).
* **Review Rules** — check static/contract (architecture, policy, provenance).
* **Finding Emit** — phát hiện có severity (info/warn/block) + evidence.
* **Policy Boundary** — finding block phải qua policy (T113).

### 2. Code Review Contract

```text
ReviewReport
├── artifact_ref          (T127)
├── patch_ref             (T128)
├── findings[]           (severity, rule, evidence_ref)
├── verdict               (APPROVE/REQUEST_CHANGES/BLOCK)
├── agent_id              (immutable, T001 Rule 1)
└── evidence_ref          (T001)
```

Quy tắc:

* Agent không I/O trực tiếp; review qua Capability/Runtime (ARCH-004).
* Finding block → verdict BLOCK (fail-closed, T078).
* Mọi finding có provenance (T001 Rule 5).
* Review deterministic: cùng artifact + cùng rules → cùng verdict (deterministic).

### 3. Code Review Safety

* **Architecture gate** — agent import forbidden module → BLOCK (ARCH-001..004).
* **Fail-closed** — finding block → verdict BLOCK (T078).
* **Evidence required** — mọi finding có provenance (T001 Rule 5).
* **Deterministic** — cùng artifact + rules → cùng verdict.
* **No God Object** — review chỉ đề xuất, không bypass policy (T022).
* **No parallel reviewer** — dùng Coder Agent (T125) + Patch (T128) + Architecture (ARCH) + Reviewer (T001) + Policy (T113).
