### 2. Conformance/Certification Contract

```text
ProviderCertification
├── provider_ref         (T110)
├── model_ref            (T111)
├── conformance_result   (PASS/FAIL/INCONCLUSIVE)
├── cert_id              (T049, immutable)
├── integrity_verified   (T078)
├── evidence_ref         (T001)
```

Quy tắc:

* Conformance FAIL/INCONCLUSIVE → không certify (fail-closed, T078).
* Certification chỉ cấp khi conformance PASS + integrity verified (T078).
* `cert_id` immutable (T001 Rule 1, T049).
* Mọi run có provenance (T001 Rule 5).
* Cùng provider/model + cùng suite → cùng result (deterministic).

### 3. Conformance/Certification Safety

* **Fail-closed** — INCONCLUSIVE → không certify (T078).
* **Integrity verified** — conformance phải qua integrity gate (T078).
* **Immutable cert** — `cert_id` không tái sử dụng (T001 Rule 1, T049).
* **Evidence required** — mọi run có provenance (T001 Rule 5).
* **Deterministic** — cùng input + suite → cùng result.
* **No parallel cert** — dùng Provider (T110) + Model (T111) + Inference (T112) + Usage (T115) + Integrity (T078) + Certification (T049).
