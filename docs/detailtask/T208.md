## TASK-208 — Multi-Agent Coding

**Mục tiêu**

Triển khai **Multi-Agent Coding** như một năng lực có contract, evidence và harness riêng — coding với nhiều agent phối hợp, fail-closed. TASK-208 là **multi-agent coordinator, không phải session mới** (dựa trên Session Fork T207 + Multi-Agent Autonomy T059 + Coder Agent T125 + Evidence T001).

TASK-208 thuộc **M26**, ngay sau T207. Trọng tâm canonical: **Multi-Agent Coding**.

### 3. Multi-Agent Coding Safety

* **Fail-closed** — consensus vi phạm boundary → DENY (T067/T113).
* **Immutable id** — `coord_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi coordination có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng plan.
* **No parallel coordinator** — dùng Session Fork (T207) + Multi-Agent Autonomy (T059) + Coder Agent (T125) + Evidence (T001).
