## TASK-209 — Parallel Coding

**Mục tiêu**

Triển khai **Parallel Coding** như một năng lực có contract, evidence và harness riêng — coding song song nhiều task, fail-closed. TASK-209 là **parallel scheduler, không phải coordinator mới** (dựa trên Multi-Agent Coding T208 + Parallel Scheduler T028 + Coding Session T206 + Evidence T001).

TASK-209 thuộc **M26**, ngay sau T208. Trọng tâm canonical: **Parallel Coding**.

Quy tắc:

### 3. Parallel Coding Safety

* **Fail-closed** — task fail → theo join policy (T028), không promote nếu ALL_COMPLETED fail.
* **Immutable id** — `run_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi run có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng output (T029/T079).
* **No parallel scheduler** — dùng Multi-Agent Coding (T208) + Parallel Scheduler (T028) + Coding Session (T206) + Evidence (T001).
