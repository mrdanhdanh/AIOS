## TASK-114 — Retry / Timeout / Streaming / Cancellation

**Mục tiêu**

Triển khai **Retry / Timeout / Streaming / Cancellation** như một năng lực có contract, evidence và harness riêng — quản lý lifecycle execution của inference (T112) với retry/cancel/timeout và streaming, không trở thành control plane. TASK-114 là **execution resilience, không phải engine mới** (dựa trên Inference T112 + Execution T005 + Security T113).

TASK-114 thuộc **M17**, ngay sau T112/T113. Trọng tâm canonical: **Retry / Timeout / Streaming / Cancellation**.

### 1. Phạm vi — Execution resilience, không new engine

```text
Retry / Timeout / Streaming / Cancellation
├── Retry                (retry theo policy, không loop vô hạn)
├── Timeout              (timeout bound, fail-closed)
├── Streaming            (stream chunk có provenance)
└── Cancellation         (cancel an toàn, T005)
```

* **Retry** — retry theo policy (số lần/cooldown), không loop vô hạn (T005).
* **Timeout** — mọi call có timeout bound; hết timeout → fail-closed (T078).
* **Streaming** — stream chunk có provenance (T001 Rule 5).
* **Cancellation** — cancel an toàn, giải phóng resource (T005).

### 2. Resilience Contract

```text
ResilienceConfig
├── max_retries
├── retry_cooldown
├── timeout_ms
├── streaming: bool
├── cancellable: bool
├── inference_ref        (T112)
└── evidence_ref         (T001)
```

Quy tắc:

* Retry không vượt `max_retries`; vượt → fail-closed (T078).
* Timeout hết → fail-closed, không treo (T005).
* Streaming chunk có provenance (T001 Rule 5).
* Cancel phải giải phóng resource (T005).
* Cùng config + cùng failure → cùng retry behavior (deterministic).

### 3. Resilience Safety

* **Fail-closed** — retry/timeout vượt → reject (T078).
* **No infinite loop** — retry bounded (T005).
* **Evidence required** — mọi chunk/event có provenance (T001 Rule 5).
* **Deterministic** — cùng config + failure → cùng behavior.
* **Policy boundary** — dùng Execution (T005) + Inference (T112) + Security (T113).
