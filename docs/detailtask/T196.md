### 3. Continuous Evaluation Safety

* **Fail-closed** — thành phần fail → run FAIL (T078).
* **Immutable id** — `run_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi run có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng output (T029/T079).
* **No parallel loop** — dùng toàn bộ M25 (T185→T195) + Observability (T021) + Evidence (T001).
