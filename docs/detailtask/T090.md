## TASK-090 — Harness Coverage + Readiness

**Mục tiêu**

Đo lường và nâng **Harness Coverage + Readiness** — đảm bảo harness (T030/T032/T078/T079/T089) bao phủ đủ bề mặt hệ thống và sẵn sàng (readiness) để chứng nhận build. TASK-090 là **coverage/readiness metric, không phải harness mới** (dựa trên Harness + Certification T073).

TASK-090 thuộc **M13**, ngay sau T089. Trọng tâm canonical: **Harness Coverage + Readiness**.

### 1. Phạm vi — Coverage metric, không new harness

```text
Harness Coverage + Readiness
├── Coverage map        (which surfaces harnessed)
├── Readiness gate      (harness ready to certify?)
├── Gap report          (un-covered surfaces)
└── Readiness evidence  (provenance)
```

* **Coverage map** — ánh xạ bề mặt hệ thống → harness đang cover.
* **Readiness gate** — harness đủ sẵn sàng để chứng nhận build không.
* **Gap report** — liệt kê bề mặt chưa được harness cover.
* **Readiness evidence** — mọi readiness check có provenance.

### 2. Coverage Contract

```text
CoverageReport
├── total_surfaces
├── harnessed_surfaces
├── coverage_ratio
├── gaps: [..]
├── readiness: READY | NOT_READY
└── evidence_ref
```

Quy tắc:

* Coverage dưới ngưỡng → NOT_READY (fail-closed, không certify).
* Gap phải được report (không giấu).
* Mọi readiness check có provenance (T001 Rule 5).

### 3. Coverage Safety

* **Fail-closed readiness** — coverage thấp → NOT_READY.
* **No hidden gap** — gap phải report.
* **Evidence required** — mọi readiness check có provenance.
* **Deterministic** — cùng system + cùng harness → cùng coverage.
* **No parallel coverage system** — dùng Harness (T030/T032) + Certification (T073).

### 4. Deliverables

* Coverage map (surface → harness).
* Readiness gate (fail-closed).
* Gap report.
* Readiness evidence (provenance).
* Integration với Harness (T030/T032/T089) + Certification (T073).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs khi task yêu cầu.

### 5. Acceptance Criteria

TASK-090 chỉ PASS khi:

* Coverage map ánh xạ đủ bề mặt hệ thống.
* Coverage dưới ngưỡng → NOT_READY (fail-closed).
* Gap được report (không giấu).
* Mọi readiness check có provenance (T001 Rule 5).
* Cùng system + harness → cùng coverage (deterministic).
* Tích hợp được với Harness + Certification.
* Regression của các milestone trước PASS; không vi phạm invariants.
