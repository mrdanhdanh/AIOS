## TASK-084 — Version + Compatibility Baseline

**Mục tiêu**

Thiết lập **Version + Compatibility Baseline** — quy ước versioning (semver) và chính sách tương thích cho AIOS 1.x, làm nền tảng cho mọi task compatibility sau (T085-T088). TASK-084 là **versioning policy + baseline, không phải feature mới** (dựa trên Contract Freeze T064).

TASK-084 thuộc **M12 – Compatibility**, mở đầu chuỗi compatibility. Trọng tâm canonical: **Version + Compatibility Baseline**.

### 1. Phạm vi — Versioning policy, không change contracts

```text
Version + Compatibility Baseline
├── Semver policy        (MAJOR.MINOR.PATCH)
├── Compatibility matrix (1.0 <-> 1.x)
├── Deprecation window   (notice period)
└── Baseline document    (ADR)
```

* **Semver** — breaking change → MAJOR; backward-compatible → MINOR; fix → PATCH.
* **Compatibility matrix** — định nghĩa 1.0 tương thích với 1.x như thế nào.
* **Deprecation window** — tính năng deprecated phải có thời gian báo trước.
* **Baseline** — ghi nhận chính thức (ADR) làm tham chiếu T085-T088.

### 2. Version Contract

```text
VersionPolicy
├── scheme: semver
├── breaking -> MAJOR
├── compatible -> MINOR
├── deprecation_window
└── evidence_ref
```

Quy tắc:

* Breaking change không được silent (phải MAJOR + ADR + deprecation).
* Compatibility matrix là tham chiếu cho conformance (T087).
* Mọi version change có provenance (T001 Rule 5).

### 3. Version Safety

* **No silent breaking** — breaking → MAJOR + ADR.
* **Deprecation notice** — deprecated phải báo trước.
* **Evidence required** — mọi version policy có provenance.
* **Deterministic policy** — cùng change type → cùng version bump.
* **No parallel versioning** — dùng Contract (T064) + ADR.

### 4. Deliverables

* Semver policy + compatibility matrix.
* Deprecation window definition.
* Baseline document (ADR).
* Integration với Contract Freeze (T064) + Migration (T074).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — versioning baseline).
