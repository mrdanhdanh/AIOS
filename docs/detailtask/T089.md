## TASK-089 — Behavioral Conformance

**Mục tiêu**

Thiết lập **Behavioral Conformance** — định nghĩa và kiểm tra *hành vi* (behavior) của hệ thống theo các kịch bản quan sát được, đảm bảo AIOS 1.x hành xử đúng theo spec hành vi (không chỉ contract). TASK-089 là **behavioral spec + conformance, không phải runtime feature** (dựa trên Harness T030/T032 + Evidence T001).

TASK-089 thuộc **M13**, mở đầu chuỗi behavioral/harness. Trọng tâm canonical: **Behavioral Conformance**.

### 1. Phạm vi — Behavior spec, không change runtime

```text
Behavioral Conformance
├── Behavior Spec        (observable scenarios)
├── Behavior Harness     (drive + observe)
├── Conformance check    (actual == expected)
└── Behavior evidence    (provenance)
```

* **Behavior Spec** — định nghĩa kịch bản hành vi quan sát được (input → expected observable output).
* **Behavior Harness** — drive hệ thống, quan sát hành vi thực tế.
* **Conformance** — so sánh actual vs expected; lệch → flag.
* **Evidence** — mọi behavior run có provenance (T001 Rule 5).

### 2. Behavior Contract

```text
BehaviorScenario
├── scenario_id
├── given (precondition)
├── when (action)
├── then (expected observable)
├── actual_observable
├── conforms: bool
└── evidence_ref
```

Quy tắc:

* Behavior lệch expected → không conform (fail-closed).
* Behavior spec phải observable (không đoán nội tâm).
* Mọi behavior run có provenance (T001 Rule 5).

### 3. Behavior Safety

* **Fail-closed conform** — lệch expected → không conform.
* **Observable only** — spec dựa trên observable, không nội tâm.
* **Evidence required** — mọi behavior run có provenance.
* **Deterministic** — cùng scenario + cùng system → cùng observable.
* **No parallel behavior system** — dùng Harness (T030/T032) + Evidence (T001).
