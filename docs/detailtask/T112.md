## TASK-112 — Inference Runtime Orchestration

**Mục tiêu**

Triển khai **Inference Runtime Orchestration** như một năng lực có contract, evidence và harness riêng — điều phối thực thi inference qua provider (T110) + model (T111) một cách deterministic, quản lý execution plan và không trở thành control plane LLM. TASK-112 là **orchestration inference, không phải engine mới** (dựa trên Model Contract T109 + Provider Registry T110 + Model Registry T111 + Execution T005).

TASK-112 thuộc **M17**, ngay sau T110/T111. Trọng tâm canonical: **Inference Runtime Orchestration**.

### 1. Phạm vi — Orchestration inference, không new engine

```text
Inference Runtime Orchestration
├── Execution Plan        (plan inference qua provider/model)
├── Provider Dispatch     (gọi provider qua T110)
├── Model Selection       (chọn model qua T111)
└── Policy Boundary       (T113)
```

* **Execution Plan** — lập plan inference (provider + model + params) deterministic.
* **Provider Dispatch** — gọi provider đã đăng ký (T110), không bypass.
* **Model Selection** — chọn model qua resolver (T111).
* **Policy Boundary** — mọi inference phải qua policy (T113).

Quy tắc:

### 3. Inference Orchestration Safety

* **Deterministic-first** — plan rule, không LLM (T001 Rule 4).
* **Fail-closed** — provider/model không hợp lệ → reject (T078).
* **Evidence required** — mọi inference có provenance (T001 Rule 5).
* **Deterministic** — cùng plan + state → cùng result.
* **Policy boundary** — dùng Permission/Policy (T113) + Provider (T110) + Model (T111) + Execution (T005).
