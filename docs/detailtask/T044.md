## TASK-044 — Plugin Runtime

## 1. Metadata

* **Milestone:** M8 — Ecosystem + Autonomy
* **Task ID:** TASK-044
* **Tên:** Plugin Runtime
* **Mục tiêu canonical:** Plugin Runtime (lifecycle, sandbox, isolation).
* **Dependency trực tiếp:** TASK-043 — Public AIOS SDK
* **Priority:** High
* **Status:** PLANNED
* **Execution model:** Runtime-first · Policy-first · Evidence-first · Fail-closed


**Milestone:** M8 — Ecosystem
**Trạng thái:** Roadmap sạch — chưa coi task đã thực hiện. 

### 1. Mục tiêu

Xây **Plugin Runtime** để AIOS có thể nạp, quản lý vòng đời và cô lập plugin/extension một cách an toàn, dựa trên các public contract đã được mở ở TASK-043.

Plugin Runtime **không được trở thành một Runtime thứ hai** và không được bypass Core Runtime, Capability, Permission, Policy hoặc Harness.

### 2. Phạm vi

* Plugin manifest và metadata.
* Plugin discovery/loading.
* Lifecycle:
  `DISCOVERED → VALIDATED → INSTALLED → ENABLED → LOADED → RUNNING`
  và:
  `DISABLED → UNLOADED → REMOVED`
* Dependency resolution giữa plugin.
* Compatibility check theo contract/schema version.
* Capability declaration và registration.
* Plugin isolation.
* Permission/policy pre-check trước khi plugin thực hiện action.
* Health check và lifecycle failure handling.
* Unload/reload an toàn.
* Rollback về certified plugin version.
* Plugin state persistence.
* Integration với:

  * Runtime Services
  * Capability Registry
  * Policy/Permission
  * Artifact Service
  * Event/Audit
  * Harness M6
  * Public SDK TASK-043.

### 4. Plugin Contract

Tối thiểu cần có:

```yaml
plugin:
  id: example.plugin
  version: 1.0.0
  api_version: 1.0
  runtime_version: ">=1.0,<2.0"

  dependencies: []

  capabilities:
    - example.capability

  permissions:
    - filesystem.read

  resources:
    cpu: 1
    memory_mb: 256

  lifecycle:
    entrypoint: plugin:create
```

Runtime phải validate manifest **trước khi load code**.

### 5. Isolation

Plugin không được mặc nhiên có toàn quyền.

Mọi resource/action phải đi qua:

```text
Plugin Request
      ↓
Policy
      ↓
Permission
      ↓
Capability
      ↓
Runtime
```

Plugin bị disable phải **không còn capability active**.

Plugin unload phải giải phóng:

* registrations
* event subscriptions
* runtime handles
* resources
* background tasks
* temporary state.

### 6. Failure & Recovery

Các trường hợp bắt buộc:

| Tình huống       | Kết quả             |
| ---------------- | ------------------- |
| Manifest invalid | `REJECT`            |
| API incompatible | `REJECT`            |
| Dependency thiếu | `BLOCKED`           |
| Policy deny      | `DENIED`            |
| Load failure     | `FAILED`            |
| Health failure   | `UNHEALTHY`         |
| Unload failure   | `FAILED` + evidence |
| Upgrade failure  | rollback            |
| Plugin disabled  | capability removed  |

Không được chuyển `UNKNOWN` thành `PASS`.

### 7. Evidence & Audit

Mỗi lifecycle transition phải tạo evidence/audit có provenance:

```text
Plugin
 → Lifecycle Event
 → Runtime Run
 → Evidence
 → Policy Decision
 → Artifact / Version
```

Đặc biệt phải truy được:

* plugin version
* runtime version
* actor/principal
* tenant nếu có
* policy decision
* capabilities
* permissions
* lifecycle transition
* failure reason.

Điều này phù hợp nguyên tắc Evidence-First của master specification.
