## TASK-170 — Prompt Injection Tester + Untrusted Artifact Isolation

**Mục tiêu**

Triển khai **Prompt Injection Tester + Untrusted Artifact Isolation** như một năng lực có contract, evidence và harness riêng — tấn công prompt injection và cô lập artifact không tin cậy, fail-closed. TASK-170 là **tester + isolation, không phải sandbox mới** (dựa trên Adversarial Harness T165 + Credential Isolation T040 + Policy T113 + Sandbox T136 + Evidence T001).

TASK-170 thuộc **M23**, ngay sau T169. Trọng tâm canonical: **Prompt Injection Tester + Untrusted Artifact Isolation**.

### 3. Prompt Injection Tester + Untrusted Artifact Isolation Safety

* **Fail-closed** — injection/leak bị phát hiện (T040/T113).
* **Immutable id** — `test_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi test có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng detect result.
* **No parallel tester** — dùng Adversarial Harness (T165) + Credential Isolation (T040) + Policy (T113) + Sandbox (T136) + Evidence (T001).
