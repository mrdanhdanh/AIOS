## TASK-085 — Migration 1.0 → 1.1

**Mục tiêu**

Xây dựng **Migration 1.0 → 1.1** — kế hoạch và công cụ migrate hệ thống từ version 1.0 sang 1.1 một cách an toàn, reversible và có evidence, tuân thủ Version + Compatibility Baseline (T084). TASK-085 là **version migration, không phải runtime feature** (dựa trên Upgrade/Migration T074).

TASK-085 thuộc **M12 – Compatibility**, ngay sau T084. Trọng tâm canonical: **Migration 1.0 → 1.1**.

### 1. Phạm vi — Version migration, không redesign

```text
Migration 1.0 -> 1.1
├── Detect 1.0 state
├── Plan (ordered, reversible)
├── Dry-run + verify (harness T032)
├── Apply (state migrate T066)
└── Rollback to 1.0
```

* **Detect** — phát hiện hệ thống đang ở 1.0.
* **Plan** — các bước migrate lên 1.1, mỗi bước reversible.
* **Dry-run** — thử không mutate; verify qua harness trước apply.
* **Rollback** — quay về 1.0 an toàn nếu cần.

### 2. Migration Contract

```text
VersionMigration
├── from: 1.0.0
├── to: 1.1.0
├── steps: [ {id, up, down, verify} ]
├── dry_run_supported: bool
└── evidence_ref
```

Quy tắc:

* Verify FAIL → không apply (fail-closed, T074).
* Mọi bước reversible (có `down`).
* Mọi bước ghi evidence (T001 Rule 5).

### 3. Migration Safety

* **Fail-closed apply** — verify FAIL → không apply.
* **Reversible** — mọi bước có rollback.
* **Evidence required** — mọi bước có provenance.
* **Deterministic** — cùng plan + state → cùng kết quả.
* **No data loss** — state migrate an toàn (T066).

### 4. Deliverables

* Version Migration 1.0→1.1 (detect + plan + apply + rollback).
* Dry-run + verify (harness T032).
* State migration (durable T066).
* Integration với Upgrade (T074) + Version Baseline (T084) + Harness (T032).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs khi task yêu cầu.
