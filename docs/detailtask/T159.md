## TASK-159 — Regression Verifier

**Mục tiêu**

Triển khai **Regression Verifier** như một năng lực có contract, evidence và harness riêng — xác minh không có regression so với baseline, fail-closed. TASK-159 là **regression verifier, không phải gate mới** (dựa trên Requirement→Evidence Mapping T155 + Benchmark/Regression T033 + Verification Engine T142 + Evidence T001).

TASK-159 thuộc **M22**, ngay sau T158. Trọng tâm canonical: **Regression Verifier**.

### 1. Phạm vi — Regression verifier, không gate mới

```text
Regression Verifier
├── Baseline             (baseline từ T033)
├── Compare              (so sánh với baseline)
├── Regression Flag      (phát hiện regression)
└── Policy Boundary      (T113)
```

* **Baseline** — baseline lấy từ Benchmark/Regression (T033).
* **Compare** — so sánh output với baseline.
* **Regression Flag** — regression phát hiện → FAIL (fail-closed).
* **Policy Boundary** — verification qua policy (T113).

### 2. Regression Verifier Contract

```text
RegressionResult
├── result_id            (immutable, T001 Rule 1)
├── map_ref              (T155)
├── baseline_ref         (T033)
├── verdict              (PASS/FAIL/INCONCLUSIVE)
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Regression phát hiện → FAIL (fail-closed, T078/T033).
* Mọi result có provenance (T001 Rule 5).
* Verification deterministic: cùng input → cùng verdict.
* Baseline từ T033 — không tự sinh ngoài baseline.

### 3. Regression Verifier Safety

* **Fail-closed** — regression → FAIL (T078/T033).
* **Immutable id** — `result_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi result có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng verdict.
* **No parallel verifier** — dùng Requirement→Evidence (T155) + Benchmark/Regression (T033) + Verification Engine (T142) + Evidence (T001).

### 4. Deliverables

* Regression Verifier (baseline + compare + flag).
* Policy Boundary (T113).
* Integration với Requirement→Evidence Mapping (T155) + Benchmark/Regression (T033) + Verification Engine (T142) + Evidence (T001).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — regression verifier).

TASK-159 chỉ PASS khi:

* Verifier so sánh output với baseline (T033).
