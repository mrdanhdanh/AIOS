## TASK-215 — Coding Certification

**Mục tiêu**

Triển khai **Coding Certification** như một năng lực có contract, evidence và harness riêng — cấp certificate cho coding đã qua release gate, fail-closed. TASK-215 là **certification, không phải release gate mới** (dựa trên Release Gate T214 + Certification T049 + Trust Evaluator T164 + Evidence T001).

TASK-215 thuộc **M26**, ngay sau T214. Trọng tâm canonical: **Coding Certification**.

### 2. Coding Certification Contract

```text
CodingCertificate
├── cert_id              (immutable, T001 Rule 1)
├── release_ref          (T214)
├── trust_ref            (T164)
├── issued: bool
├── evidence_ref         (T001)

```

Quy tắc:

* Release DENY → không cấp certificate (fail-closed, T078/T214).
* Mọi certificate có provenance (T001 Rule 5).
* Certification deterministic: cùng input → cùng verdict.
* Certificate không vượt policy boundary (T113).

### 3. Coding Certification Safety

* **Fail-closed** — release DENY → không cấp (T078/T214).
* **Immutable id** — `cert_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi certificate có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng verdict.
* **No parallel certification** — dùng Release Gate (T214) + Certification (T049) + Trust Evaluator (T164) + Evidence (T001).
