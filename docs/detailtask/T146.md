## TASK-146 — Execution Observation

**Mục tiêu**

Triển khai **Execution Observation** như một năng lực có contract, evidence và harness riêng — quan sát execution trace/event trong suốt coding loop (T145) để làm input cho failure classification (T147). TASK-146 là **observation layer, không phải classifier mới** (dựa trên Execution Contract T135 + Output/Artifact Collector T141 + Evidence T001).

TASK-146 thuộc **M21**, ngay sau T145. Trọng tâm canonical: **Execution Observation**.

### 1. Phạm vi — Observation layer, không classifier mới

```text
Execution Observation
├── Trace Capture        (capture execution trace, T135)
├── Event Stream         (stream event từ run, T141)
├── Observation Store    (lưu observation có provenance, T001)
└── Policy Boundary      (T113)
```

* **Trace Capture** — capture execution trace theo Execution Contract (T135).
* **Event Stream** — stream event từ collector (T141) trong suốt run.
* **Observation Store** — mọi observation có provenance (T001 Rule 5).
* **Policy Boundary** — observation qua policy (T113).

### 2. Execution Observation Contract

```text
Observation
├── observation_id       (immutable, T001 Rule 1)
├── loop_ref             (T145)
├── execution_ref        (T135)
├── trace[]              (T141)
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Mọi observation có provenance chain đầy đủ (T001 Rule 5).
* Observation deterministic: cùng execution → cùng trace (T135).
* Observation không lộ secret (T040/T113).
* Observation gắn với loop (T145) để classify bước sau.

### 3. Execution Observation Safety

* **Fail-closed** — observation thiếu provenance → không promote (T001 Rule 5).
* **Immutable id** — `observation_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi observation có provenance (T001 Rule 5).
* **Deterministic** — cùng execution → cùng trace.
* **No parallel observer** — dùng Execution Contract (T135) + Collector (T141) + Evidence (T001).

### 4. Deliverables

* Execution Observation (trace capture + event stream + store).
* Policy Boundary (T113).
* Integration với Coding Loop (T145) + Execution Contract (T135) + Collector (T141) + Evidence (T001).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — execution observation).

TASK-146 chỉ PASS khi:
