## TASK-205 — Artifact Lineage

**Mục tiêu**

Triển khai **Artifact Lineage** như một năng lực có contract, evidence và harness riêng — truy vết lineage của artifact coding xuyên suốt, fail-closed. TASK-205 là **lineage tracker, không phải artifact mới** (dựa trên Recovery Orchestrator T204 + Coding Artifact T130 + Evidence T001 Rule 5 + Integrity T078).

TASK-205 thuộc **M26**, ngay sau T204. Trọng tâm canonical: **Artifact Lineage**.

### 1. Phạm vi — Lineage tracker, không artifact mới

```text
Artifact Lineage
├── Lineage              (truy vết artifact)
├── Hash                 (content_hash, T078)
├── Provenance           (chain T001 Rule 5)
└── Policy Boundary      (T113)
```

* **Lineage** — truy vết artifact từ Coding Artifact (T130).
* **Hash** — mọi artifact có `content_hash` (T078).
* **Provenance** — mọi artifact có provenance chain (T001 Rule 5).
* **Policy Boundary** — tracking qua policy (T113).

### 2. Artifact Lineage Contract

```text
ArtifactLineage
├── lineage_id           (immutable, T001 Rule 1)
├── artifact_ref         (T130)
├── content_hash         (sha256, T078)
├── producer
├── lineage_chain[]      (T001 Rule 5)
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Mọi artifact có `content_hash` (T078) + provenance chain (T001 Rule 5).
* Artifact không verify → không promote PASS (fail-closed, T078).
* `lineage_id` immutable (T001 Rule 1).
* Cùng artifact + cùng verifier → cùng verdict (deterministic).

### 3. Artifact Lineage Safety

* **Fail-closed** — artifact không verify → không promote PASS (T078).
* **Integrity verified** — artifact qua integrity gate (T078).
* **Immutable id** — `lineage_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi artifact có provenance chain (T001 Rule 5).
* **Deterministic** — cùng artifact + verifier → cùng verdict.
* **No parallel tracker** — dùng Recovery Orchestrator (T204) + Coding Artifact (T130) + Integrity (T078) + Evidence (T001).

### 4. Deliverables

* Artifact Lineage (lineage + hash + provenance).
* Policy Boundary (T113).
* Integration với Recovery Orchestrator (T204) + Coding Artifact (T130) + Verification Integrity (T078) + Evidence (T001).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — artifact lineage).

### 5. Acceptance Criteria

TASK-205 chỉ PASS khi:

* Lineage truy vết được artifact (T130).
* Mọi artifact có `content_hash` (T078).
* Mọi artifact có provenance chain đầy đủ (T001 Rule 5).
* Artifact không verify → không promote PASS (fail-closed, T078).
* `lineage_id` immutable (T001 Rule 1).
* Tích hợp được với Recovery Orchestrator + Coding Artifact + Integrity + Evidence.
* Regression của các milestone trước PASS; không vi phạm invariants.
