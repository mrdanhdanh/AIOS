## TASK-083 — SkillDistiller + Static Deploy

**Mục tiêu**

Xây dựng **SkillDistiller** — trích xuất (distill) một workflow / agent behavior thành một **Skill** có thể tái sử dụng, và **Static Deploy** — đóng gói skill để deploy mà không cần runtime động. TASK-083 là **skill packaging, không phải agent framework mới** (dựa trên Skill T001/aios/skill + Devkit T071).

TASK-083 thuộc **M11**, ngay sau T082 (Creative Domain). Trọng tâm canonical: **SkillDistiller + Static Deploy**.

### 1. Phạm vi — Skill distill + static deploy, không replace skill system

```text
SkillDistiller + Static Deploy
├── Distill         (workflow/behavior -> Skill)
├── Skill Contract  (defined interface, T064 1.0)
├── Static Package  (self-contained, no dynamic runtime)
└── Deploy          (install skill, conform architecture T063)
```

* **Distiller** — trích xuất workflow/behavior thành Skill (có contract rõ ràng).
* **Skill Contract** — skill tuân thủ public contract 1.0 (T064).
* **Static Package** — đóng gói self-contained, không phụ thuộc runtime động.
* **Deploy** — cài skill, phải conform architecture (T063) + guard.

### 2. Skill Contract

```text
DistilledSkill
├── skill_id
├── contract_version: 1.0.0
├── inputs/outputs schema
├── static_package_ref
├── conforms_to: architecture(1.0)
└── evidence_ref
```

Quy tắc:

* Skill phải có contract rõ ràng (T064 1.0).
* Static package không được phá layer contract (T063).
* Mọi skill có provenance (T001 Rule 5).

### 3. Skill Safety

* **Contract conformance** — skill phải conform 1.0 (T064).
* **Architecture conformance** — static deploy phải qua guard (T063).
* **No dynamic runtime dependency** — static package self-contained.
* **Evidence required** — mọi skill có provenance.
* **Deterministic distill** — cùng workflow + cùng distiller → cùng skill.
* **No parallel skill system** — dùng Skill (aios/skill) + Devkit (T071).

### 4. Deliverables
