## TASK-065 — Runtime Production Hardening

**Mục tiêu**

**Hardening Runtime** cho môi trường production — tăng cường resilience, observability, config validation, error handling và resource limits của `aios/runtime/` mà không thay đổi layer contract (đã freeze ở T063). TASK-065 là **hardening, không phải tính năng mới**.

TASK-065 thuộc **M10 – Architecture 1.0**, ngay sau T064 (Contract Freeze). Trọng tâm canonical: **Hardening runtime**.

### 1. Phạm vi — Harden, không extend contract

```text
aios/runtime/
├── kernel.py        # composition root — resilience
├── execution.py     # retry / cancel / timeout hardening
├── scheduler.py     # resource-aware scheduling
├── state.py         # state store durability guard
├── resource.py      # resource limits / quotas
└── policy.py        # pre-check hardening
```

* **Resilience** — timeout, cancellation, bounded retry với backoff.
* **Observability** — structured JSON logging + metrics hooks (dùng `aios/core/logging`, `aios/observability`).
* **Config validation** — `aios/core/config.Config` validate sớm (fail-closed nếu sai).
* **Resource limits** — guard resource exhaustion (liên kết T069 Reliability).

### 2. Hardening Contract

```text
RuntimeHealth
├── component
├── status: HEALTHY | DEGRADED | UNHEALTHY
├── last_check
└── evidence_ref
```

Quy tắc:

* Lỗi cấu hình → fail-closed (không chạy với config sai).
* Retry phải bounded (không infinite loop) — liên kết T061 (Stuck Detection).
* Mọi failure path có observability trace.

### 3. Hardening Safety

* **Fail-closed config** — config sai → refuse start.
* **Bounded retry** — không infinite retry; vượt giới hạn → escalate (T055/T061).
* **No contract change** — hardening không phá layer contract (T063) / public contract (T064).
* **Deterministic** — cùng input lỗi + cùng policy → cùng hành vi.

### 4. Deliverables

* Runtime resilience (timeout/cancel/bounded-retry).
* Observability hooks (JSON log + metrics).
* Config validation fail-closed.
* Resource limit guards.
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs nếu tạo architectural decision mới.

### 5. Acceptance Criteria

TASK-065 chỉ PASS khi:

* Config sai → refuse start (fail-closed).
* Retry bounded; vượt giới hạn → escalate (không infinite loop).
* Mọi failure path có observability trace.
* Resource exhaustion được guard.
* Hardening không phá layer contract (T063) / public contract (T064).
* Cùng input lỗi + policy → cùng hành vi (deterministic).
* Regression của các milestone trước PASS; không vi phạm invariants.
