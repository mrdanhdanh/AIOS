## TASK-198 — Coding State Machine

**Mục tiêu**

Triển khai **Coding State Machine** như một năng lực có contract, evidence và harness riêng — state machine cho coding session, fail-closed. TASK-198 là **state machine, không phải contract mới** (dựa trên Unified Coding Contract T197 + Coder State Machine T125 + Coding Loop State Machine T145 + Lifecycle T001 Rule 6).

TASK-198 thuộc **M26**, ngay sau T197. Trọng tâm canonical: **Coding State Machine**.

### 1. Phạm vi — State machine, không contract mới

```text
Coding State Machine
├── States               (AUTHORIZED→EXECUTED→VERIFIED→RESILIENT→GOVERNED→EVALUATED→CERTIFIED)
├── Transitions          (điều kiện artifact bắt buộc)
├── Loop Controller      (drive coding session)
└── Policy Boundary      (T113)
```

* **States** — các trạng thái coding xác định (Coding Completion Contract).
* **Transitions** — thiếu artifact → reject transition (T001 Rule 6).
* **Loop Controller** — điều khiển session coding.
* **Policy Boundary** — mọi transition qua policy (T113).

### 2. Coding State Machine Contract

```text
CodingState
├── state_id             (immutable, T001 Rule 1)
├── contract_ref         (T197)
├── current_state
├── transition_history[]
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Mọi transition có điều kiện artifact bắt buộc (T001 Rule 6).
* Thiếu artifact → transition bị reject (fail-closed).
* Mọi transition có provenance (T001 Rule 5).
* Cùng state + cùng input → cùng next state (deterministic).

### 3. Coding State Machine Safety

* **Fail-closed** — thiếu artifact → reject transition (T001 Rule 6).
* **Immutable id** — `state_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi transition có provenance (T001 Rule 5).
* **Deterministic** — cùng state + input → cùng next state.
* **No parallel state machine** — dùng Unified Coding Contract (T197) + Coder State Machine (T125) + Coding Loop (T145) + Lifecycle (T001).
