# M23 — Adversarial Evaluation

M23 gồm **10 task: TASK-165 → TASK-174**. Theo roadmap sạch, chưa task nào được mặc định là đã hoàn thành.

Thứ tự chuẩn (adversarial harness + các attacker, tích hợp với verification suite M22):

1. **TASK-165 — Adversarial Evaluation Harness**
2. **TASK-166 — Evidence Attackers**
3. **TASK-167 — Test Weakness Attackers**
4. **TASK-168 — Requirement / Scope Attackers**
5. **TASK-169 — Certificate Attackers**
6. **TASK-170 — Prompt Injection Tester + Untrusted Artifact Isolation**
7. **TASK-171 — Execution Integrity Attackers**
8. **TASK-172 — Environment / Dependency Attackers**
9. **TASK-173 — Boundary Attackers**
10. **TASK-174 — Collusion Detector + Resilience Score + Attack Corpus Regression**

Roadmap đặt chuỗi `T165 → T166 → T167 → T168 → T169 → T170 → T171 → T172 → T173 → T174`. M23 xây trên substrate verification của M22 (T155→T164) và security của M20 (T143/T070); các attacker này stress-test tính fail-closed của verification suite.

Vì các task trong file Master Task Specification hiện đang ở dạng chuẩn hóa khá ngắn (`Objective → Scope → Deliverables → Acceptance → Dependencies`), phần chi tiết dưới đây nên bám **master plan gốc** để không tự bịa thêm scope.

### TASK-165 — Adversarial Evaluation Harness

Harness chạy các attacker (T166→T173) chống verification suite (T155→T164), đo resilience.

### TASK-166 — Evidence Attackers

Tấn công evidence (T163/T078) — forge/tamper hash, break provenance.

### TASK-167 — Test Weakness Attackers

Tấn công test adequacy/mutation (T156) — weak test, mutation escape.

### TASK-168 — Requirement / Scope Attackers

Tấn công requirement→evidence mapping (T155) — scope creep, missing coverage.

### TASK-169 — Certificate Attackers

Tấn công certificate (T164/T049) — forge cert, trust inflation.

### TASK-170 — Prompt Injection Tester + Untrusted Artifact Isolation

Tấn công prompt injection + isolate artifact không tin cậy (T040/T113).

### TASK-171 — Execution Integrity Attackers

Tấn công execution integrity (T135/T078) — tamper trace, replay mismatch.

### TASK-172 — Environment / Dependency Attackers

Tấn công environment/dependency (T136/T137) — poisoned dep, env drift.

### TASK-173 — Boundary Attackers

Tấn công boundary (T153/T067) — blast radius escape, policy bypass.

### TASK-174 — Collusion Detector + Resilience Score + Attack Corpus Regression

Phát hiện collusion + điểm resilience + regression corpus tấn công. Task cuối của M23.
