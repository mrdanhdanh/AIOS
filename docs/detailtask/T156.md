## TASK-156 — Test Adequacy Analyzer + Mutation Verifier

**Mục tiêu**

Triển khai **Test Adequacy Analyzer + Mutation Verifier** như một năng lực có contract, evidence và harness riêng — đo độ phủ test (adequacy) và mutation score, fail-closed. TASK-156 là **analyzer + verifier, không phải test runner mới** (dựa trên Requirement→Evidence Mapping T155 + Test Harness T031 + Verification Engine T142 + Evidence T001).

TASK-156 thuộc **M22**, ngay sau T155. Trọng tâm canonical: **Test Adequacy Analyzer + Mutation Verifier**.

### 1. Phạm vi — Analyzer + verifier, không runner mới

```text
Test Adequacy Analyzer + Mutation Verifier
├── Adequacy             (đo coverage/adequacy)
├── Mutation             (mutation score)
```

### 3. Test Adequacy Analyzer + Mutation Verifier Safety

* **Fail-closed** — dưới ngưỡng → FAIL (T078).

* **Evidence required** — mọi report có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng score.
* **No parallel analyzer** — dùng Requirement→Evidence (T155) + Test Harness (T031) + Verification Engine (T142) + Evidence (T001).
