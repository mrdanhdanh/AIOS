# M25 — Evaluation & Benchmark

M25 gồm **12 task: TASK-185 → TASK-196**. Theo roadmap sạch, chưa task nào được mặc định là đã hoàn thành.

Thứ tự chuẩn (evaluation contract → engine → dimensions → registry/baseline → detectors/evaluators → store → benchmark → continuous):

1. **TASK-185 — Coding Evaluation Contract**
2. **TASK-186 — Evaluation Engine**
3. **TASK-187 — Quality Dimensions**
4. **TASK-188 — Benchmark Registry**
5. **TASK-189 — Baseline Manager**
6. **TASK-190 — Regression Detector**
7. **TASK-191 — Agent Behavior Evaluator**
8. **TASK-192 — Efficiency Evaluator**
9. **TASK-193 — Failure Attribution**
10. **TASK-194 — Evaluation Store**
11. **TASK-195 — Model / Agent Benchmark**
12. **TASK-196 — Continuous Evaluation**

Roadmap đặt chuỗi `T185 → T186 → T187 → T188 → T189 → T190 → T191 → T192 → T193 → T194 → T195 → T196`. M25 xây trên substrate evaluation của M6 (T031/T032) + verification M22 (T155→T164) + governance M24 (T175→T184); các task này là năng lực đánh giá/chấm điểm chất lượng xuyên suốt.

Vì các task trong file Master Task Specification hiện đang ở dạng chuẩn hóa khá ngắn (`Objective → Scope → Deliverables → Acceptance → Dependencies`), phần chi tiết dưới đây nên bám **master plan gốc** để không tự bịa thêm scope.

### TASK-185 — Coding Evaluation Contract

Contract chuẩn cho evaluation (dựa trên Evaluation Harness T032 + Evidence T001).

### TASK-186 — Evaluation Engine

Engine chấm điểm (dựa trên Evaluation Harness T032 + Contract T185).

### TASK-187 — Quality Dimensions

Các chiều chất lượng (correctness/robustness/…) (dựa trên Evaluation Engine T186).

### TASK-188 — Benchmark Registry

Đăng ký benchmark (dựa trên Benchmark/Regression T033 + Contract T185).

### TASK-189 — Baseline Manager

Quản lý baseline (dựa trên Benchmark/Regression T033 + Registry T188).

### TASK-190 — Regression Detector

Phát hiện regression (dựa trên Baseline T189 + Regression Verifier T159).

### TASK-191 — Agent Behavior Evaluator

Đánh giá hành vi agent (dựa trên Behavioral Verifier T157 + Evaluation Engine T186).

### TASK-192 — Efficiency Evaluator

Đánh giá hiệu quả (dựa trên Performance Verifier T161 + Evaluation Engine T186).

### TASK-193 — Failure Attribution

Truy nguyên failure (dựa trên Diagnostic Agent T148 + Failure Classification T147).

### TASK-194 — Evaluation Store

Lưu trữ evaluation (dựa trên Evidence T001 + Integrity T078 + Contract T185).

### TASK-195 — Model / Agent Benchmark

Benchmark model/agent (dựa trên Benchmark Registry T188 + Baseline T189 + Evaluation Engine T186).

### TASK-196 — Continuous Evaluation

Evaluation liên tục (dựa trên toàn bộ M25 T185→T195 + Observability T021). Task cuối của M25.
