## TASK-054 — Autonomy Governor

**Milestone:** M9 — Autonomous
**Mục tiêu:** Xây lớp kiểm soát quyền tự chủ của AIOS, bảo đảm autonomous loop chỉ được hành động trong phạm vi quyền, rủi ro, tài nguyên và policy đã cho phép. Theo roadmap, TASK-054 nằm ngay sau TASK-053 Autonomous Loop và trước TASK-055 Autonomous Recovery. 

### 1. Mục tiêu chi tiết

Autonomous Loop đã cho phép AIOS thực hiện:

`Goal → Plan → Act → Observe → Learn`

TASK-054 bổ sung **Governor** để kiểm soát mỗi hành động trước khi thực thi:

```text
Autonomous Loop
      │
      ▼
Autonomy Governor
      │
      ├── Scope Check
      ├── Risk Check
      ├── Policy Check
      ├── Permission Check
      ├── Resource/Budget Check
      ├── Action Limit Check
      └── Approval Check
              │
       ┌──────┴──────┐
       ▼             ▼
     ALLOW        BLOCK/ASK
       │
       ▼
   Execution
```

Governor **không thay thế Policy Engine**. Nó là lớp governance riêng cho autonomous behavior và phải sử dụng các policy/permission/runtime contract hiện có.

### 2. Phạm vi

#### 2.1 Autonomy Policy

Định nghĩa policy cho mức độ tự chủ:

```yaml
autonomy:
  mode: supervised

  limits:
    max_steps: 20
    max_runtime_seconds: 1800
    max_cost: 1.00
    max_tool_calls: 50

  actions:
    read: allow
    write: ask
    execute: ask
    network: deny
    install_skill: ask

  approval:
    destructive: required
    policy_escalation: required
```

Các mode tối thiểu:

* `disabled`
* `supervised`
* `bounded`
* `autonomous`

Không được hiểu `autonomous` là toàn quyền; mọi mode vẫn chịu Policy Engine, Permission Service và architecture invariants.

#### 2.2 Action Classification

Governor phải phân loại autonomous action trước khi quyết định:

```text
READ
WRITE
EXECUTE
NETWORK
CREDENTIAL
INSTALL
MODIFY_SYSTEM
DESTRUCTIVE
POLICY_ESCALATION
```

Action càng có side effect hoặc rủi ro cao càng cần approval hoặc bị block.

#### 2.3 Risk Scoring

Tạo deterministic risk assessment trước execution:

```text
Risk =
  action_risk
+ resource_risk
+ target_risk
+ privilege_risk
+ reversibility_risk
+ cumulative_risk
```

Risk level:

```text
LOW
MEDIUM
HIGH
CRITICAL
```

Không được dùng LLM làm quyết định duy nhất cho risk gate.

#### 2.4 Autonomy Budget

Governor phải theo dõi budget của một autonomous run:

* số bước
* số tool calls
* execution time
* token usage
* estimated/actual cost
* resource consumption
* số lần retry
* cumulative risk

Khi vượt budget:

```text
ALLOW → LIMIT_REACHED → BLOCK
```

Không tự động tăng budget.

#### 2.5 Scope Boundary

Autonomous agent chỉ được hành động trong scope đã được cấp:

```text
Goal
 └── Allowed Scope
      ├── Workspace
      ├── Files
      ├── Capabilities
      ├── Tools
      ├── Network
      ├── Resources
      └── Time
```

Attempt vượt scope phải bị `DENY` hoặc `ASK`, không silently expand scope.

#### 2.6 Human Approval

Các action cần người duyệt phải tạo approval request chứa tối thiểu:

```text
goal
action
target
reason
risk
requested_permissions
resource_estimate
expected_side_effect
rollback_strategy
evidence
```

Approval phải gắn với **một action cụ thể**, có expiry và không được tái sử dụng vô hạn.

#### 2.7 Fail-Closed

Khi Governor không xác định được:

* policy
* risk
* scope
* permission
* budget
* approval state

→ **BLOCK**, không mặc định `ALLOW`.

### 4. Decision Contract

Governor nên trả về một decision có cấu trúc:

```text
AutonomyDecision
├── decision: ALLOW | ASK | DENY | BLOCK
├── reason
├── risk_level
├── policy_version
├── scope
├── budget_remaining
├── required_approval
├── approval_id
└── evidence_ref
```

Không trả về boolean đơn giản kiểu:

```text
allowed = true
```

vì autonomous governance cần audit được **tại sao** action được phép.

### 5. Acceptance Criteria

**AC-01 — Scope**

Action nằm ngoài autonomous scope → `DENY/BLOCK`.

**AC-02 — Risk**

Action `HIGH/CRITICAL` phải tuân approval policy; không được autonomous execution nếu policy yêu cầu approval.

**AC-03 — Budget**

Vượt `max_steps`, `max_cost`, `max_runtime` hoặc `max_tool_calls` → execution bị block.

**AC-04 — Policy**

Governor không được bypass Policy Engine hoặc Permission Service.

**AC-05 — Fail-Closed**

Thiếu policy/risk/scope/permission information → `BLOCK`.

**AC-06 — Approval**

Approval chỉ có hiệu lực cho đúng action/scope/context đã được phê duyệt và phải có expiry.

**AC-07 — Audit**

Mọi `ALLOW`, `ASK`, `DENY`, `BLOCK` đều tạo evidence/audit event có provenance.

**AC-08 — Deterministic**

Các quyết định có thể xác định bằng policy/rule phải chạy không cần LLM.

**AC-09 — Regression**

Toàn bộ regression của M0–M8 và autonomous components trước TASK-054 phải PASS.

**AC-10 — Architecture**

Không tạo một autonomous control plane song song; Governor phải nằm trong architecture hiện tại và đi qua Runtime/Policy/Permission contracts.

### 6. Test Matrix

| Scenario                                       | Expected  |
| ---------------------------------------------- | --------- |
| Read file trong scope                          | ALLOW     |
| Write file cần approval                        | ASK       |
| Write ngoài workspace                          | DENY      |
| Network bị policy cấm                          | BLOCK     |
| Tool calls vượt budget                         | BLOCK     |
| Cost vượt budget                               | BLOCK     |
| Risk HIGH + approval hợp lệ                    | ALLOW     |
| Risk HIGH + không approval                     | ASK/BLOCK |
| Policy không tồn tại                           | BLOCK     |
| Approval hết hạn                               | BLOCK     |
| Autonomous mode nhưng policy deny              | DENY      |
| LLM đề xuất action nguy hiểm nhưng policy deny | DENY      |

### 7. Dependency / Gate

Theo roadmap, TASK-054 phụ thuộc chuỗi autonomous trước đó:

```text
TASK-050 Autonomous Goal Engine
        ↓
TASK-051 Autonomous Planner
        ↓
TASK-052 World Model
        ↓
TASK-053 Autonomous Loop
        ↓
TASK-054 Autonomy Governor
        ↓
TASK-055 Autonomous Recovery
```

TASK-054 đặc biệt phải bảo đảm autonomous execution **không trở thành unrestricted execution**. Roadmap xác định TASK-054 là task “Giới hạn quyền tự chủ”, tiếp nối trực tiếp TASK-053. 

### 8. Definition of Done

TASK-054 chỉ được `DONE` khi:

```text
Autonomous Action
      ↓
Scope
      ↓
Risk
      ↓
Policy
      ↓
Permission
      ↓
Budget
      ↓
Approval
      ↓
ALLOW / ASK / DENY / BLOCK
      ↓
Execution
      ↓
Evidence + Audit
```

và toàn bộ chuỗi:

`PLAN → SPEC → CRITIQUE×2 → BREAKDOWN → REVIEW → IMPLEMENT → TEST → EVALUATE → REGRESSION → COMMIT`

đạt PASS theo governance workflow của AIOS. 

**Kết quả mong muốn:** sau TASK-054, AIOS có thể tự hành nhưng **không tự cấp thêm quyền cho chính mình**; mọi autonomous action đều bounded, policy-aware, budget-aware, approval-aware và evidence-first.
