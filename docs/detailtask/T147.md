## TASK-147 — Failure Classification

**Mục tiêu**

Triển khai **Failure Classification** như một năng lực có contract, evidence và harness riêng — phân loại failure từ observation (T146) theo một taxonomy xác định, deterministic, làm input cho diagnostic agent (T148). TASK-147 là **classifier, không phải diagnostic mới** (dựa trên Execution Observation T146 + Execution Contract T135 + Evidence T001).

TASK-147 thuộc **M21**, ngay sau T146. Trọng tâm canonical: **Failure Classification**.

### 1. Phạm vi — Classifier, không diagnostic mới

```text
Failure Classification
├── Taxonomy             (loại failure xác định)
├── Classify            (observation → class)
├── Confidence          (độ tự tin phân loại)
└── Policy Boundary      (T113)
```

* **Taxonomy** — tập loại failure đóng, xác định trước.
* **Classify** — ánh xạ observation (T146) → class failure.
* **Confidence** — mỗi classification có confidence; thấp → UNKNOWN (không promote PASS).
* **Policy Boundary** — classification qua policy (T113).

### 2. Failure Classification Contract

```text
FailureClass
├── class_id            (immutable, T001 Rule 1)
├── observation_ref     (T146)
├── taxonomy_label
├── confidence          (0..1)
├── evidence_ref        (T001)
└── authority: aios
```

Quy tắc:

* Classification UNKNOWN (confidence thấp) → không promote PASS (T078).
* Mọi classification có provenance (T001 Rule 5).
* Classification deterministic: cùng observation → cùng class.
* Taxonomy đóng — không sinh class ngoài tập định nghĩa.

### 3. Failure Classification Safety

* **Fail-closed** — UNKNOWN → không promote PASS (T078).
* **Immutable id** — `class_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi classification có provenance (T001 Rule 5).
* **Deterministic** — cùng observation → cùng class.
* **No parallel classifier** — dùng Observation (T146) + Execution Contract (T135) + Evidence (T001).

### 4. Deliverables

* Failure Classification (taxonomy + classifier + confidence).

* Integration với Execution Observation (T146) + Execution Contract (T135) + Evidence (T001).
