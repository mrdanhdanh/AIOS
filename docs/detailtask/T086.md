## TASK-086 — Backward Compatibility

**Mục tiêu**

Đảm bảo **Backward Compatibility** — hệ thống 1.x tiếp tục phục vụ consumer được viết cho 1.0 mà không break (API/schema/event không đổi breaking). TASK-086 là **compatibility guarantee, không phải feature mới** (dựa trên Contract Freeze T064 + Version Baseline T084).

TASK-086 thuộc **M12 – Compatibility**, ngay sau T085. Trọng tâm canonical: **Backward Compatibility**.

### 1. Phạm vi — Compat guarantee, không change behavior

```text
Backward Compatibility
├── API compat          (1.0 consumer -> 1.x works)
├── Schema compat       (old schema still accepted)
├── Event compat       (old event shape still emitted/consumed)
└── Compat test suite  (locks behavior)
```

* **API compat** — endpoint 1.0 vẫn hoạt động ở 1.x.
* **Schema compat** — schema cũ vẫn được chấp nhận (không breaking).
* **Event compat** — event shape cũ vẫn emit/consume được.
* **Compat test suite** — khóa behavior tương thích.

### 2. Compat Contract

```text
CompatCheck
├── surface: API | SCHEMA | EVENT
├── consumer_version: 1.0
├── provider_version: 1.x
├── compatible: bool
└── evidence_ref
```

Quy tắc:

* Breaking change với 1.0 consumer → bị chặn (phải MAJOR + deprecation, T084).
* Compat test phải PASS trước DONE.
* Mọi compat check có provenance (T001 Rule 5).

### 3. Compat Safety

* **Fail-closed compat** — break 1.0 consumer → BLOCK.
* **Deprecation required** — nếu muốn break, phải qua T084 (MAJOR + window).
* **Evidence required** — mọi compat check có provenance.
* **Deterministic** — cùng surface + version → cùng kết quả.
* **No parallel compat system** — dùng Contract (T064) + Version (T084).

### 4. Deliverables

* Backward Compatibility guarantee (API/schema/event).
* Compat test suite (locks 1.0 behavior).
* Integration với Contract (T064) + Version Baseline (T084) + Migration (T085).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs khi task yêu cầu.

### 5. Acceptance Criteria

TASK-086 chỉ PASS khi:

* 1.0 consumer vẫn hoạt động trên 1.x (API/schema/event).
* Breaking change với 1.0 consumer → BLOCK (phải MAJOR + deprecation T084).
* Compat test suite PASS trước DONE.
* Mọi compat check có provenance (T001 Rule 5).
* Cùng surface + version → cùng kết quả (deterministic).
* Tích hợp được với Contract + Version + Migration.
* Regression của các milestone trước PASS; không vi phạm invariants.
