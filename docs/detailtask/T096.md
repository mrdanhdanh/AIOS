## TASK-096 — Simulation + Meta-Verification Gate

**Mục tiêu**

Trước khi apply remediation, **Simulation + Meta-Verification Gate** mô phỏng (simulate) candidate trong môi trường an toàn và chạy meta-verification (T091) để xác nhận candidate thực sự khắc phục mà không gây hại. TASK-096 là **simulation gate, không phải apply** (dựa trên Candidate T095 + Meta T091 + Harness T030/T032).

TASK-096 thuộc **M14**, ngay sau T095. Trọng tâm canonical: **Simulation + Meta-Verification Gate**.

### 1. Phạm vi — Simulate + verify, không apply

```text
Simulation + Meta-Verification Gate
├── Simulate candidate   (safe sandbox)
├── Observe outcome      (harness T030/T032)
├── Meta-verify         (T091 verify-the-verifier)
└�── Gate decision       (pass -> apply, fail -> reject)
```

* **Simulate** — chạy candidate trong sandbox an toàn.
* **Observe** — quan sát outcome qua harness (T030/T032).
* **Meta-verify** — xác nhận verdict qua meta-harness (T091).
* **Gate** — chỉ cho apply khi simulate PASS + meta-verify PASS.

### 2. Simulation Contract

```text
SimulationResult
├── candidate_id
├── sandbox_id
├── observed_outcome
├── meta_verified: bool
├── gate: PASS | REJECT
└── evidence_ref
```

Quy tắc:

* Simulate FAIL → REJECT (fail-closed, không apply).
* Meta-verify FAIL → REJECT.
* Mọi simulation có provenance (T001 Rule 5).

### 3. Simulation Safety

* **Fail-closed gate** — simulate/meta FAIL → REJECT.
* **Sandbox isolation** — simulation không ảnh hưởng production.
* **Evidence required** — mọi simulation có provenance.
* **Deterministic** — cùng candidate + cùng sandbox → cùng outcome.
* **No parallel simulation system** — dùng Harness (T030/T032) + Meta (T091).

### 4. Deliverables

* Simulation engine (safe sandbox).
* Outcome observation (harness T030/T032).
* Meta-verification integration (T091).
* Gate decision (fail-closed).
* Integration với Candidate (T095) + Meta (T091) + Harness (T030/T032).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs khi task yêu cầu.

### 5. Acceptance Criteria

TASK-096 chỉ PASS khi:

* Candidate được simulate trong sandbox an toàn.
* Outcome quan sát qua harness (T030/T032).
* Simulate FAIL → REJECT (fail-closed).
* Meta-verify FAIL → REJECT (T091).
* Mọi simulation có provenance (T001 Rule 5).
* Cùng candidate + sandbox → cùng outcome (deterministic).
* Tích hợp được với Candidate + Meta + Harness.
* Regression của các milestone trước PASS; không vi phạm invariants.
