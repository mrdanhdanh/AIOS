## TASK-206 — Coding Session

**Mục tiêu**

Triển khai **Coding Session** như một năng lực có contract, evidence và harness riêng — quản lý session coding (vòng đời, state, artifact), fail-closed. TASK-206 là **session manager, không phải state machine mới** (dựa trên Artifact Lineage T205 + Coding State Machine T198 + Coder Agent Contract T125 + Evidence T001).

TASK-206 thuộc **M26**, ngay sau T205. Trọng tâm canonical: **Coding Session**.

### 1. Phạm vi — Session manager, không state machine mới

```text
Coding Session
├── Session Lifecycle    (tạo/dừng session)
├── State Bind           (gắn state T198)
├── Artifact Bind        (gắn artifact T205)
└── Policy Boundary      (T113)
```

* **Session Lifecycle** — quản lý vòng đời session coding.
* **State Bind** — gắn session với Coding State Machine (T198).
* **Artifact Bind** — gắn session với Artifact Lineage (T205).
* **Policy Boundary** — session qua policy (T113).

### 2. Coding Session Contract

Quy tắc:

### 3. Coding Session Safety

* **Fail-closed** — session thiếu provenance → không promote (T001 Rule 5).
* **Immutable id** — `session_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi session có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng state (T198).
* **No parallel session** — dùng Artifact Lineage (T205) + Coding State Machine (T198) + Coder Agent Contract (T125) + Evidence (T001).
