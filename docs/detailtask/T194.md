## TASK-194 — Evaluation Store

**Mục tiêu**

Triển khai **Evaluation Store** như một năng lực có contract, evidence và harness riêng — lưu trữ evaluation có integrity (hash/provenance), fail-closed. TASK-194 là **store, không phải collector mới** (dựa trên Evaluation Engine T186 + Coding Evaluation Contract T185 + Evidence Collector/Integrity T163 + Evidence T001 Rule 5).

TASK-194 thuộc **M25**, ngay sau T193. Trọng tâm canonical: **Evaluation Store**.

### 1. Phạm vi — Store, không collector mới

```text
Evaluation Store
├── Store                (lưu evaluation)
├── Hash                 (content_hash sha256, T078)
├── Provenance           (chain T001 Rule 5)
└── Policy Boundary      (T113)
```

* **Store** — lưu evaluation từ engine (T186).
* **Hash** — mọi evaluation có `content_hash` (T078).
* **Provenance** — mọi evaluation có provenance chain (T001 Rule 5).
* **Policy Boundary** — store qua policy (T113).

### 2. Evaluation Store Contract

```text
StoredEvaluation
├── eval_id              (immutable, T001 Rule 1)
├── engine_ref           (T186)
├── content_hash         (sha256, T078)
├── producer             (engine)
├── evidence_chain[]     (T001 Rule 5)
├── integrity_verified   (T078)
└── authority: aios
```

Quy tắc:

* Mọi evaluation có `content_hash` (T078) + provenance chain (T001 Rule 5).
* Evaluation không verify → không promote PASS (fail-closed, T078).
* `eval_id` immutable (T001 Rule 1).
* Cùng evaluation + cùng verifier → cùng verdict (deterministic).

### 3. Evaluation Store Safety

* **Fail-closed** — evaluation không verify → không promote PASS (T078).
* **Integrity verified** — evaluation qua integrity gate (T078).
* **Immutable id** — `eval_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi evaluation có provenance chain (T001 Rule 5).
* **Deterministic** — cùng evaluation + verifier → cùng verdict.
* **No parallel store** — dùng Evaluation Engine (T186) + Coding Evaluation Contract (T185) + Evidence Collector/Integrity (T163) + Evidence (T001).
