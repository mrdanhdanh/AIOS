## TASK-063 — AIOS Architecture 1.0

**Mục tiêu**

**Đóng băng (freeze) architecture baseline 1.0** của AIOS — chuẩn hóa và ghi nhận chính thức lớp kiến trúc `Agent → Orchestrator → Runtime → Capability → Tool` cùng các quy tắc `ARCH-001..004` thành tài liệu tham chiếu ổn định (ADR + Architecture Guard codified). TASK-063 là **documentation + guard codification, không phải runtime feature mới**.

TASK-063 thuộc **M10 – Architecture 1.0**, mở đầu chuỗi đóng băng 1.0 (tiếp nối T062, trước T064 Contract Freeze). Trọng tâm canonical: **Đóng băng architecture baseline**.

### 1. Phạm vi — Freeze, không redesign

```text
Agent → Orchestrator → Runtime → Capability → Tool
   (ARCH-001)   (ARCH-002)    (ARCH-003)     (ARCH-004)
```

* **Layer Contract** — mỗi layer có contract rõ ràng; import chỉ đi xuống (downward).
* **ARCH-001** — Agent không import `subprocess`/`os` execution primitives.
* **ARCH-002** — Agent không import provider adapters.
* **ARCH-003** — Agent không import filesystem adapters.
* **ARCH-004** — không upward / skip-layer import (vd: tool → runtime).
* **Architecture Guard** — `aios/governance/architecture/guard.py` codified thành 1.0 baseline.

### 2. Architecture Contract (frozen 1.0)

```text
LAYER_ORDER = ["agent","orchestrator","runtime","capability","tool"]
LAYER_KEYWORDS = { ... }  # classification
Violation(rule, module, detail, line)  # fail-closed
```

Quy tắc:

* Mọi import vi phạm → `ARCHITECTURE GATE = FAIL → TASK BLOCKED`.
* Architecture Guard chạy trong CI (local + remote) trước mọi DONE.
* Baseline 1.0 là tham chiếu cho T064 (Contract Freeze) và mọi task sau.

### 3. Freeze Safety

* **No silent change** — thay đổi layer contract phải qua ADR + version bump.
* **Fail-closed** — parse error / violation → BLOCK (không warn rồi tiếp).
* **Deterministic** — cùng source tree + cùng guard version → cùng kết quả.
* **No parallel architecture** — không tạo layer thứ hai song song.

### 4. Deliverables

* Architecture 1.0 baseline document (ADR) chuẩn hóa 5 layers + ARCH-001..004.
* Architecture Guard codified thành 1.0 (test coverage đầy đủ).
* Layer contract reference cho mọi task sau.
* CI integration (local + remote) cho architecture gate.
* Unit + Contract + Architecture + Regression tests.
* ADR/docs (bắt buộc — task là freeze + document).

### 5. Acceptance Criteria

TASK-063 chỉ PASS khi:

* Layer contract `Agent → Orchestrator → Runtime → Capability → Tool` được ghi nhận chính thức (ADR).
* `ARCH-001..004` được codified trong Architecture Guard.
* Import vi phạm → `ARCHITECTURE GATE FAIL` (test PASS).
* Architecture Guard chạy trong CI trước mọi DONE.
* Thay đổi layer contract yêu cầu ADR + version bump (no silent change).
* Guard fail-closed (parse error → BLOCK).
* Guard deterministic (cùng source + version → cùng kết quả).
* Không tạo layer thứ hai song song.
* Regression của các milestone trước PASS; không vi phạm invariants.
