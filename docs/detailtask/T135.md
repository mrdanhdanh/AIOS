## TASK-135 — Execution Contract

**Mục tiêu**

Triển khai **Execution Contract** như một năng lực có contract, evidence và harness riêng — định nghĩa contract chuẩn cho thực thi (request/response, sandbox ref, policy ref, artifact ref) mà mọi execution task M20 dùng chung. TASK-135 là **foundation của M20, không phải runner mới** (dựa trên Execution T005 + Coder Pipeline T125–T130 + Evidence T001).

TASK-135 thuộc **M20**, ngay sau T130 (M19). Trọng tâm canonical: **Execution Contract**. Đây là task mở M20.

### 1. Phạm vi — Contract chuẩn, không new runner

```text
Execution Contract
├── Execution Schema     (request/response chuẩn)
├── Sandbox Ref          (ref sandbox, T136)
├── Policy Ref           (T113)
└── Artifact Ref         (T130)
```

* **Execution Schema** — định nghĩa cấu trúc execution request/response chuẩn.
* **Sandbox Ref** — execution trỏ tới sandbox (T136) để chạy isolated.
* **Policy Ref** — mọi execution qua policy (T113).
* **Artifact Ref** — execution sinh artifact (T130).

### 2. Execution Contract

```text
ExecutionContract
├── execution_id         (immutable, T001 Rule 1)
├── request_schema
├── response_schema
├── sandbox_ref          (T136)
├── policy_ref           (T113)
├── artifact_ref         (T130)
└── evidence_ref         (T001)
```

Quy tắc:

* Mọi execution task M20 phải implement `ExecutionContract`.
* Contract không chứa logic runner; runner (T139/T140) mới implement.
* Mọi execution có provenance (T001 Rule 5).
* Cùng contract + cùng input → cùng schema validation (deterministic).

### 3. Execution Contract Safety

* **Fail-closed** — contract không hợp lệ → reject, không promote PASS (T078).
* **Evidence required** — mọi execution có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng validation.
* **Policy boundary** — dùng Permission/Policy (T113) + Sandbox (T136) + Artifact (T130).
* **No parallel contract** — dùng Execution (T005) + Coder Pipeline (T125–T130) + Evidence (T001).

### 4. Deliverables

* Sandbox Ref schema (T136).

### 5. Acceptance Criteria

TASK-135 chỉ PASS khi:

* Execution Contract định nghĩa rõ request/response/sandbox/policy/artifact schema.
* Contract không hợp lệ → reject (fail-closed, T078).
* Mọi execution có provenance (T001 Rule 5).
* Cùng input → cùng validation (deterministic).
* Tích hợp được với Execution + Coder Pipeline + Sandbox + Evidence.
* Regression của các milestone trước PASS; không vi phạm invariants.
