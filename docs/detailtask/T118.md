## TASK-118 — Source / Symbol Index

**Mục tiêu**

Triển khai **Source / Symbol Index** như một năng lực có contract, evidence và harness riêng — parse source thành symbol (function/class/var) và index để retrieval. TASK-118 là **symbol index, không phải retriever mới** (dựa trên Repository Scanner T117 + Context Retriever T121).

TASK-118 thuộc **M18**, ngay sau T117. Trọng tâm canonical: **Source / Symbol Index**.

### 1. Phạm vi — Symbol index, không new retriever

```text
Source / Symbol Index
├── Parser               (parse source -> symbols)
├── Symbol Store         (function/class/var + location)
├── Index                (lookup symbol)
└── Policy Boundary      (T113)
```

* **Parser** — parse source thành symbols (theo ngôn ngữ hỗ trợ).
* **Symbol Store** — lưu symbol + location (file, line, `content_hash` T078).
* **Index** — lookup symbol nhanh theo name/type.
* **Policy Boundary** — index không lộ secret (T040/T113).

### 2. Symbol Index Contract

```text
SymbolIndex
├── repo_ref
├── symbols[]            (name, kind, file, line, content_hash)
├── index_id             (immutable, T001 Rule 1)
├── policy_ref           (T113)
└── evidence_ref         (T001)
```

Quy tắc:

* Mọi symbol có location + `content_hash` (T078) + provenance (T001 Rule 5).
* Index idempotent: cùng source → cùng symbol set (deterministic).
* Parse fail → reject (fail-closed, T078).
* Mọi index có provenance (T001 Rule 5).

### 3. Symbol Index Safety

* **Fail-closed** — parse fail → reject (T078).
* **Secret isolation** — không lộ secret (T040/T113).
* **Evidence required** — mọi index có provenance (T001 Rule 5).
* **Deterministic** — cùng source → cùng symbol set.
* **No parallel index** — dùng Scanner (T117) + Evidence (T001) + Integrity (T078).

### 4. Deliverables
