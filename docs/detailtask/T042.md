## TASK-042 — Enterprise Operations + Dashboard

## 1. Metadata

* **Milestone:** M8 — Ecosystem + Autonomy
* **Task ID:** TASK-042
* **Tên:** Enterprise Operations + Dashboard
* **Mục tiêu canonical:** Enterprise Operations + Dashboard.
* **Dependency trực tiếp:** TASK-041 — HA + Audit + Recovery
* **Priority:** High
* **Status:** PLANNED
* **Execution model:** Runtime-first · Policy-first · Evidence-first · Fail-closed


TASK-042 thuộc **M7 – Enterprise**, đứng sau TASK-041 (HA + Audit + Recovery). Nguồn master xác định mục tiêu là cung cấp năng lực vận hành enterprise; task phải tích hợp với Runtime/Harness hiện có và không tạo control plane song song. 

### 1. Mục tiêu

Xây lớp **Enterprise Operations** để quản trị và quan sát toàn bộ AIOS Enterprise từ Control Plane, bao gồm:

* Health & operational status
* Runtime/tenant/project metrics
* Enterprise observability
* Tenant Operations Dashboard
* Audit visibility
* Resource/cost/execution monitoring
* Backup/recovery status
* Operational alerts
* Readiness / release visibility

Dashboard **chỉ là projection của state thật**, không trở thành một control plane riêng.

### 2. Phạm vi

**Control Plane**

```text
Enterprise Operations
├── Health
├── Metrics
├── Audit
├── Runtime Operations
├── Tenant Operations
├── Cost / Resource Operations
├── Recovery Status
└── Dashboard API
```

**Dashboard**

Các nhóm view chính:

1. **System Overview**

   * Overall health
   * Runtime nodes
   * Active executions
   * Failed executions
   * Queue depth
   * Policy violations

2. **Runtime Operations**

   * Runtime node health
   * Capacity
   * Active/queued executions
   * Drain/failover state
   * Version

3. **Tenant Operations**

   * executions
   * success/failure rate
   * latency
   * token usage
   * cost
   * quota utilization
   * policy violations

4. **Execution Operations**

   * execution status
   * workflow
   * agent
   * model
   * runtime
   * duration
   * resource usage
   * recovery/failover history

5. **Audit**

   * Who
   * What
   * When
   * Tenant
   * Project
   * Agent
   * Workflow
   * Tool
   * Credential scope
   * Policy decision
   * Result

6. **Recovery**

   * failed nodes
   * active leases
   * recovered executions
   * pending recovery
   * backup/snapshot status

### 4. Operational API

Cần có contract/API cho tối thiểu:

```text
GET /api/v1/operations/health
GET /api/v1/operations/overview
GET /api/v1/operations/runtimes
GET /api/v1/operations/executions
GET /api/v1/operations/tenants/{tenant_id}
GET /api/v1/operations/audit
GET /api/v1/operations/recovery
GET /api/v1/operations/metrics
```

Mọi endpoint phải tuân:

```text
Identity
→ Tenant Boundary
→ Policy
→ Authorization
→ Data
```

Không cho Dashboard bypass Policy/Permission/Tenant Boundary.

### 5. Health Model

Health không chỉ trả về một boolean.

```text
HEALTHY
DEGRADED
UNHEALTHY
UNKNOWN
```

Phải phân biệt:

* Control Plane
* Runtime Pool
* Runtime Node
* Scheduler
* Resource
* Database/storage
* Audit
* Model provider
* Harness
* Tenant services

`UNKNOWN` không được tự động chuyển thành `HEALTHY`.

### 7. Dashboard Security

Dashboard phải enforce tenant isolation ở **server side**.

Ví dụ:

```text
User A
  ↓
Tenant A
  ↓
Operations API
  ↓
Tenant Filter
  ↓
Tenant A metrics
```

Không được dựa vào frontend filter:

```text
❌ Browser nhận toàn bộ tenant data rồi tự filter
```
