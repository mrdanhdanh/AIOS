## TASK-165 — Adversarial Evaluation Harness

**Mục tiêu**

Triển khai **Adversarial Evaluation Harness** như một năng lực có contract, evidence và harness riêng — harness chạy các attacker (T166→T173) chống verification suite (T155→T164) để đo resilience, fail-closed. TASK-165 là **adversarial harness, không phải attacker mới** (dựa trên toàn bộ M22 T155→T164 + Harness Kernel T029 + Test Harness T031 + Evidence T001).

TASK-165 thuộc **M23**, là task nền tảng của milestone. Trọng tâm canonical: **Adversarial Evaluation Harness**.

### 1. Phạm vi — Adversarial harness, không attacker mới

```text
Adversarial Evaluation Harness
├── Attack Orchestration  (chạy T166→T173)
├── Resilience Measure    (đo resilience verification suite)
├── Fail-Closed Check     (verifier vẫn fail-closed dưới tấn công)
└── Policy Boundary       (T113)
```

* **Attack Orchestration** — điều phối các attacker (T166→T173) chống verifier.
* **Resilience Measure** — đo mức độ verifier chống lại tấn công.
* **Fail-Closed Check** — dưới tấn công, verifier vẫn fail-closed (T078).
* **Policy Boundary** — mọi attack qua policy (T113), sandbox-only (T136).

### 2. Adversarial Evaluation Harness Contract

```text
AdversarialRun
├── run_id               (immutable, T001 Rule 1)
├── attacker_refs[]      (T166→T173)
├── verifier_refs[]      (T155→T164)
├── resilience_score
├── fail_closed: bool
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Dưới tấn công, verifier FAIL/INCONCLUSIVE vẫn không promote PASS (fail-closed, T078).
* Mọi run có provenance (T001 Rule 5).
* Run deterministic: cùng attack → cùng verdict (T029/T079).
* Attack chỉ trong sandbox (T136/T040), không lộ secret (T040/T113).

### 3. Adversarial Evaluation Harness Safety

* **Fail-closed** — verifier dưới tấn công vẫn fail-closed (T078).
* **Immutable id** — `run_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi run có provenance (T001 Rule 5).
* **Deterministic** — cùng attack → cùng verdict (T029/T079).
* **No parallel harness** — dùng toàn bộ M22 (T155→T164) + Harness Kernel (T029) + Test Harness (T031) + Evidence (T001).

### 4. Deliverables

* Adversarial Evaluation Harness (orchestration + resilience + fail-closed check).
