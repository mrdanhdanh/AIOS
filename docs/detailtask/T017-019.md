# TASK-017 — FastAPI REST + WebSocket

## 1. Metadata

* **Milestone:** M3 — Desktop Edition
* **Task ID:** TASK-017
* **Tên:** FastAPI REST + WebSocket
* **Mục tiêu canonical:** Mở Runtime/Orchestrator qua API ổn định (REST + WebSocket, auth boundary, error model).
* **Dependency trực tiếp:** TASK-016 — Architecture Hardening
* **Task tiếp theo:** TASK-018 — Dashboard SPA; TASK-019 — VS Code Extension
* **Priority:** Critical
* **Status:** PLANNED
* **Execution model:** Runtime-first · Policy-first · Evidence-first · Fail-closed

### 1. Mục tiêu

Xây API boundary chính thức để Dashboard, VS Code Extension và CLI có thể sử dụng cùng một Runtime/Orchestrator backend.

Roadmap xác định phạm vi gồm **REST resources, WebSocket events, auth boundary và error model**; CLI/UI/API phải dùng chung contracts và event stream không được bypass policy. 

### 2. Phạm vi

#### REST API

Expose tối thiểu các nhóm:

```text
/api/v1/
├── health
├── system
├── orchestrator
├── executions
├── workflows
├── tasks
├── agents
├── capabilities
├── tools
├── skills
├── memory
├── artifacts
├── models
├── prompts
└── events
```

API không gọi implementation nội bộ tùy tiện.

Luồng chuẩn:

```text
HTTP Request
    ↓
API Contract
    ↓
Orchestrator / Runtime API
    ↓
Policy
    ↓
Execution
```

#### WebSocket

WebSocket phục vụ realtime:

```text
Runtime Event Bus
      ↓
Event Service
      ↓
WebSocket Gateway
      ↓
Dashboard / Extension
```

Các event quan trọng:

```text
execution.created
execution.started
execution.node.started
execution.node.completed
execution.failed
execution.completed

task.created
task.updated
task.completed

agent.started
agent.completed

artifact.created
skill.changed
health.changed
policy.decision
```

WebSocket **chỉ stream event**, không trở thành đường bypass execution.

### 3. API Contract

Mọi request/response phải dựa trên contract version hóa:

```text
API Contract
├── request schema
├── response schema
├── error schema
├── pagination
├── version
└── compatibility
```

Error model thống nhất:

```text
400 INVALID_REQUEST
401 UNAUTHORIZED
403 POLICY_DENIED
404 NOT_FOUND
409 CONFLICT
422 CONTRACT_INVALID
429 RESOURCE_LIMIT
500 INTERNAL_ERROR
503 SERVICE_UNAVAILABLE
```

Không expose traceback hoặc implementation detail ra client.

### 4. Authentication boundary

M3 chỉ cần tạo **boundary**, chưa triển khai Enterprise IAM của M7.

```text
Client
  ↓
API Boundary
  ↓
Authentication Context
  ↓
Orchestrator / Runtime
```

Identity/tenant đầy đủ vẫn thuộc M7.

### 5. Deliverables

* FastAPI application.
* REST routers.
* WebSocket gateway.
* API schemas.
* Error model.
* OpenAPI specification.
* Contract tests.
* Integration tests.
* Event-stream tests.
* API documentation.

### 6. Acceptance Criteria

#### AC-017-01 — Shared contracts
CLI, Dashboard và Extension sử dụng cùng backend contracts (không có contract riêng).

#### AC-017-02 — Policy boundary
REST request không bypass Policy; mọi mutation đi qua Orchestrator/Runtime/Policy.

#### AC-017-03 — WebSocket event integrity
WebSocket chỉ phát event hợp lệ từ Event Service; không trở thành đường bypass execution.

#### AC-017-04 — Execution state accuracy
Execution state hiển thị đúng với State Service.

#### AC-017-05 — Stable error schema
API error có schema ổn định; không expose traceback/implementation detail ra client.

#### AC-017-06 — API versioning
API versioning hoạt động; client gọi đúng version qua header.

#### AC-017-07 — No implementation leak
API không expose implementation detail ra client.

#### AC-017-08 — WebSocket reconnect consistency
WebSocket reconnect không làm mất tính nhất quán của execution state.

#### AC-017-09 — Offline tests
Test offline chạy được (không phụ thuộc mạng/LLM).

### 7. Dependency

```text
TASK-016 (Architecture Hardening — cuối M2)
        ↓
     TASK-017
```

> Closure: TASK-017 kế thừa toàn bộ foundation M0–M2 (TASK-001 → TASK-016); chỉ cần TASK-016 PASS là READY.

# TASK-018 — Dashboard SPA

## 1. Metadata

* **Milestone:** M3 — Desktop Edition
* **Task ID:** TASK-018
* **Tên:** Dashboard SPA
* **Mục tiêu canonical:** Xây operational UI thống nhất (10 view) phản ánh state thật; mọi action đi qua API/Runtime.
* **Dependency trực tiếp:** TASK-017 — FastAPI REST + WebSocket
* **Task tiếp theo:** TASK-019 — VS Code Extension (cùng M3); TASK-020 — Upgrade Pipeline (M4)
* **Priority:** High
* **Status:** PLANNED
* **Execution model:** Runtime-first · Policy-first · Evidence-first · Fail-closed

### 1. Mục tiêu

> **Scope revision (audit 2026-08-22):** The canonical detailtask requires a React + Vite SPA, but the agreed task-folder `spec.md` (`aios/progress/tasks/TASK-018/spec.md`) deliberately revises scope to a **Python backend / data-layer service** (`aios/dashboard/`) that any frontend would consume. The implementation follows the revised scope; the React+Vite SPA is deferred.

Xây **operational desktop dashboard** thống nhất để người dùng quan sát và điều khiển AIOS.

Roadmap định nghĩa **10 view**: Chat, Workflow, Timeline, Tools, Memory, Artifacts, Skills, Models, Prompts và Health. UI phải phản ánh state thật và mọi action phải đi qua API/Runtime. 

### 2. Kiến trúc

# TASK-019 — VS Code Extension

## 1. Metadata

* **Milestone:** M3 — Desktop Edition
* **Task ID:** TASK-019
* **Tên:** VS Code Extension
* **Mục tiêu canonical:** Đưa AIOS vào coding workspace; extension là client thuần, không chứa business logic riêng.
* **Dependency trực tiếp:** TASK-017 — FastAPI REST + WebSocket
* **Task tiếp theo:** TASK-020 — Upgrade Pipeline (M4)
* **Priority:** High
* **Status:** PLANNED
* **Execution model:** Runtime-first · Policy-first · Evidence-first · Fail-closed

### 1. Mục tiêu

> **Scope revision (audit 2026-08-22):** The canonical detailtask requires a real VS Code Extension (package.json / TS / .vsix), but the agreed task-folder `spec.md` (`aios/progress/tasks/TASK-019/spec.md`) revises scope to a **Python client/contract layer** (`aios/extension/`) that any VS Code extension would consume. The implementation follows the revised scope; the packaged extension is deferred.

Đưa AIOS trực tiếp vào coding workspace.

Roadmap xác định Extension phục vụ **Chat, workflow run, task/progress, artifacts và diagnostics**; extension không chứa business logic riêng mà sử dụng AIOS APIs.
