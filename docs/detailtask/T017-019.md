## M3 — Desktop Edition

Theo roadmap canonical, **M3 = Desktop Edition**, gồm **P5 Dashboard** và **P6 VS Code Extension**. Trong Master Task Specification, M3 tương ứng **TASK-017 → TASK-019**. 

M3 không tạo business logic mới; mục tiêu là **đưa Runtime + Orchestrator + Registry + Observability của M0–M2 ra giao diện desktop thống nhất**.

### Mục tiêu M3

```text
M0–M2
Runtime + Orchestrator + Worker + Tool + Skill
                │
                ▼
        Stable API Boundary
                │
        ┌───────┴────────┐
        ▼                ▼
   Dashboard SPA    VS Code Extension
```

Nguyên tắc:

* UI không bypass Runtime/Policy/Permission.
* UI không chứa business logic riêng.
* REST/WebSocket chỉ là presentation/API boundary.
* Dashboard và Extension dùng chung contracts/API.
* Event realtime phải đi qua Event Service/WebSocket.
* M3 không biến frontend thành một control plane thứ hai.

# TASK-017 — FastAPI REST + WebSocket

### 1. Mục tiêu

Xây API boundary chính thức để Dashboard, VS Code Extension và CLI có thể sử dụng cùng một Runtime/Orchestrator backend.

Roadmap xác định phạm vi gồm **REST resources, WebSocket events, auth boundary và error model**; CLI/UI/API phải dùng chung contracts và event stream không được bypass policy. 

### 2. Phạm vi

#### REST API

Expose tối thiểu các nhóm:

```text
/api/v1/
├── health
├── system
├── orchestrator
├── executions
├── workflows
├── tasks
├── agents
├── capabilities
├── tools
├── skills
├── memory
├── artifacts
├── models
├── prompts
└── events
```

API không gọi implementation nội bộ tùy tiện.

Luồng chuẩn:

```text
HTTP Request
    ↓
API Contract
    ↓
Orchestrator / Runtime API
    ↓
Policy
    ↓
Execution
```

#### WebSocket

WebSocket phục vụ realtime:

```text
Runtime Event Bus
      ↓
Event Service
      ↓
WebSocket Gateway
      ↓
Dashboard / Extension
```

Các event quan trọng:

```text
execution.created
execution.started
execution.node.started
execution.node.completed
execution.failed
execution.completed

task.created
task.updated
task.completed

agent.started
agent.completed

artifact.created
skill.changed
health.changed
policy.decision
```

WebSocket **chỉ stream event**, không trở thành đường bypass execution.

### 3. API Contract

Mọi request/response phải dựa trên contract version hóa:

```text
API Contract
├── request schema
├── response schema
├── error schema
├── pagination
├── version
└── compatibility
```

Error model thống nhất:

```text
400 INVALID_REQUEST
401 UNAUTHORIZED
403 POLICY_DENIED
404 NOT_FOUND
409 CONFLICT
422 CONTRACT_INVALID
429 RESOURCE_LIMIT
500 INTERNAL_ERROR
503 SERVICE_UNAVAILABLE
```

Không expose traceback hoặc implementation detail ra client.

### 4. Authentication boundary

M3 chỉ cần tạo **boundary**, chưa triển khai Enterprise IAM của M7.

```text
Client
  ↓
API Boundary
  ↓
Authentication Context
  ↓
Orchestrator / Runtime
```

Identity/tenant đầy đủ vẫn thuộc M7.

### 5. Deliverables

* FastAPI application.
* REST routers.
* WebSocket gateway.
* API schemas.
* Error model.
* OpenAPI specification.
* Contract tests.
* Integration tests.
* Event-stream tests.
* API documentation.

### 6. Acceptance Criteria

* CLI, Dashboard và Extension sử dụng cùng backend contracts.
* REST request không bypass Policy.
* WebSocket chỉ phát event hợp lệ từ Event Service.
* Execution state hiển thị đúng với State Service.
* API error có schema ổn định.
* API versioning hoạt động.
* API không expose implementation detail.
* WebSocket reconnect không làm mất tính nhất quán của execution state.
* Test offline chạy được.

### 7. Dependency

```text
TASK-011
TASK-010
TASK-012
TASK-013
TASK-014
TASK-015
TASK-016
        ↓
     TASK-017
```

# TASK-018 — Dashboard SPA

### 1. Mục tiêu

Xây **operational desktop dashboard** thống nhất để người dùng quan sát và điều khiển AIOS.

Roadmap định nghĩa **10 view**: Chat, Workflow, Timeline, Tools, Memory, Artifacts, Skills, Models, Prompts và Health. UI phải phản ánh state thật và mọi action phải đi qua API/Runtime. 

### 2. Kiến trúc

```text
React + Vite
     │
     ├── REST API Client
     │
     └── WebSocket Client
              │
              ▼
        FastAPI Boundary
              │
       ┌──────┴──────┐
       ▼             ▼
 Orchestrator      Runtime
```

Dashboard **không được**:

```text
React → DB
React → Runtime Service implementation
React → Tool
React → subprocess
React → Model Provider
```

### 3. Dashboard 10 View

# TASK-019 — VS Code Extension

### 1. Mục tiêu

Đưa AIOS trực tiếp vào coding workspace.

Roadmap xác định Extension phục vụ **Chat, workflow run, task/progress, artifacts và diagnostics**; extension không chứa business logic riêng mà sử dụng AIOS APIs. 

### 2. Kiến trúc

```text
VS Code
   │
   ▼
AIOS Extension
   │
   ├── Command Registry
   ├── Workspace Adapter
   ├── API Client
   └── Event Client
            │
            ▼
       AIOS API
            │
       Orchestrator
            │
         Runtime
```

Extension chỉ là **client**.

### 3. Commands

Các chức năng chính:

```text
AIOS: Chat
AIOS: Explain
AIOS: Fix Selection
AIOS: Generate Test
AIOS: Review PR
AIOS: Refactor
AIOS: Rename
AIOS: Ask Workspace
AIOS: Chat with Repository
```

### 4. Workspace Context

Extension có thể gửi:

```text
workspace
selected file
selected code
current file
open files
git state
repository metadata
```

Nhưng context phải được backend xử lý qua Context/Memory/Policy; extension không tự quyết định quyền truy cập.

### 5. Coding Flow

Ví dụ `Fix Selection`:

```text
User selects code
      ↓
VS Code Extension
      ↓
API
      ↓
Normalizer
      ↓
Rule Engine
      ↓
Workflow Matcher
      ↓
Coder Worker
      ↓
Capability
      ↓
Tool
      ↓
Artifact / Evidence
      ↓
Extension
      ↓
Diff Preview
```

Extension **không tự sửa file** nếu backend chưa cấp execution/action hợp lệ.

### 6. Task / Progress

Extension phải hiển thị:

```text
Goal
 └── Task
      └── Workflow
           └── Execution
                ├── Node
                ├── State
                └── Evidence
```

Cho phép người dùng theo dõi task mà không tạo task state riêng trong extension.

### 7. Artifact Integration

Artifact có thể:

* mở file
* preview diff
* xem metadata
* xem provenance
* mở execution liên quan

Nhưng artifact authoritative nằm ở Artifact Service.

### 8. Diagnostics

Extension nhận diagnostics từ AIOS:

```text
Architecture violation
Policy violation
Workflow failure
Tool failure
Test failure
Health warning
```

Diagnostics phải có provenance và severity.

### 9. Offline-first

Khi không có LLM:

```text
Extension
   ↓
API
   ↓
Normalizer
   ↓
Rule Engine
   ↓
Known Workflow
   ↓
Mock / Local execution
```

Các command deterministic vẫn phải hoạt động khi có thể.

### 10. Deliverables

* VS Code extension.
* Command registry.
* AIOS API client.
* WebSocket/event client.
* Workspace context adapter.
* Task/progress panel.
* Artifact integration.
* Diagnostics integration.
* Diff/preview integration.
* Extension tests.
* Backend integration tests.

### 11. Acceptance Criteria

* Các command chính gọi đúng AIOS API.
* Extension không chứa orchestration/business logic.
* Workspace context tuân Policy.
* Không truy cập Runtime/Tool trực tiếp.
* Task/progress lấy từ backend.
* Artifact provenance được giữ.
* Diagnostics hiển thị đúng severity/state.
* Offline deterministic path hoạt động.
* Extension reconnect được với backend.
* Không tạo state authoritative song song.
