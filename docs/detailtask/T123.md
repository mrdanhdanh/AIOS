TASK-123 thuộc **M18**, ngay sau T122. Trọng tâm canonical: **Context Verification + Evidence**.

### 3. Context Verification Safety

* **Fail-closed** — INCONCLUSIVE → không promote PASS (T078).
* **Integrity verified** — context phải qua integrity gate (T078).
* **Evidence required** — mọi verification có provenance (T001 Rule 5).
* **Deterministic** — cùng context → cùng result.
* **No parallel verification** — dùng Builder (T122) + Integrity (T078) + Evidence (T001).
