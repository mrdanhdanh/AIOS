## TASK-126 — Coding Planner + PlanVerifier

**Mục tiêu**

Triển khai **Coding Planner + PlanVerifier** như một năng lực có contract, evidence và harness riêng — lập kế hoạch coding (deterministic-first) và verify plan trước khi thực thi, không để LLM làm control plane. TASK-126 là **planner + verifier, không phải generator mới** (dựa trên Coder Agent T125 + Planning Engine T026 + Deterministic T001 Rule 4).

TASK-126 thuộc **M19**, ngay sau T125. Trọng tâm canonical: **Coding Planner + PlanVerifier**.

### 1. Phạm vi — Planner + verifier, không new generator

```text
Coding Planner + PlanVerifier
├── Planner               (lập plan coding, deterministic-first)
├── PlanVerifier         (verify plan hợp lệ trước exec)
├── Deterministic Path   (rule trước LLM, T001 Rule 4)
└── Policy Boundary       (T113)
```

* **Planner** — lập coding plan (steps) theo rule; LLM chỉ fallback khi rule không đủ (T001 Rule 4).
* **PlanVerifier** — verify plan hợp lệ (schema, dependency, policy) trước execution.
* **Deterministic Path** — rule quyết định được → LLM call = 0.
* **Policy Boundary** — plan phải qua policy (T113).

### 2. Coding Planner Contract

```text
CodingPlan
├── agent_ref             (T125)
├── steps[]              (action, target, policy_ref)
├── planner_deterministic: bool
├── verified: bool        (PlanVerifier)
├── llm_call_count        (0 nếu rule đủ)
└── evidence_ref          (T001)
```

Quy tắc:

* Plan deterministic: rule đủ → `llm_call_count = 0` (T001 Rule 4).
* Plan phải qua PlanVerifier trước execution; verify FAIL → reject (fail-closed, T078).
* Mọi plan có provenance (T001 Rule 5).
* Cùng request + cùng rule → cùng plan (deterministic).

### 3. Coding Planner Safety

* **Deterministic-first** — rule trước LLM (T001 Rule 4).
* **Fail-closed** — plan verify FAIL → reject (T078).
* **Evidence required** — mọi plan có provenance (T001 Rule 5).
* **Deterministic** — cùng request + rule → cùng plan.
* **No parallel planner** — dùng Coder Agent (T125) + Planning Engine (T026) + Deterministic (T001) + Policy (T113).
