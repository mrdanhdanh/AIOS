## TASK-081 — Asset Pipeline + Asset Capability Registry + Routing

**Mục tiêu**

Xây dựng **Asset Pipeline** — quản lý lifecycle của asset (tạo, validate, version, route) qua một **Asset Capability Registry** và cơ chế **routing** đến capability/tool xử lý asset phù hợp. TASK-081 là **asset management layer, không phải capability mới** (dựa trên Capability T001/aios/capability + Evidence T001).

TASK-081 thuộc **M11**, ngay sau T080 (Visual Evidence). Trọng tâm canonical: **Asset Pipeline + Asset Capability Registry + Routing**.

### 1. Phạm vi — Asset pipeline, không replace capability

```text
Asset Pipeline
├── Asset Registry      (versioned assets)
├── Asset Capability Registry (which capability handles which asset type)
├── Routing             (asset -> capable capability/tool)
└── Validation          (asset integrity + schema)
```

* **Asset Registry** — lưu asset versioned + content_hash (T001 Rule 5).
* **Asset Capability Registry** — ánh xạ asset type → capability/tool xử lý.
* **Routing** — chọn capability/tool đúng theo asset type (policy-driven).
* **Validation** — asset phải qua integrity + schema check trước khi route.

### 2. Asset Contract

```text
AssetRecord
├── asset_id
├── asset_type
├── version
├── content_hash
├── capable_capabilities: [..]
└── evidence_ref
```

Quy tắc:

* Asset không validate → không route (fail-closed).
* Routing chỉ đến capability đã đăng ký xử lý asset type đó.
* Mọi asset có provenance (T001 Rule 5).

### 3. Asset Safety

* **Fail-closed routing** — asset không validate → không route.
* **Capability scoping** — chỉ route đến capability đủ năng lực.
* **Evidence required** — mọi asset có provenance.
* **Deterministic routing** — cùng asset type + cùng registry → cùng route.
* **No parallel asset system** — dùng Capability (aios/capability) + Evidence (T001).

### 4. Deliverables

* Asset Registry (versioned + content_hash).
* Asset Capability Registry (asset type → capability).
* Routing (policy-driven selection).
* Asset Validation (integrity + schema).
* Integration với Capability (aios/capability) + Evidence (T001) + Visual (T080).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs khi task yêu cầu.

### 5. Acceptance Criteria

TASK-081 chỉ PASS khi:

* Asset Registry lưu asset versioned + content_hash.
