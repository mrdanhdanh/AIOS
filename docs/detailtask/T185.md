## TASK-185 — Coding Evaluation Contract

**Mục tiêu**

Triển khai **Coding Evaluation Contract** như một năng lực có contract, evidence và harness riêng — định nghĩa contract chuẩn cho evaluation (request/response, dimension ref, evidence ref) mà mọi evaluation task M25 dùng chung. TASK-185 là **foundation của M25, không phải engine mới** (dựa trên Evaluation Harness T032 + Evidence T001 Rule 5).

TASK-185 thuộc **M25**, là task mở milestone. Trọng tâm canonical: **Coding Evaluation Contract**.

### 1. Phạm vi — Contract chuẩn, không engine mới

```text
Coding Evaluation Contract
├── Evaluation Schema    (request/response chuẩn)
├── Dimension Ref        (ref các chiều chất lượng, T187)
├── Evidence Ref         (T001)
└── Policy Boundary      (T113)
```

* **Evaluation Schema** — định nghĩa cấu trúc evaluation request/response chuẩn.
* **Dimension Ref** — evaluation trỏ tới các dimension (T187).
* **Evidence Ref** — mọi evaluation có provenance (T001 Rule 5).
* **Policy Boundary** — evaluation qua policy (T113).

### 2. Coding Evaluation Contract

```text
EvaluationContract
├── eval_id              (immutable, T001 Rule 1)
├── request_schema
├── response_schema
├── dimension_ref        (T187)
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Mọi evaluation có provenance (T001 Rule 5).
* Evaluation deterministic: cùng input → cùng output (T032).
* `eval_id` immutable (T001 Rule 1).
* Cùng evaluation + cùng verifier → cùng verdict (deterministic).

### 3. Coding Evaluation Contract Safety

* **Fail-closed** — evaluation thiếu provenance → không promote (T001 Rule 5).
* **Immutable id** — `eval_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi evaluation có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng output (T032).
* **No parallel contract** — dùng Evaluation Harness (T032) + Evidence (T001).

### 4. Deliverables
