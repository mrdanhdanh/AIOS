## TASK-066 — Durable Execution 1.0

**Mục tiêu**

Xây dựng **durable execution** cho Runtime — state của execution được checkpoint và có thể resume sau crash / restart mà không mất tiến triển đã verified. TASK-066 là **state durability + recovery, không phải scheduler mới**.

TASK-066 thuộc **M10 – Architecture 1.0**, ngay sau T065 (Runtime Hardening). Trọng tâm canonical: **Durable state / checkpoint / recovery**.

### 1. Phạm vi — Durability, không redesign loop

```text
Execution
   │
   ▼
Checkpoint Store (durable)
   ├── state snapshot (verified)
   ├── progress marker
   └── resume token
   │
   ▼
Crash / Restart
   │
   ▼
Resume from last verified checkpoint
```

* **Checkpoint Store** — lưu snapshot state đã verified (provenance).
* **Resume Protocol** — khôi phục từ checkpoint gần nhất đã verified.
* **Idempotency Guard** — bước đã thực thi không thực thi lại gây side-effect kép.

### 2. Durability Contract

```text
Checkpoint
├── execution_id
├── step_id
├── state_hash
├── verified: bool      # chỉ resume từ verified
├── created_at
└── evidence_ref
```

Quy tắc:

* Chỉ resume từ checkpoint `verified=true` (fail-closed — không resume từ state chưa verify).
* Checkpoint phải durable (persist qua restart) — thiết kế sẵn cho T062 (Scheduler).
* Resume không được gây side-effect kép (idempotency).

### 3. Durability Safety

* **No resume from unverified** — checkpoint chưa verify → KHÔNG resume (fail-closed).
* **Idempotency** — resume không thực thi lại bước đã done.
* **Evidence required** — mỗi checkpoint có provenance.
* **Deterministic** — cùng checkpoint + cùng resume protocol → cùng state.
* **No parallel execution store** — dùng Runtime state store (T065).

### 4. Deliverables

* Checkpoint Store (durable) + Resume Protocol.
* Idempotency Guard (không double-execute).
* Integration với Runtime state store (T065) + Recovery (T055).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs nếu tạo architectural decision mới.

### 5. Acceptance Criteria

TASK-066 chỉ PASS khi:

* State được checkpoint durable (persist qua restart).
* Chỉ resume từ checkpoint `verified=true`.
* Resume không gây side-effect kép (idempotency).
* Checkpoint có provenance evidence.
* Cùng checkpoint + resume protocol → cùng state (deterministic).
* Tích hợp được với Runtime (T065) + Recovery (T055).
* Không tạo execution store song song.
* Regression của các milestone trước PASS; không vi phạm invariants.
