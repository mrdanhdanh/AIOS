## TASK-216 — Benchmark Gate

**Mục tiêu**

Triển khai **Benchmark Gate** như một năng lực có contract, evidence và harness riêng — gate benchmark cho coding, fail-closed. TASK-216 là **benchmark gate, không phải benchmark mới** (dựa trên Coding Certification T215 + Model/Agent Benchmark T195 + Benchmark/Regression T033 + Evidence T001).

TASK-216 thuộc **M26**, ngay sau T215. Trọng tâm canonical: **Benchmark Gate**.

### 1. Phạm vi — Benchmark gate, không benchmark mới

```text
Benchmark Gate
├── Gate                 (gate benchmark coding)
├── Benchmark Bind       (gắn benchmark T195)
├── Regression Check     (kiểm regression T033)
└── Policy Boundary      (T113)
```

* **Gate** — gate benchmark cho coding đã certify (T215).
* **Benchmark Bind** — gắn Model/Agent Benchmark (T195).
* **Regression Check** — kiểm regression (T033/T190).
* **Policy Boundary** — gate qua policy (T113).

### 2. Benchmark Gate Contract

```text
CodingBenchmarkGate
├── gate_id              (immutable, T001 Rule 1)
├── cert_ref             (T215)
├── benchmark_ref        (T195)
├── verdict              (PASS/FAIL)
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Benchmark fail/regression → FAIL (fail-closed, T078/T195/T033).
* Mọi gate có provenance (T001 Rule 5).
* Gate deterministic: cùng input → cùng verdict.
* Gate không vượt policy boundary (T113).

### 3. Benchmark Gate Safety

* **Fail-closed** — benchmark fail → FAIL (T078/T195/T033).
* **Immutable id** — `gate_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi gate có provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng verdict.
* **No parallel gate** — dùng Coding Certification (T215) + Model/Agent Benchmark (T195) + Benchmark/Regression (T033) + Evidence (T001).

### 4. Deliverables
