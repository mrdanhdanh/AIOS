## TASK-152 — Context Refresh + Patch Chain

**Mục tiêu**

Triển khai **Context Refresh + Patch Chain** như một năng lực có contract, evidence và harness riêng — làm mới context (Context Optimizer T024) và chuỗi hóa patch (Workspace/Snapshot T137) giữa các vòng lặp, sau khi verification gate (T151) PASS. TASK-152 là **refresh + chain, không phải optimizer mới** (dựa trên Verification Gate T151 + Context Optimizer T024 + Workspace/Snapshot T137 + Evidence T001).

TASK-152 thuộc **M21**, ngay sau T151. Trọng tâm canonical: **Context Refresh + Patch Chain**.

### 1. Phạm vi — Refresh + chain, không optimizer mới

```text
Context Refresh + Patch Chain
├── Context Refresh      (làm mới context, T024)
├── Patch Chain          (chuỗi hóa patch, T137)
├── Snapshot             (snapshot trước/sau, T137)
└── Policy Boundary      (T113)
```

* **Context Refresh** — làm mới context theo Context Optimizer (T024) mỗi vòng.
* **Patch Chain** — chuỗi hóa các patch qua các vòng lặp (T137).
* **Snapshot** — snapshot workspace trước/sau mỗi patch (T137).
* **Policy Boundary** — refresh/chain qua policy (T113).

### 2. Context Refresh + Patch Chain Contract

```text
PatchChain
├── chain_id             (immutable, T001 Rule 1)
├── verification_ref     (T151)
├── context_ref          (T024)
├── patch_links[]        (T137)
├── snapshot_ref         (T137)
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Mọi patch trong chain có provenance (T001 Rule 5).
* Context refresh deterministic: cùng state → cùng context (T024).
* Snapshot trước/sau phải khớp (T137) — mismatch → fail-closed.
* Chain không vượt policy boundary (T113).

### 3. Context Refresh + Patch Chain Safety

* **Fail-closed** — snapshot mismatch → reject (T137).
* **Immutable id** — `chain_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi patch có provenance (T001 Rule 5).
* **Deterministic** — cùng state → cùng context (T024).
* **No parallel chain** — dùng Verification Gate (T151) + Context Optimizer (T024) + Workspace/Snapshot (T137) + Evidence (T001).

### 4. Deliverables

* Context Refresh + Patch Chain (refresh + chain + snapshot).
* Policy Boundary (T113).
* Integration với Verification Gate (T151) + Context Optimizer (T024) + Workspace/Snapshot (T137) + Evidence (T001).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — context refresh + patch chain).

### 5. Acceptance Criteria

TASK-152 chỉ PASS khi:

* Context Refresh làm mới context mỗi vòng (T024).
* Patch Chain chuỗi hóa patch qua các vòng (T137).
* Snapshot trước/sau khớp (T137) — mismatch → fail-closed.
* Mọi patch có provenance (T001 Rule 5).
* Cùng state → cùng context (deterministic, T024).
* Tích hợp được với Verification Gate + Context Optimizer + Workspace/Snapshot + Evidence.
* Regression của các milestone trước PASS; không vi phạm invariants.
