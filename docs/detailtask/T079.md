## TASK-079 — RenderReplay / Deterministic Harness

**Mục tiêu**

Xây dựng **RenderReplay / Deterministic Harness** — khả năng ghi lại (record) một execution run và phát lại (replay) một cách xác định (deterministic) để tái tạo verdict/behavior nhằm audit và debug. TASK-079 là **record/replay harness, không phải execution engine mới** (dựa trên Harness T030/T032 + Evidence T001).

TASK-079 thuộc **M11**, ngay sau T078 (Verification Integrity). Trọng tâm canonical: **RenderReplay / Deterministic Harness**.

### 1. Phạm vi — Record/replay, không replace runtime

```text
Deterministic Harness
├── Record       (capture inputs + evidence + verifier state)
├── Replay       (re-run với cùng inputs -> cùng verdict)
├── Determinism check (same input + same verifier -> same output)
└── Diff report  (replay mismatch -> flag non-determinism)
```

* **Recorder** — ghi lại normalized input + evidence snapshot + verifier version/config.
* **Replayer** — phát lại với cùng inputs → phải ra cùng verdict.
* **Determinism check** — nếu replay khác original → flag non-determinism (T060/T078).

### 2. Replay Contract

```text
ReplaySession
├── original_run_id
├── recorded_inputs_hash
├── verifier_version
├── verifier_config_hash
├── replay_verdict
├── matches_original: bool
└── evidence_ref
```

Quy tắc:

* Replay với cùng input + cùng verifier → cùng verdict (deterministic, T060/T078).
* Replay mismatch → flag non-determinism, không tự biến thành PASS.
* Mọi replay ghi evidence (provenance).

### 3. Replay Safety

* **Deterministic guarantee** — cùng input + verifier → cùng verdict.
* **Fail-closed on mismatch** — replay khác → flag, không promote.
* **Evidence required** — mọi replay có provenance.
* **No side-effects** — replay không mutate production state.
* **No parallel harness** — dùng Harness (T030/T032) + Evidence (T001).

### 4. Deliverables

* Recorder (capture inputs + evidence + verifier state).
* Replayer (deterministic re-run).
* Determinism check + diff report.
* Integration với Harness (T030/T032) + Evidence (T001) + Integrity (T078).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs khi task yêu cầu.
