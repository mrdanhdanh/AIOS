## TASK-125 — Coder Agent Contract + State Machine

**Mục tiêu**

Triển khai **Coder Agent Contract + State Machine** như một năng lực có contract, evidence và harness riêng — định nghĩa contract cho coder agent (I/O-free, capability-injected) và state machine vòng đời coding task. TASK-125 là **contract + state machine, không phải agent runtime mới** (dựa trên Agent Orchestrator T001/AGENTS + Worker Plane T013 + Lifecycle T001 Rule 6).

TASK-125 thuộc **M19**, ngay sau T124 (M18). Trọng tâm canonical: **Coder Agent Contract + State Machine**. Đây là task mở M19.

### 1. Phạm vi — Contract + state machine, không new agent runtime

```text
Coder Agent Contract + State Machine
├── Agent Contract        (I/O-free, capability-injected)
├── State Machine         (coding task lifecycle)
├── Capability Injection  (chỉ qua Runtime/Capability, T013)
└── Policy Boundary       (T113)
```

* **Agent Contract** — coder agent thuần túy, không I/O trực tiếp, nhận capability qua injection (T013/AGENTS).
* **State Machine** — lifecycle coding task: `PLANNED → CODING → REVIEWING → PATCHING → DONE` (dựa T001 Rule 6).
* **Capability Injection** — agent chỉ thấy capability, không import tool/runtime trực tiếp (ARCH-004).
* **Policy Boundary** — mọi transition qua policy (T113).

### 2. Coder Agent Contract

```text
CoderAgentContract
├── agent_id              (immutable, T001 Rule 1)
├── capabilities[]        (injected, T013)

├── io_free: bool         (true)

```

Quy tắc:

* Agent không có I/O trực tiếp; mọi I/O qua Runtime/Capability (ARCH-001..004).
* State transition chỉ hợp lệ khi artifact bắt buộc có mặt (T001 Rule 6).
* Agent không import `subprocess`/provider/filesystem trực tiếp (ARCH-001..003).
* Mọi transition có provenance (T001 Rule 5).

### 3. Coder Agent Safety

* **Architecture gate** — agent import forbidden module → BLOCK (ARCH-001..004).
* **Fail-closed** — thiếu artifact → transition REJECT (T001 Rule 6).
* **Evidence required** — mọi transition có provenance (T001 Rule 5).
* **Deterministic** — cùng state + cùng artifact → cùng transition (deterministic).
* **No parallel agent** — dùng Worker (T013) + Lifecycle (T001) + Policy (T113).
