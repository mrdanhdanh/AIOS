## TASK-062 — Autonomous Scheduler

**Mục tiêu**

Xây dựng **scheduler layer** cho Autonomous Goal — kích hoạt goal / workflow theo schedule (cron) hoặc trigger (event / external signal) một cách **autonomy-aware và fail-closed**. TASK-062 là **activation/orchestration trigger, không phải goal engine, planner hay execution loop**.

TASK-062 thuộc **M9 – Autonomous**, nằm ngay sau TASK-061 (Advanced Stuck Detection). Tiếp nối TASK-050 (Goal Engine) + TASK-051 (Planner) + TASK-053 (Autonomous Loop). Trọng tâm canonical: **Kích hoạt goal theo schedule / trigger**.

### 1. Phạm vi — 3 tầng riêng biệt (Schedule ≠ Plan ≠ Execute)

```text
        TASK-050 Goal Engine
                  │
                  ▼
        Scheduler (TASK-062)
        ┌────────┼────────┐
        ▼        ▼        ▼
     CRON    EVENT    MANUAL
        │        │        │
        └────────┼────────┘
                 ▼
        Autonomy / Policy Check
                 │
                 ▼
        TASK-054 Governor
                 │
        ┌────────┼────────┐
        ▼        ▼        ▼
     ALLOW    ESCALATE   BLOCK
        │        │        │
        ▼        ▼        ▼
   TASK-051   Human/    SAFE
   Planner    policy    STOP
```

Phân tầng trách nhiệm:

* **Scheduler** trả lời: *Đến lúc kích hoạt goal này chưa?* (theo schedule/trigger).
* **Planner / Goal Engine** trả lời: *Goal này cần làm gì?* (T050/T051).
* **Governor** trả lời: *Có được phép thực hiện không?* (T054).

Các thành phần (capability trên Runtime):

* **Schedule Registry** — lưu trữ schedule/trigger cho mỗi goal (durable).
* **Trigger Engine** — đánh giá cron / event / manual trigger.
* **Activation Policy** — kiểm tra autonomy level, resource budget, policy trước khi activate.
* **Scheduler Gate** — chỉ activate goal khi Governor authorize.

### 2. Schedule / Trigger Model

```text
ScheduleEntry
├── goal_id
├── trigger: CRON | EVENT | MANUAL
├── cron_expr / event_filter / manual_token
├── autonomy_level_required
├── enabled
└── next_fire (derived)
```

Quy tắc:

* Mọi activation phải qua Activation Policy + Governor.
* Trigger không xác định / không khớp → **KHÔNG** activate (fail-closed).
* Schedule phải durable (persist qua restart) — thiết kế sẵn cho T066 (Durable Execution).

### 3. Scheduler Safety (fail-closed)

* **No unscheduled execution** — goal chỉ chạy khi có schedule/trigger hợp lệ + Governor allow.
* **Governor authority** — activation phải qua Governor (T054); vượt autonomy → BLOCK.
* **Evidence required** — mỗi activation ghi audit (ai trigger, khi nào, policy nào).
* **Deterministic** — cùng trigger state + cùng policy version → cùng quyết định activate.
* **No parallel control plane** — scheduler là capability trên Runtime.

### 4. Deliverables

* Scheduler layer (không phải goal engine/planner/loop).
* Schedule Registry (durable) + Trigger Engine (cron/event/manual).
* Activation Policy (autonomy/resource/policy check).
* Scheduler Gate (activate chỉ khi Governor authorize).
* Fail-closed rule (trigger không xác định → không activate).
* Integration với Goal Engine (T050) + Planner (T051) + Loop (T053) + Governor (T054).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs nếu tạo architectural decision mới.

### 5. Acceptance Criteria

TASK-062 chỉ PASS khi:

* Goal chỉ activate khi có schedule/trigger hợp lệ.
* **Schedule ≠ Plan ≠ Execute**: Scheduler trigger, Planner/Goal định nội dung, Governor quyết định *có được phép*.
* Cron trigger đến hạn → activate (qua Governor).
* Event trigger khớp filter → activate (qua Governor).
* Manual trigger có token hợp lệ → activate.
* Trigger không xác định / không khớp → **KHÔNG** activate (fail-closed).
* Activation tôn trọng autonomy level (vượt budget → BLOCK).
* Mỗi activation ghi audit evidence (provenance đầy đủ).
* Schedule durable (persist qua restart).
* Scheduler deterministic (cùng trigger state + policy version → cùng quyết định).
* Tích hợp được với Goal Engine (T050) + Planner (T051) + Loop (T053).
* Không tạo autonomous control plane thứ hai.
* Regression của các milestone trước PASS; không vi phạm architecture invariants.
