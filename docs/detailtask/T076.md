## TASK-076 — Reserved / Not Specified in Source

**Mục tiêu**

Giữ nguyên **khoảng trống ID lịch sử** để không tái sử dụng task ID (theo Rule 1 — Task ID immutable / never-reused). Nguồn roadmap không định nghĩa canonical task cho ID này.

TASK-076 thuộc **M11**, là entry giữ chỗ (reserved). Trọng tâm canonical: **Reserved / Not Specified in Source**.

* Không tự gán implementation mới khi nguồn không định nghĩa canonical task.
* Entry này chỉ tồn tại để giữ tính liên tục của task index và ngăn reuse ID.

