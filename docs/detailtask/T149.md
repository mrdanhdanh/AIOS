## TASK-149 — Repair Planner

**Mục tiêu**

Triển khai **Repair Planner** như một năng lực có contract, evidence và harness riêng — lập kế hoạch repair (patch) từ diagnostic report (T148), dùng Planning Engine (T026) + Autonomous Recovery (T055). TASK-149 là **planner, không phải executor mới** (dựa trên Diagnostic Agent T148 + Planning Engine T026 + Autonomous Recovery T055 + Evidence T001).

TASK-149 thuộc **M21**, ngay sau T148. Trọng tâm canonical: **Repair Planner**.

### 1. Phạm vi — Planner, không executor mới

```text
Repair Planner
├── Plan                 (kế hoạch repair từ diagnosis)
├── Patch Spec           (mô tả patch dự kiến)
├── Rollback             (kế hoạch rollback, T055)
└── Policy Boundary      (T113)
```

* **Plan** — sinh kế hoạch repair từ diagnostic report (T148).
* **Patch Spec** — mô tả patch deterministic, có thể verify.
* **Rollback** — mọi plan có rollback (T055) nếu repair fail.
* **Policy Boundary** — plan qua policy (T113).

### 2. Repair Planner Contract

```text
RepairPlan
├── plan_id              (immutable, T001 Rule 1)
├── diagnostic_ref       (T148)
├── patch_spec
├── rollback_ref         (T055)
├── evidence_ref         (T001)
└── authority: aios
```

Quy tắc:

* Mọi plan có rollback (T055) — fail → revert.
* Mọi plan có provenance (T001 Rule 5).
* Plan deterministic: cùng diagnosis → cùng plan.
* Plan không vượt policy boundary (T113).

### 3. Repair Planner Safety

* **Fail-closed** — plan thiếu rollback → reject (T055).
* **Immutable id** — `plan_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi plan có provenance (T001 Rule 5).
* **Deterministic** — cùng diagnosis → cùng plan.
* **No parallel planner** — dùng Diagnostic (T148) + Planning Engine (T026) + Recovery (T055) + Evidence (T001).

### 4. Deliverables

* Repair Planner (plan + patch spec + rollback).
* Policy Boundary (T113).
* Integration với Diagnostic Agent (T148) + Planning Engine (T026) + Autonomous Recovery (T055) + Evidence (T001).
* Unit + Contract + Integration + Architecture + Regression tests.
* ADR/docs (bắt buộc — repair planner).
