* **Fail-closed** — gate BLOCKED → DENY (T078/T175).
* **Immutable id** — `release_id` không tái sử dụng (T001 Rule 1).
* **Evidence required** — mọi quyết định có explanation + provenance (T001 Rule 5).
* **Deterministic** — cùng input → cùng verdict.
* **No parallel gate** — dùng Quality Gate (T175) + Quality Debt (T179) + Governance Ledger (T181) + Evidence (T001).
